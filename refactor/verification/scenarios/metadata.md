# 资料获取与采用验收

验证来源身份、图片输入与完整资料采用。

环境、证据与完成条件见[验收标准](../acceptance.md)，各场景引用对应设计规则。

<a id="identities"></a>

## 完整来源身份

按[来源键清单](../../design/extensions/providers.md#source-keys)核对各接入、跨站映射、导入器和链接示例。品牌拼写 vndb、igdb、tmdb 保留，MyAnimeList 使用 myanimelist，Fanart.tv 使用 fanarttv；月幕和 ISBN 分别保留 ymgal、isbn。上游 links.mal、metadata.vndbId、NFO type=tmdb 和原生编号保持原语法，适配结果使用规范键。

跨站身份使用目标来源定义的同一 source 与资源语法。MangaDex 的 mal 链接与 Wikidata 的 MAL 陈述均产生 myanimelist / manga/<id>，能够由 MAL 提供者读取并复用同一正式绑定；不登记 mal 等缩写别名，也不按显示名称临时改写身份。逐项对照已支持跨站映射，类型或范围不符时保留原有冲突处理。

A06、A16 和 A29 验证同一目标的完整来源身份集合：同一话的多个明确等价发布 UUID 可以同属一个 source 并绑定同一个 Part，代表身份变化不新建话；身份组分别命中两个目标时整项报告冲突，不丢弃身份或自动合并。只读取和换图不保存绑定，卷号与封面 ID 不伪造卷身份。MangaDex 同时核对编号重置、未编号组、按已读等价组写入以及不增加实际阅读历史。

<a id="local-parts"></a>

## 无身份分部的本地对应

沿[候选合同](../../design/domains/metadata-contracts.md)核对对象 key、类型、原始 identification、fields 和 partMatching。关系成员使用普通数组；能力与会话提前确定范围，prepared 在输入边界声明 relationScopes。缺席、[] 和失败分别采用，profile 与 prepared 得到相同的本地决定。

A05、A07 和 A27 按[本地 Part 决策](../../design/domains/metadata.md#local-parts)验证：启用同作品 numberLabel 规则时，无 ID 的第 1 卷唯一命中后复用原 ID、个人标记和文件关联；重复完整更新不增加卷。两个同规则本地卷使该分支歧义，既不取首项，也不创建第三卷。首条规则无命中才尝试下一条，多命中停止，不以弱规则绕过真实身份冲突。

没有可用规则时，已有同范围对象报告依据不足；新作品或空范围只按本次明确清单初始化。prepared 省略 partMatching 不加载默认 Profile；明确提供的规则与 profile 获取使用同一值与比较实现。只更新字段不新增清单成员，卷内话号不改查作品话号。候选合成、两个输入竞争同一目标及准备后新增同号项均保持唯一对应；事务前依据变化时拒绝旧采用，不重新挑选目标。

无身份关联主体另按[本地 Entry 决策](../../design/domains/metadata.md#adoption)核对：没有同名建议且资料齐备时新增；一个或多个名称建议均保留本地对象并报告未采用，不重复创建，也不据此删除旧关系。Part 的唯一匹配能力不扩展到这些主体。

<a id="images"></a>

## 图片准备

[图片输入](../../design/domains/attachments.md#images) 验收 ICO 多尺寸选择、同尺寸位深、透明度、无效层和预算失败；输出 PNG、frameCount=1，API 宽高为 0 不进入正式尺寸。来源 WebM 缩略被忽略后，受支持的动态 WebP 原图仍可预览与采用；无图片缩略时按需生成静态缓存，取消释放资源，不预取全图库。保留动态原图、列表静态缩略、完整查看时播放与明确选帧编辑分别验收，来源文件头检查不代替完整解码和运行验收。

A14 和 A23 验证[URL 文件输入](../../design/domains/resources.md#input)的重定向策略：公开 URL 的缺省 follow 可读取合法重定向资源；显式 error 的 3xx 使本次准备失败，目标端点不收到请求。带非空 Authorization 或 Cookie 的输入只有显式 error 才可发出，缺省或 follow 在网络副作用前拒绝，头名称大小写不影响判断。其他自定义来源凭据由适配显式选择 error；原图、缩略图、字体和 SDK／IPC 传递保留各自选项，不自动去掉头或改策略重试。

<a id="updates"></a>

## 作品更新入口

候选属性核对三种回答：workCharacters.role 缺席时保留已有定位，明确 null 时按所选覆盖规则清空；personWorks 的 isSpoiler 按同一属性采用规则处理。完整成员范围不使缺席属性变成空值。

按[范围合同](../../design/domains/metadata-contracts.md#relation-scopes)验证能力、会话和采用的衔接：

| 场景                                             | 预期结果                                                         |
| ------------------------------------------------ | ---------------------------------------------------------------- |
| MAL 的 studios 返回 []                           | 只移除用户选定范围中的 studio，publisher 保留                    |
| AniList 建立 Studio 或 Staff 团体会话            | 读取前分别取得对应范围，后续 read 沿固定合同回答                 |
| 人物制作履历为空                                 | 按制作职责与无角色范围处理，voiceActor 和具体角色工作保留        |
| studio 成功，只有 publisher 范围的来源失败       | studio 的完整替换仍可执行，publisher 保留并报告未完成            |
| 两个 studio 成员来源中有一个失败                 | union 可补充成功事实，保留该范围内未回答的旧关系                 |
| first 已选定有效回答，较低优先来源的独立字段失败 | 成员选择和已选范围保持原义；字段失败单独报告                     |
| 源端点无法唯一对应                               | 保留受影响分类范围的旧关系，采用其余合法事实                     |
| fetch 结果转交 prepared                          | data 与 relationScopes 一并传递，采用结果与直接 profile 输入一致 |
| prepared 只提供候选、未声明完整范围              | 追加和属性更新按选择执行，替换报告 incompleteRange 并保留旧成员  |

关系范围另覆盖两项边界：Character 根的 workCharacters 只替换声明 workTypes 内的出场；TMDB Organization 的 scope:null 成功返回或明确空数组均只补充事实，保留旧关系并报告本次未完成的替换。混合来源时，参与成员选择的 null 范围使该关系键保留旧关系；first 已在更早来源取得回答后，后续未参与来源不影响结果。

范围与首选资料语言、相关配置在会话中保持固定，新的配置用于新会话。用户 scope 比来源完整范围小时，实际修改限于用户选择。漫画卷话收录另验证：默认补齐时保留旧关联，明确替换时移除未保留的关联；两种方式均保留卷、话、文件、个人记录和已有人工顺序。

资料更新验收遵守[统一入口](../../design/domains/metadata.md#update-entrypoints)：作品字段、关系、分部清单和按种类组织的分部字段都在作品更新器中选择；作品更新器不提供逐项分部选择，分部列表、详情和菜单不出现独立“更新资料”、快捷清单动作或另一份综合更新表单。在作品更新器中只选清单时新增合法缺项、复用旧身份并保留旧字段；只选某类分部字段时，仅处理执行前固定的该类已有分部，不发现新成员，不修改作品字段、其他分部种类或未选字段。实际写入仍限于固定范围中的明确对象；新分部初始化、旧分部个人标记、文件关联和人工排序保持各自规则，读取上下文不扩大写入权限。

<a id="processors"></a>

## 字段加工失败与采用

A05、A07 和 A27 按[字段加工规则](../../design/domains/metadata-profiles.md#processors)验证下列输入与结果，字段校验和本地提交分别由其拥有者执行。

| 场景 | 预期结果 |
| --- | --- |
| 来源 X 经 A 得到 Y，B 失败，字段本地已有 Z | 该字段不进入候选，保留 Z；报告 processorFailed，后续处理器不执行，其他独立字段继续 |
| 第一个处理器即失败，或所选处理器不可用 | 该字段不采用来源原值；失败不被当作正常缺席，保留对应问题 |
| 处理器返回不满足字段合同的值 | 按该步骤失败处理，该字段不采用；processorFailed 携带安全 OperationFailed 摘要 |
| 批量步骤中 a 成功、b 失败，a 后面还有处理器 | a 继续自己的处理器链，整链成功后才采用；b 不采用且不继续 |
| 全部所选字段加工失败，但已有目标仍合法 | 不修改资料，返回带相应问题的 unchanged |
| 新根对象的必需字段加工失败，剩余资料不足 | 新增以 ExecutionFailure 失败，不产生根条目或半份业务图，不以 identification 补回该字段 |
| 新关联对象的必需资料不足 | 排除该对象及依赖关系；合法独立部分可提交，受影响分支不成为删除旧关系的依据 |
| 整链合法返回 null、false 或 0 | 按字段含义和本次采用方式处理，不误判为处理失败或未回答 |
| 整次操作在加工期间取消或调用归属失效 | 按共同取消／实例合同结束，不把取消转成字段问题后继续提交 |

<a id="profiles"></a>

## 资料方案引用

二十八项预设共用一份版本化样本目录，在对应实现运行前固定输入与预期。每项记录预设键、资料语言、准确来源身份或本次线索、来源响应与版本、必要依赖，以及预计可以采用、明确缺席和需要用户补充的事实。既有公开样本可以复用；合成数据用于构造歧义、缺项和失败，不能代替全部正常来源样本。

| 检查层次 | 固定内容与通过条件 |
| --- | --- |
| 全部预设的配置检查 | 二十八份完整配置均通过字段与能力校验；根对象、相关对象、分部和关系范围对应正确，四种语言的来源顺序与回退符合各自定义 |
| 正常资料链 | 每类 Entry 至少有一个来源已证实具备标题之外资料的正常对象，适用的四语预设采用同一对象及各自响应。完整执行定位、读取、合成、原子采用与重开，兑现样本预先列明的字段和关系；不能仅以取得标题或 provider 返回成功通过 |
| 缺少身份与歧义 | 在既有同一输入上移除对应依据或加入真实同名冲突，结果符合已定匹配规则；不把误合并、重复对象或越界字段写入换算成更高自动成功率 |
| 来源或处理失败 | 共用失败场景验证保留范围，各来源只补充自己的分页、映射或授权差异；完整对象的独立合法部分仍按原合同提交 |
| 用户入口 | 七类对象各贯通原生新增、更新与重开；资料语言选择按同一配置采用，界面不临时修改 provider 顺序或匹配规则 |

正常样本的预期来自已核对的来源事实和正式合同。来源确实缺少的字段可以保持缺席；应该取得却未能对应或采用的字段属于未通过，不能在看到实现结果后改成“允许缺席”。来源内容或接口变化时，另存新响应、解释差异，再更新基准。确认后的缺图等产品限制直接进入相应预期，不反复作为待补功能。

报告分别列出自动采用、需用户补充、允许缺席和实际失败的数量与原因，并保留各语言的结果；比例用于判断预设用途，不建立通用置信度或任意通过百分比。纯映射与共同采用机制复用所属用例，不把二十八份配置乘成二十八套相同的事务、取消和资源测试。真实服务连通与必要账号操作另按来源验收执行，常规 CI 使用固定响应验证已确定语义。

动画四份预设另按[分集对应条件](../../design/domains/metadata-presets/anime.md#episode-correspondence)检查整条采用链：只有 Bangumi 分集身份且 TMDB 缺少匹配所需 type 时，保留合法成员与旧图片，不按同号自动配图；补入已确认的准确 TMDB 分集身份后，可以取得该分集自身图片，分类与本地 ID 保持；成员直接来自 TMDB 时，图片读取也沿其自身身份执行。根作品范围冲突或身份指向其他本地目标时仍失败，不因图片可取得而放宽对应。记录来源读取、对应、图片准备和最终采用各自的结果，局部接口可用不代替整链通过。

A08、A18 和 A27 验证[资料方案删除约束](../../design/domains/metadata-profiles.md#storage)：方案仍被扫描配置引用时拒绝删除，不清空必需外键或自动改用其他方案。用户明确更换引用或删除调用配置后，才可删除方案；已接纳的扫描继续使用固定快照。未被引用的默认方案删除后保留无默认状态，旧草稿或链接再次使用已删除 ID 时明确失败。
