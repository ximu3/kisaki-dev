# Goodreads 当前官方导出核验

核验日期：2026-10-17。用户明确允许添加少量书籍作为测试数据后，使用官网页面添加四个不同书目，并补测其中一个书目的日期精度。共生成五次导出，保留四份有效对照夹具；一次月份编辑未实际保存，已通过回读识别，不将那次重复的年份结果当作月份结论。没有发布书评正文，评分、书架、阅读事实与私人备注均为合成测试值。

[完整结构化结果](2026-10-17-test-results.json)记录校验值、测试输入、反例及清理。文件不含账号 ID、凭据、导出下载凭证或真实私人文字。

## 官方输入与表头

[官方导入／导出页](https://www.goodreads.com/review/import)在空书架时提示先加入书籍，没有导出按钮；加入测试书后出现 Export Library，并生成实际 CSV 下载。官网 sample_export.csv 列在导入说明中，只证明导入格式，不代表当前导出。

实际导出有 23 列，分别是 Book Id、Title、Author、Author l-f、Additional Authors、ISBN、ISBN13、My Rating、Publisher、Binding、Number of Pages、Year Published、Original Publication Year、Date Read、Date Added、Bookshelves、Bookshelves with positions、Exclusive Shelf、My Review、Spoiler、Private Notes、Read Count、Owned Copies。它没有 Average Rating，也没有可靠媒介、作品／单卷类别、Work Id、系列母体、语言或图片字段。

## 字段语义与反例

- My Rating 保留 3.75，未评分导出 0。旧的“只能整数五级评分”判断不适用于当前导出。
- ISBN 保留来源的等号双引号包装；0316371246 的前导零仍在。空值使用空包装，不能当作可执行公式，也不能将 ISBN 不存在解释为书目不存在。
- 私人备注输入包含逗号、双引号与换行；CSV 引号可以正确读取，换行在字段内容中变成 br 元素。My Review 保持空，没有用公开书评做测试。
- Read Count 包含正在进行的阅读记录，不是明确的完成总数。不能按 N 建完成历史，也不能用 N−1 估算过去完成。
- 一条书目具有两次完成记录时，Date Read 只给出一个日期，未保留完整历史。
- 年份和月份缺项在 Date Read 中被补成 1，CSV 不保留原有精度。第一日既可能是真实日期，也可能是来源补值；完整字符串不证明完整精度。
- 当前官网明确列出 read、currently-reading、to-read、did-not-finish 四个默认互斥书架；当前 CSV 使用对应固定值。用户还可以有其他互斥书架，不能按任意名称推断状态。
- Bookshelves 与位置列包含普通书架，也可能包含当前状态书架。普通成员按实际逗号分隔；位置属于书架，不属于作品卷次。
- Date Added 在本次导出中为 2026/10/16，而当前客户端日期为 2026-10-17。它是平台加入日期，不充当完成日期，也不因本机日期不同而被强制改写。

## 清理与证据边界

四个初始测试记录和补充日期记录均已移除，临时评分、私人备注和阅读记录随之清理。最终官网显示 All (0)，四个默认书架均为零。唯一的自建非互斥书架 kisaki-import-test 已经删除，四个默认书架保留。

批量书籍删除与单项标签删除的浏览器原生确认遇到自动操作超时；没有把点击或确认请求当成删除成功。书籍改用逐条的页面确认并逐次核对数量。单项标签删除回读仍存在后，用户在官网仅删除非互斥书架的入口完成确认；当时非互斥书架只有该空测试标签，随后回读确认已移除。核验标签页已关闭，原有用户页面保留。

本次验证了来源实际导出与关键语义，并使用标准 CSV 读取核对列、行、标识与合成内容。它不代表 Kisaki 导入器已经实现；完整交互、本体采用、取消、冲突、复杂书评、更多版本与制品仍按[已确认接入方案](../../../design/extensions/importers/goodreads.md)验收。对象新增与字段采用范围已经确认，完整方案使用所选资料方案原生新增，来源导出的个人数据与明确保留字段分别采用。
