# Markdown 编辑与呈现

`/markdown` 提供源码编辑器、工具栏、编辑命令与预览。正文身份、草稿、附件选择、保存、并发校验和关闭策略由宿主持有。视图可并列放置编辑器和预览，也可将同一草稿交给放大编辑区域。[草稿寿命](../state.md#drafts)

## 编辑事务

编辑器使用 CodeMirror 6，接收初始文本或受控文本，保留原生选择、输入法组合、撤销和扩展机制。工具栏接受宿主提供的动作名称和图标，格式命令与编辑器快捷键使用同一套编辑事务。执行格式化后焦点回到编辑器并保留相应选区。

宿主可以规范化、采用或替换正文。受控更新等待进行中的输入法组合提交，在编辑器处理完原生输入后读取宿主最终值，避免覆盖刚刚确认的文字。相同正文保持原选区和编辑历史。只读状态、可访问名称和编辑扩展跟随实例更新。实例卸载时销毁编辑器、撤销订阅，并通知持有引用的调用方该引用已经失效。[CodeMirror 模块与生命周期](https://codemirror.net/docs/guide/)

## 预览与资源

预览用 markdown-it 15.0.3，任务列表与脚注分别采用 `@mdit/plugin-tasklist` 1.1.4 和 `@mdit/plugin-footnote` 1.1.3。支持 Markdown、表格、任务列表、脚注、自动链接、软换行和标点转换。原始 HTML 按文本显示。任务勾选状态由源码决定。预览实例为任务标签和脚注链接分配独立标识，页内跳转落在同一实例内。[Markdown 安全策略](https://github.com/markdown-it/markdown-it/blob/master/docs/safety.md) · [任务列表](https://mdit-plugins.github.io/tasklist.html) · [脚注](https://mdit-plugins.github.io/footnote.html)

正文里的图片地址先交给宿主映射。只有宿主已经取得并授权的 URL 才成为图片请求，未映射时在原位置显示替代文字。普通内容链接经渲染器校验后可以交给宿主导航。文档内容和已渲染节点随组件更新和卸载释放，映射、占用与 URL 撤销由资源拥有者负责。
