# libmpv-node 验收

A11、A23、A28 和 A33 验证绑定、原生资源、画面交接与最终包消费。共同交付条件见[独立项目联合交付](projects.md)，具体行为由[调用](../../design/projects/libmpv-node/api.md)、[值](../../design/projects/libmpv-node/values.md)、[通知](../../design/projects/libmpv-node/notifications.md)、[运行寿命](../../design/projects/libmpv-node/lifecycle.md)和[输出](../../design/projects/libmpv-node/video.md)定义。

## 调用、值与通知

createMpv、结构化命令、属性读写与观察、事件和日志订阅、close 使用同一个 Mpv 实例及其资源管理。初始化选项、运行期属性和绑定层渲染配置分别验证；类型提示与通用命令入口语义一致，声明和实际导出与最终构建目录匹配，未知名称不靠泛型伪造结果。

属性不可用与合法的 false、0、空字符串分别表达。转换失败保留同次原生结果和稳定错误字段，通知不通过重读状态归因。字节数据与结果不借用已释放内存，整数不静默丢失精度，原生错误可以按类型或原因判断。事件与日志文本按各自结构交付。

覆盖创建取消、终止竞争、回调中关闭、同步异常与异步上下文：请求和登记关联正确，跨线程结果完整交付，未完成请求有确定结局，停止或关闭完成后无新回调，调用方异常不改写为引擎错误。

## 实例与执行资源

实例初始化、loadfile 命令回复与应用内容就绪分别完成。初始化失败释放已取得资源；纯音频及无图形输出的调用不创建图形上下文，受管视频先准备 VideoOutput 再加载内容。播放到末尾保留实例，关闭后拒绝再次加载，渲染上下文先于播放核心销毁。

按[控制执行与运行时交接](../../design/projects/libmpv-node/lifecycle.md)分别核对进程代码映射、核心、原生客户端、Node 环境和已交付结果的持有。运行库常驻，多核心反复创建关闭、Worker 退出与其他实例继续运行各自成立；辅助客户端先于核心销毁。已提交回复仍须消费并释放，环境退出完成原生清理。

对请求、属性、事件、日志、hook 和帧积压验证各自接纳、合并、缺口与终止。队列预算同时限制条目和字节，终止与清理不等待普通队列腾位；真实负载形成内部容量基准。并发压力、回调与环境退出使用实际 addon 验收，结果按实际输入和运行范围判定。

自定义流覆盖读取、定位、取消、迟到打开和释放失败，核对[实际字节、同核心重入限制、原生等待解除与收尾](../../design/projects/libmpv-node/streams.md)。

## 应用加载与操作交错

分别观察命令回复、文件加载、定位完成和画面可用。Kisaki 的 media 组合完整加载、初始定位与就绪、定位完成和内容采集；绑定不承载高层 open、seek 或 captureImage 流程。screenshot-raw 保持上游图像结果含义，media 关联紧邻的实际位置和文件，sessions 核对作品归属。

media 完整操作与命令、脚本交错时，状态始终取自实际引擎反馈。新内容事件不完成旧内容等待，旧回调不写入新上下文；受管资源确有约束的直接请求按有依据的范围失败。命令或脚本关闭同样被绑定识别并收尾，内容替换使旧等待失效，各入口使用同一实例和事实。

## 颜色、截图与显示

截图来源标记分别覆盖正常 VO、显式软件与 screenshot-sw=no 下的 VO 取图失败回退。实际 source 与同次字节路径一致，VO 回退为 software 时本体在图片准备前返回 CaptureUnavailable；不因命令成功或 no 选项而接纳。来源字段缺失或未知同样拒绝。普通与 native 结果都保留该字段，原图尺寸、字幕与独立字节仍按原合同验证；测试注入不进入正式构建。

按[当前 SDR 范围](../../design/projects/libmpv-node/video.md#targets)验证 Kisaki 的 sRGB 和库的 Display P3 SDR。覆盖普通 SDR、十位 SDR、HDR 片源到 SDR 的色调与色域映射、复杂动态字幕、抖动和最终显示。HDR 显示、PQ／扩展线性受管帧、显示亮度查询和可变 nit 单位仍在交付范围之外。

截图按[采集条件与路径差异](../../design/engineering/integrations.md#screenshot)核对原生布局、有效行、独立字节、颜色及后续编码。sRGB／Display P3 不能仅从 rgba 格式名推导。Kisaki 正常 GPU 路径采用 screenshot-sw=no，并分别核对 HDR 到 SDR 与字幕；软件对照及上游可能发生的自动回退按实际路径记录，命令成功或选项值不足以证明 GPU 路径已采用。覆盖持续播放、设备失败和实际产品采集。

按[平台画面交接](../../design/projects/libmpv-node/platforms.md)检查像素排列、原色、传递曲线、RGB／full-range、尺寸／stride 和宿主别名，并使用错误颜色标签作为对照。生产完成同步与消费引用回收分别验证。

| 平台    | 画面路径与资源断言                                                                                           |
| ------- | ------------------------------------------------------------------------------------------------------------ |
| Windows | 验证选定 GPU 路线及 NT 句柄在所属进程内的导入、同步、宿主显示和回收                                          |
| macOS   | 验证 CGL／BGRA IOSurface 的池、FBO、完成同步及独立引用；IOSurfaceRef 在所属进程内导入                        |
| Linux   | 验证 GBM 分配、EGL 导入和选定的线性单 plane BGRA dma-buf 路线；核对真实 fd 范围、planes、modifier 与字节排列 |

六个目标分别验证 Render API 到共享纹理、显示及回收。原生资源不能用普通 IPC 克隆代替传输；设备条件缺席时不隐式切换输出模式，显式软件输出按自身合同验证。平台运行范围按[共同交付条件](projects.md#delivery)记录，已有[来源核对](../evidence/platform-closure/closure.md)及图像实验保留各自覆盖范围。

## 帧寿命与关闭

持有 NativeFrame 时改变尺寸、切换内容或关闭 Mpv，既有帧仍有效至持有者 release。Mpv 关闭不等待外部归还，也不靠保留完整 Mpv 维持帧寿命；停止订阅不撤销已交付帧。

慢消费者下队列与资源池保持有界，未交付帧可以丢弃，已交付纹理不得覆盖或强行复用。JavaScript 接收变慢不直接阻塞必要渲染更新或驱动播放时钟。Electron 的单个导入引用释放与 allReferencesReleased 分别成立，全部引用释放后才归还原生帧；核心关闭后已有图像的独立持有和宿主最终归还也分别成立。

Kisaki 继续执行[播放与标注场景](sessions.md#playback)，核对文件一致性、媒体就绪、显示引用回收、完整关闭及记录保存。采集图片在播放器和原生帧释放后仍可独立处理。

## 最终包与运行环境

按[引擎与整包装配](../../design/projects/libmpv-node/distribution.md)验证主包和平台包精确配对，直接与传递媒体依赖、动态模块、字体及非代码资源都有归属，系统接口与可再分发运行库分开。

普通 Node 和 Electron 从最终 tarball 安装并执行原生工作。缺包或版本不配明确失败，不借助开发 PATH、当前目录或开发机残留；核对安装载体中的实际路径、系统与 ABI 下限、宿主已有同名媒体依赖、许可和对应源码。最终验证包含环境退出，候选包或单机清理 PATH 的结果只说明其实际执行范围。
