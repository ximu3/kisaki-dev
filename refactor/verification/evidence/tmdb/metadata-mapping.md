# TMDB 字段与关系的来源核对

2026-10-16，核对官方 v3 OpenAPI 和两份公开贡献规则。该轮没有认证 API 调用；[结构化记录](2026-10-16-metadata-mapping.json)保存来源地址、时间、摘要、接口字段及观察结果。

| 来源事实      | 核对结果                                                               |
| ------------- | ---------------------------------------------------------------------- |
| 影片主日期    | 官方规则优先选院线上映，再考虑首映及其他发布，不必然是全球首次公开日期 |
| 影片片长      | 贡献规则要求原版、含片尾，并向上取整为分钟                             |
| Released 状态 | 贡献规则允许在全球首映前四天自动设置，不足以证明已经发行结束           |
| adult         | 官方含义主要涉及硬核色情，不覆盖所有敏感内容                           |
| 图片集合      | 影片含 posters、backdrops、logos；季含 posters；分集含 stills          |
| credit 详情   | 可含 season_number 与 show_id；TV 署名本身不能证明逐季参与范围         |
| 影片合集      | belongs_to_collection 表达成员关系，不能单独证明前传、续作或重制关系   |

字段、图片和关系如何映射到 Kisaki，由[TMDB 来源设计](../../../design/extensions/sources/tmdb.md#fields)定义。实际公开 API 与游客评分见[接口实测](live-api.md)，本人授权与个人记录见[账号实测](account-api.md)；三类核对分别记录覆盖范围。
