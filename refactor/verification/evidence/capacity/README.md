# 引用集合与扫描报告的容量模型

[脚本](capacity-probe.mjs)与[原始结果](capacity-results.jsonl)保存 2026-10-22 的 Node 合成模型。每个规模在独立进程中运行三次，同时保留源对象、JSON、解析值和克隆值；输入为合成引用或精简扫描报告，不含真实用户数据。

| 模型     |      数量 | JSON 字节数 | 克隆耗时中位数 | 保留堆增量中位数 |
| -------- | --------: | ----------: | -------------: | ---------------: |
| 条目引用 |    10,000 |     610,001 |        4.82 ms |         5.38 MiB |
| 条目引用 |   100,000 |   6,100,001 |       49.30 ms |        52.08 MiB |
| 条目引用 | 1,000,000 |  61,000,001 |      728.32 ms |       448.99 MiB |
| 扫描报告 |     1,000 |     266,860 |        2.98 ms |         2.04 MiB |
| 扫描报告 |    10,000 |   2,687,861 |       26.84 ms |        20.62 MiB |
| 扫描报告 |   100,000 |  27,077,862 |      304.28 ms |       208.85 MiB |

环境为 Node 24.11.1、AMD Ryzen 9 7945HX，其他信息见原始结果。该模型说明复制成本随数量增长，不测量 Electron IPC、真实 SQLite 保存、正式报告或应用峰值。正式性能验收使用设计规定的实际场景。

复现示例：`node --expose-gc capacity-probe.mjs 10000 scan`。输出写到新的结果位置，保留本目录的历史数据。

验收规模与资源处理规则见[性能边界](../../../design/engineering/performance.md)。
