# Bangumi 公开标签与使用统计

本材料复用 2026-10-13 已取得的四项匿名 subject 详情响应，[观察数据](2026-10-13-tags.json)保留相关字段及原始读取时间，不重复执行账号查询。

官方 [v0 schema](https://github.com/bangumi/api/blob/a7055f2dca7286d6963aaa7928345eeca6293e2b/open-api/v0.yaml)将 meta_tags 定义为维基维护的公共标签；tags 中 count 是使用该标签标记当前作品的用户数，total_count 是标签在全部条目中的使用总次数。这两个数量不能互换，也不是本地标签使用数。

《葬送的芙莉莲》的高频用户标签包含治愈、公路片、旅行、寿命论，也包含 MADHouse、2023年10月、斋藤圭一郎等机构、时间和姓名文字。《奇诺之旅》的高频标签同时包含作品名、作者、画师、出版品牌与幻想、旅人等描述。用户标签提供不同于公共分类的内容信息，也不保证只表达题材或风格。

这些样本只证明实际详情返回了上述数据，不表示全部来源记录都有公共标签，也不确立恒定的全站数量上限。搜索摘要与 subject 详情可以返回不同数量的标签，搜索结果不能代替正式字段读取。

本人收藏接口的 tags 属于所连接账号的整理记录，和这两类公开资料分开处理。已确认的[采用规则](../../../design/extensions/sources/bangumi.md#tags)默认合并全部公共标签与当前作品使用人数排名前十的用户标签，允许关闭用户标签或调整数量。标签名字不直接证明人物、组织或作品之间的结构化关系。
