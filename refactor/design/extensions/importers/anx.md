# Anx Reader Importer 接入方案

Anx Reader 导入器迁入作品资料、本人记录、分组、文字、文件与可准确转换的位置。输入基线为 [v1.14.0](https://github.com/Anxcye/anx-reader/releases/tag/v1.14.0)、提交 356b7183e8463e7c60d84a72502d0055e55a19fd、数据库 schema 7；格式与转换依据见[源码及合成核验](../../../verification/evidence/anx-importer/source-and-fixtures.md)。

<a id="scope"></a>

## 用途与输入

提供一个本地手动迁移页面，处理用户选中的漫画、小说及相关文字。类型由实际作品范围决定，不能按 EPUB、PDF 或文件夹猜测；源书库中的其他书籍不自动变成 ACGN 作品。导入器不注册资料 provider、不登录 Anx／WebDAV、不持续同步，也不恢复源应用。

| 输入方式   | 本项范围                                                                                              |
| ---------- | ----------------------------------------------------------------------------------------------------- |
| 书库数据库 | 源程序关闭后取得的一致 app_database.db，或已下载到本地的官方 WebDAV database7.db 快照；媒体根另行选择 |
| 笔记 CSV   | 官方九列表头的 GBK 文件，逐条保留所选摘录、用户批注与上下文；没有 CFI 的记录不恢复定位                |
| 文字导出   | 官方 UTF-8 Markdown／TXT，整份文件迁为一篇普通 Note，不反向拆解为伪造的原笔记记录                     |

数据库必须有合法 SQLite 头、user_version=7 以及本项使用的真实表与必要列。应用版本名和文件名都不是单独的识别依据；不把所有同名 .db、任意 JSON、旧 schema、插件私有库或未经声明的 ZIP 当作输入。当前没有据此承诺官方全库 ZIP 家族。

源上传代码使用 VACUUM INTO 等方式准备同步快照；导入器只接收用户提供的已有副本，不调用源备份函数、不进行同步、不修补数据库头。直接复制仍在变化的主库而遗漏 WAL，不属于一致输入。多份本地／远端库由用户明确择一，本项不承担它们之间的冲突合并。

<a id="reading"></a>

## 读取边界与源键

数据库通过只读连接查询，启用 query_only、关闭 trusted_schema，不装载扩展，不执行来源触发器、升级代码或修复操作。按预算限制数据库、行数、字段长度、正文和媒体解析；错误只保留有界标识和安全原因，不输出整行或私人文字。

读取 tb_books、tb_notes、tb_reading_time、tb_groups，以及下文指定的 tb_styles 标记行。tb_themes、普通字体样式、偏好、AI 供应商、聊天记录、账号和同步凭据不迁入。必要结构无效在写入前拒绝；已识别结构内独立可选值无效只影响该字段，不清除本体资料。

Book.id、Note.id、Group.id 与计时行 id 只在本次源库内关联，不写入公开 external ID。整数源键按实际精度处理，不先转为会舍入的 JavaScript Number；源键与本体引用的对应按[批次进度](../importers.md#repeat)保存，继续批次复用，任务结束不清除。失联记录不能按标题、行号、书名文件或相似文字重新猜主人。

is_deleted=1 的书目默认排除，用户可另选已删除范围；源删除不在本体重放。源行的有效删除状态与状态未知分开，不能把异常值当作明确的未删除。缺少媒体的云端书目仍可有合法资料、评分、笔记和累计时间。

<a id="identity"></a>

## 作品与资料采用

本次明确的本地 Work／Part、实际已登记文件的归属与完整公开身份用于对应。同名不自动合并；有冲突的对应报告失败。单卷、合订本与整部作品先核对范围；源书目、分组、EPUB 目录和页数不生成本体卷话结构。

没有本地对应时，按本次选定的 Comic 或 Novel 类型，以来源中可准确解释的名称和普通字段形成 prepared 输入，调用 ingest.add 完成本地新增。选定的评分、初始完成事实与附加时长随 initial 采用；已有对象默认保留本地值。最低资料不足的项目报告未迁入，联网补充由用户在导入后另外选择，不作为创建前提。

来源普通资料默认选中，新对象直接采用已知的 name、description、实际本地封面与其他已声明字段；已有对象只有明确选择补空或覆盖时才通过 prepared 更新。缺项保持未知。author 作为署名文字，可保留在来源资料 Note 中，不仅凭人名创建人物关系。Book 没有本项可直接使用的公开书目身份或发行日期。

create_time 是源书目的建立时间，可以单独选择采用加入日期；保留实际日期精度，带偏移的值按本次选定来源时区取日历日。update_time、源文件修改时间、笔记时间与最后位置不作为作品完成时间或最近使用。本体技术 created_at／updated_at 仍使用实际保存时刻。

file_md5 按生成时的真实含义辅助本次文件核对：TXT 导入先对原文件计算 MD5，再转换并保存 EPUB；之后的批量重算可能改为现存文件摘要。位置恢复依据明确源路径、实际文件归属与文档结构，摘要在含义对应时参与比对。TXT 原摘要与转换后的 EPUB 摘要分别解释，作品仍通过正式身份对应。

<a id="personal"></a>

## 本人评分、完成事实与累计阅读时间

源评分界面使用五颗星并允许半星。有效正评分按五分尺度乘 20，采用为本体 0–100 整数；3.5 星对应 70。0 和数据库中的正常 null 表示未评分；非法类型、越界与非有限值不钳制。已有对象的评分默认保留，明确采用源未评分时才清除。

Book 没有独立特别喜爱或当前安排字段，书库成员、分组与名为“喜欢”的标签都不据此生成这些值，也不把中间进度写成 active。

本接入采用源“已读”判定 reading_percentage>=0.98 作为至少完成过一次的来源事实。只有合法、有限且在 0–1 范围内的比例参与判断，不把显示四舍五入、未知值或越界值当成达到阈值。选择采用完成事实，且来源范围确为整部 Work 时，新作品随 initial 初始化一条未知日期完成记录；已有作品仅在历史为空时使用 expected.completionCount: 0 创建一条，非空历史保留。

来源对应单卷等准确 Part 时，只设置该分部完成标记；范围未知时不提升为整部完成。同一 Work 的多个已读来源书目只提供一次最低事实，不按文件数增加完成次数。低于阈值不删除已有历史，记录采用也不清除当前状态、补造末页或开始活动。该源判定没有逐次历史或完成日期，不将书目修改日、计时日或导入日填为完成日，也不声称逐页读完；CSV 与文字导出没有这个比例时不推断已读。

tb_reading_time.reading_time 保存秒。源代码按 book_id 和日历日累加，模型 startedAt 只是对 date 的读取解释；即使 date 有时间部分，也没有完整的逐次起止区间。本项不生成 Activity，也不推算“最后时间减累计量”。

用户可选择采用累计阅读时长。对所选书目，按真实计时行 id 读取有效非负整数秒，安全换算为毫秒后归集。相同日期的不同合法行都参与源 SUM 口径，不擅自按日期去重；日期无效不使独立有效的累计秒数失效。计时数据整体缺席是未知，明确的零正常采用；非法时长和归集溢出分别报告。

多个所选源书籍归属同一 Work 时，先归集已明确的独立时间范围，再进行一次 Work 总量采用，不逐卷覆盖附加值。采用遵守[共同附加时长合同](../../domains/records.md#duration)：新对象采用选定初值；已有对象明确采用时，将附加绝对值设为来源总量减去本次已保存实际活动量，不再叠加旧附加值。来源总量较小不删除活动或生成负数。

附加时长计入作品累计阅读时间，不进入日期图表、热力图、单次统计或最近使用，也不创建阅读概况笔记。它归属 Work，不要求已有准确 Part，但不生成分部附加时长或完成标记。

<a id="organization"></a>

## 层级分组与标签

tb_groups 保存真实分组及 parent_id；tb_books.group_id 是书籍直接所属分组。id=0 的 Root 是内部根，不创建同名合集。用户选中的实际分组各迁为一个普通手动 Collection，用完整可读祖先路径区分同名末级分组，不能按名称合并来源 ID。

每个合集只采用该组的直接书籍成员，不再把全部子组成员重复塞入父组；层级没有被声称恢复为本体嵌套合集。源组有循环、父组失联或所需祖先已删除时，报告相关整理无法完整采用，不猜父级，也不阻止独立作品或文字迁入。

源表没有独立手动成员序号，不把 update_time 排序或当前视图筛选当作人工顺序。采用明确、稳定的源键顺序处理新成员；若复用用户明确选定的已有合集，保留已有成员位置，新成员按本次顺序追加。真实空组可迁入，因选择范围或失败产生的缺成员分别说明。

Anx 的标签并不位于独立 tags 表，而是占用 tb_styles 的标记行：

| 来源形状                                         | 含义与采用                                                        |
| ------------------------------------------------ | ----------------------------------------------------------------- |
| abs(font_size−1.0)<0.0001 且 font_family 非 null | font_family 是标签名称，可迁为普通作品标签                        |
| abs(font_size−2.0)<0.0001                        | line_height 是源书籍 ID，letter_spacing 是源标签 ID，构成标签关系 |
| 其他 tb_styles 行                                | 普通样式，不迁为标签或恢复阅读配置                                |

标签关系中的 REAL 值必须是精确、安全的整数，并指向本次合法对象；不复制源 SQL 的截断 CAST 来把 1.5 关联到书籍 1。过大、失真或失联引用只影响对应关系；重复关系按本体普通规则归为一个成员。源标签颜色不转换为标注颜色，标签名也不推断状态、评分或卷结构。

<a id="notes"></a>

## 摘录、批注与独立文字

tb_notes 同时保存 highlight、underline 和 bookmark。前两者的 content 是摘录，reader_note 是用户普通文字，源界面按 Text 显示；迁入时保留字面标点、换行和有意义空格，安全转为本体 Markdown，不擅自把原来的星号等解释为格式。source cfi 描述位置，不能以 content 的首次出现替代它。

位置准确对应同一实际文件时，建立一条 Annotation：quote 保留来源摘录或书签文字，content 保留用户批注。书签属于点位，不因为有文字就创建高亮范围；bookmark 的 color 实际保存进度字符串，不是 RGB 颜色。高亮与下划线均使用本体统一标记样式，不增加逐条颜色字段。

缺文件、CFI 无法解释或定位不受支持时，已选文字迁为普通 Note，并关联已经明确的 Work，结果说明定位未迁入。不同时创建同内容 Note 和 Annotation。只有位置而没有可保留文字的失败项不造空笔记；失联书籍不通过文字相似度猜归属。

未知 type 的文字可以在本次明确选择后作为来源文字 Note 保存，并报告该种类没有解释为标注；不丢弃已有 content／reader_note，也不伪装其位置已恢复。create_time、update_time 与 chapter 可作为选定的可读上下文，非法时间保持未知，不使用导入当天补齐来源时间。

官方 CSV 的字段依次为 Book、Author、Chapter、Content、Reader Note、Type、Color、Create Time、Update Time。按 GBK 严格解码并使用标准 CSV 引号规则，保留中文、逗号、双引号、换行和公式前缀的字面文字。它没有 Book.id、Note.id、MD5 或 CFI，因此不能恢复标注位置，也不按相同正文把两行合并。

CSV 的 Book 提供书名，Author 保留实际署名文字；用户也可在执行前明确已有作品。只有可解释的真实书目范围才新增 Work；仅为保存文字时可以选择不关联作品，不创建 Unknown book 或文件名占位作品。CSV 不携带书库分组、评分或累计时间，不从导出日期猜这些数据。

Markdown 与 TXT 是展示性导出，合并章节标题会改变正文结构；TXT 正文甚至不包含书名。它们只按整份文件建立一篇 Note：Markdown 使用本体安全正文边界，TXT 保留普通文字；关联作品由用户明确选择。章节标题、缩进和引用符不用于重建虚构记录 ID、笔记数量或 CFI，也不从导出中的链接自动下载资源。

<a id="files"></a>

## 实际文件与封面

按照源记录中的 file_path、cover_path 与用户选择的数据根定位，默认布局分别是 file/ 与 cover/。同步数据库下载目录未必就是媒体根，不能自动将两者混为一处。旧绝对路径只通过明确根映射解释，授权范围外、穿越、链接逃逸及多个候选均不能擅自采用。

已有媒体默认原位登记；用户也可以明确选择持久内容目录后复制，不能覆盖已有不同文件或把临时读取目录登记为 holdings。真实格式、可读性和作品归属由正常文件操作核验，缺失资源不制造有效记录，也不自动访问云端下载。

封面先核验实际图片内容，再通过 attachments 接收并取得正式附件身份。未知、损坏或含主动内容的输入按图片问题报告，已成功迁入的资料与文字保持。资产采用范围为选定的作品资源，源软件缓存、字体、背景和 AI 临时文件保持在迁移范围之外。

## CFI、固定页面与转换范围

Anx 的 Foliate 接入对不同格式使用不同地址。必须先核对实际文件种类、源地址系列及目标归属，再选择适配；不能把所有 epubcfi(...) 字符串都理解为真实 EPUB 包地址。

| 实际文档与来源地址                                        | 本项转换                                                                                         |
| --------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| EPUB 的包／正文点位或范围 CFI                             | 按实际 OPF、spine、正文节点与 UTF-16 边界解析，重新编码为本体 epubCfi 锚点；范围保留完整起止端点 |
| 明确固定版式 EPUB 的包内页地址                            | 核对 rendition 与具体 itemref，转为实际 epubSpineItem 页起点                                     |
| PDF 的裸合成 CFI，例如 epubcfi(/6/4)                      | 源固定布局不保存页内范围，该值表示零基第 1 页；核对实际 PDF 后转为 pageIndex 页起点              |
| CBZ 的裸合成 CFI                                          | 重建源页列表，将索引转为明确 memberPath 页起点                                                   |
| PDF 文字选区中的正文 CFI、MOBI／AZW3／FB2 等生成 DOM 地址 | 不冒充 PDF 几何或原始格式锚点；本项保留所选文字，不恢复这些高亮范围                              |

EPUB 适配核对 package 与 spine 归属、ID 断言、实际正文、点位或范围次序和文本边界，不执行书内脚本或源阅读器。相邻文字与 CDATA 按源 CFI 的逻辑文字段解释，UTF-16 offset 不能切开代理对；有摘录时用已保存文字核对实际内容。生成的翻译、临时包装、源码修复或缺失资源导致地址无法对应原文时，报告定位未迁入，不搜索首个相同句子或按百分比插值。

本项处理源当前生成的元素／文字点位与范围；未验证的 CFI 空间、时间扩展不套为文字 offset，也不借源 parser 的宽松解析接受非法地址。

源库可能含没有正文间接段的合成 CFI。PDF 中 /6/4 的第二个数字只是编码后的页面索引，不是 EPUB 第二项；源固定布局通过 range=null 生成这类地址。带有正文片段的 PDF 高亮则指向生成的文本层，数据库没有原 PDF quad，本项不将文本层 offset 转成虚构页面选区。

CBZ 源页列表对完整成员名按 JavaScript 字符串顺序排序，过滤扩展名区分大小写。支持的源后缀为 .jpg、.jpeg、.png、.gif、.bmp、.webp、.svg、.jxl、.avif；例如 1.png、10.png、2.png 依此排序，.PNG 可能没有进入源页列表。不能用自然排序替代，也不能先删掉本体不支持的图片格式再套索引；精确成员确认后仍须由本体核验可读性。重名、非法成员或越界索引报告失败，不截到末页。

已经由 Anx 转换并实际保存为 EPUB 的 TXT 可以按那份实际 EPUB 核对，不把其 CFI 解释为原始 TXT 偏移。其他格式可按本体能力独立登记文件，文件登记成功不代表其来源定位已恢复。

续读与 Annotation 分别采用。已有位置默认保留，明确选择后才更新；多个来源位置落于同一文件且矛盾时报告冲突。保存本体位置时进度初值为空，之后由 Kana 计算，不照抄 reading_percentage，不打开阅读器、开始活动、修改首选或生成完成记录。

## 页面与执行

一个页面选择数据库／CSV／文字导出方式、输入、书籍范围、Comic／Novel 类型及本次采用。来源普通资料默认选中，其他本人评分、已读事实、累计时长、分组、标签、文字、书签、文件和续读分别选择；已有值默认保留。导入不要求资料方案，结果可打开普通更新器另行联网补充。

来源标题、输入种类、目标类型、Work／Part 范围、文件状态和结果各占一列，窄宽度横向滚动。需要明确已有作品或合集时，在本次输入范围中完成选择。只在实际需要时显示媒体根、路径映射、持久目录或来源日期时区。

先检查必要结构、源键关系和同一目标的矛盾事实，再组织原生新增／复用、所选来源资料更新、评分、空历史完成事实与附加时长、整理、实际文件、标注与 Note 采用。源库读取与文件、网络准备不放进数据库写入事务；Webview 不直接查询源库或写本体库。

每个完整操作独立提交，取消停止后续工作，关闭页面不取消后台任务。结果区保留新增、更新、未变化、部分完成、跳过、失败和所选内容未迁入的原因；不能用文件已登记掩盖定位失败，也不将未选范围报告为问题。

新建批次、继续未完成步骤与未知提交遵守[共同批次合同](../importers.md#repeat)。同批次保留源键与本地结果对应，继续时不重复已完成的文字或标注；另建批次仍按本次明确选择新增。累计值和最低完成继续遵守各自采用规则。
