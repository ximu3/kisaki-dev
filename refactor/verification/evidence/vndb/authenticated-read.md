# VNDB 授权账号只读核对

核对日期：2026-10-12。使用用户提供的临时令牌，仅请求 authinfo、ulist_labels 和 ulist。共四次请求，全部返回 HTTP 200，没有执行 PATCH、DELETE 或其他远端写入。[证据记录](2026-10-12-authenticated-read.json)只保存请求形态、汇总与判定，不保存令牌、账号 ID、用户名、标签名称或私人记录正文。

## 已观察结果

| 核对项       | 实际结果                                                         | 覆盖范围                                                  |
| ------------ | ---------------------------------------------------------------- | --------------------------------------------------------- |
| 认证与权限   | authinfo 返回合法账号结构，含 listread、listwrite                | 证明本次令牌有效且可读；写权限未使用                      |
| 标签定义     | 8 项内置定义，含 id = 0 的虚拟“无标签”项                         | 私有项仅为该虚拟项，没有自定义或其他私有标签样本          |
| 所需字段查询 | 请求 vote、started、finished、labels.id，返回 0 条、more = false | 证明请求合法及本次 API 清单为空，不证明实际字段值已经核对 |
| 最小查询确认 | 仅请求默认身份字段并计数，count = 0、more = false                | 空结果与所选记录字段无关                                  |

完整读取本次空 API 清单不等于遍历了所有网站占位项，也不证明账号从未保存过记录。来源对已删除 VN 的省略继续遵守[读取范围](../../../design/extensions/sources/vndb.md#account-reading)。私有虚拟标签的出现，不能冒充已经验证了用户自建私有标签或私有作品记录。

## 尚未覆盖

该账号没有可读取的作品记录，因而本次未覆盖实际状态组合、评分和日期值、私有记录、下一页、明确 VN 身份分批读取，以及写入后的回读与可见性。没有用空数组上的校验结果宣称这些场景通过，也没有为获得样本而自动创建记录。

后续可改用已有记录的账号继续只读，或由用户准备测试记录。创建、修改和删除远端测试记录需要另外明确对象与字段范围；本次令牌具有 listwrite 并不扩大先前只读授权。完整扩展运行、SDK 与本地持久化仍需在实现后验收。

后续用户另行授权三部指定作品的临时测试，读写与清理结果见[账号读写验证](account-roundtrip.md)。本文件和对应 JSON 只记录先行的四次只读请求，不混同两个阶段的授权与覆盖范围。
