# Bangumi 作品、单行本与章节范围

验证日期：2026-10-13。使用匿名公开请求核对对象粒度和字段含义，没有连接用户账号或修改平台记录。[记录数据](2026-10-13-subject-scope.json)保留 20 次成功请求的参数、时间、状态码和相关响应字段投影；没有将投影称为完整原始响应。

采用的 [v0 API 合同](https://github.com/bangumi/api/blob/a7055f2dca7286d6963aaa7928345eeca6293e2b/open-api/v0.yaml)及其内容摘要记录在数据文件中。请求使用包含开发者、应用和项目地址的 User-Agent，遵守[来源要求](https://github.com/bangumi/api/blob/master/docs-raw/user%20agent.md)。

## 搜索与书籍对象

四次 POST /v0/search/subjects 分别搜索奇诺之旅、我想吃掉你的胰脏、四叶妹妹和葬送的芙莉莲。使用 sort = match，书籍限定 type = 1，动画限定 type = 2；每次读取首段八项。搜索样本不代表全部候选已经读取，也不用于证明唯一匹配。

API 将 series 定义为是否属于书籍系列主条目。实际样本如下：

| subject ID | 资料对象                   | platform | series | 相关记录                                 |
| ---------- | -------------------------- | -------- | ------ | ---------------------------------------- |
| 13911      | 奇诺之旅小说               | 小说     | true   | 24 项单行本关系                          |
| 7853       | 奇诺之旅第 1 卷            | 小说     | false  | 系列关系指向 13911                       |
| 141797     | 我想吃掉你的胰脏，独立小说 | 小说     | false  | 没有系列关系；有漫画、动画及真人改编关系 |
| 10086      | 四叶妹妹漫画               | 漫画     | true   | 16 项单行本关系                          |
| 56575      | 四叶妹妹第 1 卷            | 漫画     | false  | 系列关系指向 10086                       |

series = false 不能单独证明记录是卷。相同的 subject 资源类型既用于整部作品，也用于单行本；采用时需要结合书籍分类与实际关系。独立小说没有系列父项，也不因此需要补造一卷。上述数量是这次接口返回的关系项数量，不证明作品最终会出版多少卷。

本体已有的 [Novel 与卷](../../../design/domains/novels.md#model)、[Comic 与卷话](../../../design/domains/comics.md)可以分别容纳这些对象。单行本来源身份属于实际 Part，不应同时作为整部作品的身份。[来源采用](../../../design/extensions/sources/bangumi.md#identities)明确将没有系列归属的非系列小说与漫画作为独立作品；这是采用约定，本次样本本身不证明所有缺少关系的书籍都是独立作品。来源搜索保留根 Entry 范围，不将命中的单卷替换为父作品。

## 动画与章节分类

subject/400602 与 subject/515759 分别对应《葬送的芙莉莲》第一季和第二季，接口提供续集与前传关系；它们不是同一个来源条目中的季字段。

第一季详情的 eps 为 28，total_episodes 为 36。对 /v0/episodes 使用 limit = 20，读取 offset = 0 和 offset = 20，得到 20 项和 16 项，36 个 ID 均不重复：

| 来源章节 type | 来源名称 | 本次数量 |
| ------------- | -------- | -------- |
| 0             | 本篇     | 28       |
| 1             | SP       | 3        |
| 2             | OP       | 2        |
| 3             | ED       | 3        |

total_episodes 包含这次返回的不同章节类别，不能直接作为正片集数。两个分页覆盖本次声明的全部 36 项；该验证没有改变任何完成标记。

[episode/1253227](https://bgm.tv/ep/1253227) 被来源归为 SP，其简介明确描述的是正式开播前的声优谈话节目，穿插制作资料和音乐录制内容。该条是“SP 不一定表示剧情特别篇”的实际反例。其他两个 SP 的简介为空，本材料不根据标题替它们补出已确定的内容分类。

本体区分[正式分集与附加内容](../../../design/domains/anime.md#model)。[来源采用约定](../../../design/extensions/sources/bangumi.md#parts)将 type = 1 默认作为特别篇，接受它与真实内容可能不同，由普通种类更正处理；不建立自由文本分类器或来源例外名单。用户更正后，资料刷新保留本地种类与对象身份。

## 个人记录的已知接口边界

本节来自公开 schema 核对，没有执行本人记录读取或写入。

- 作品收藏状态使用 1–5，分别表达想看、看过、在看、搁置和抛弃。没有独立的空状态值。
- UserSubjectCollection 提供评分、状态、卷话进度、评论、标签、可见性和 updated_at，没有完成日期字段。合同明确 updated_at 不是条目的收藏时间，不能用它生成一次完成日期。
- 当前 schema 在 /v0/users/-/collections/{subject_id} 上定义 POST 和 PATCH；所选状态字段只能写入其实际枚举值。缺少状态参数表示不修改，不能当作清空。
- rate 的 0 表示删除评分，与本体的有效 0 分含义不同。具体分制采用继续遵守[同步合同](../../../design/extensions/synchronization.md#ratings)。

作品与分部的本人记录必须先对应到正确对象。单行本的读完事实只能支持相应卷的完成标记，不能据此新增整部作品完成记录；单卷评分也不能直接成为整部作品评分。这是现有[作品与分部边界](../../../design/domains/records.md#parts)在来源采用中的要求。

## 验证范围

本材料证明上述公开样本与 schema 字段，不表示完整 Bangumi 扩展、所有书籍关系、所有章节类别或账号流程已经通过验收。没有读取私有收藏、取得账号凭据、下载图片字节或测试平台写入；来源角色、配音、人员职责和其余字段仍需分别核对。
