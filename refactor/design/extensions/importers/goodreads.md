# Goodreads Importer 接入方案

Goodreads 导入器读取官方 Library Export CSV，迁入明确作品、本人记录、所选文字与书架。23 列导出中的评分、书架、阅读计数、日期和私人备注按下述规则采用，格式依据见[真实导出核验](../../../verification/evidence/goodreads-importer/live-export.md)。

<a id="scope"></a>

## 用途与对象范围

读取本地 CSV 进行手动迁移，新作品按[共同流程](../importers.md#flow)直接采用有效来源资料。不提供 Goodreads 账号连接、自建公开搜索、自动导入、持续同步或远端写入。只登记一个导入页面，不注册 metadata provider，不改变公共 Entry 搜索合同。

已绑定且范围一致的 Goodreads Book Id 或规范 ISBN 可以对应已有 Comic、Novel、ComicVolume 或 NovelVolume。查询全部有效身份，出现类型、归属或多目标冲突时报告，不取首项或按名称合并。Book Id 标识书目，不能由其数值或标题推导整作、版本或所属作品。

用户选择要导入的行，为新作品选择漫画或小说，类型可以批量设置且没有默认值。已有准确对应对象正常复用；未匹配的独立作品以合法来源身份、名称及其他已知字段形成 prepared 候选。已有类型与归属不改变，卷归属不明的项目报告问题。范围选择由普通导入页承担，不增加书目候选类型或 Part 搜索。

CSV 没有可靠媒介、内容粒度、作品母体或系列身份。标题中的 Vol.、#1、Book 1 不能成为归属算法；《我想吃掉你的胰脏》的独立小说也带有作者作品集的 Book 1 后缀。分卷长篇的单册只处理已有准确对应的卷，不由单册新建母体或目录。非虚构、工具书、音乐及范围不明的条目不以 Novel 兜底。

<a id="input"></a>

## 输入合同与身份

支持下述 Goodreads Library Export CSV 表头系列，不承接官网用于导入 Goodreads 的 14 列示例。输入至少包含 Book Id、Title、Exclusive Shelf；其他已知列缺席按未知处理。按列名读取，不依赖顺序；未知列说明未采用，重复表头、破损引号或无法可靠分行在写入前拒绝。

采用普通依赖 [csv-parse](https://csv.js.org/parse/)进行流式读取，支持 UTF-8 与 UTF-8 BOM、标准 CSV 引号、逗号和带引号的换行。字段值先保持文本，再由对应语义解析；不让 CSV 库自动把标识、日期、评分和正文全部转换为数字。正文保留有效空白，文件与单字段限制沿宿主既有边界，输入文件始终只读。

Goodreads 身份使用 source=goodreads、sourceId=book/<规范十进制 Book Id>，保留字符串精度；普通外链为该真实 book ID 的官网书目页。CSV 不提供 Work Id，不构造系列身份。ISBN 与 ISBN13 仅识别普通文本或严格的等号双引号包装；空包装表示未提供。只拆包和校验，不执行公式、补丢失的前导零或猜测编号。ISBN-10 校验后转为规范 ISBN-13，按 isbn 来源合同读取与绑定。

当前 CSV 中相同书目只有一行。重复 Book Id 或多个来源行对应同一本地目标时，先核对冲突；个人值不一致不能按行序覆盖。本次完成事实初始化以 Work 为单位至多一次，不能把版本记录的行数当完成次数。没有有效身份的行不能参与自动对应；新建按所选作品类型及本体必需资料执行。

<a id="fields"></a>

## 23 个字段的采用

CSV 中可准确映射的名称、出版信息和页数默认选入来源资料；对象范围一致且满足本体字段含义时采用。评分、状态、阅读事实、文字和书架分别选择。新作品不依赖在线资料获取，已有资料默认保留，联网补充另行发起。

| 来源列                     | 采用规则                                                                                           |
| -------------------------- | -------------------------------------------------------------------------------------------------- |
| Book Id                    | 当前真实书目的 Goodreads 身份及普通出处，按上述对象范围处理                                        |
| Title                      | 原生定位的名称线索；用户选择保留名称时写入同范围对象，不制造母体名称                               |
| Author                     | 用于来源行说明，不只凭名字创建人物或作者关系                                                       |
| Author l-f                 | 来源排序显示，不成为人物别名或另一份作者资料                                                       |
| Additional Authors         | 可能混合插画、翻译等参与；不按姓名列表推导职责与主体类型                                           |
| ISBN                       | 校验实际出版物标识，规范为 ISBN-13；空值不使已有身份消失                                           |
| ISBN13                     | 同上；与 ISBN 不一致时报告身份冲突，不选其中一个掩盖问题                                           |
| My Rating                  | 0 表示未评分；有效 0.25–5 星按 0.25 步进读取，乘 20 转为本体评分，3.75 星为 75；仅 Work 有同义评价 |
| Publisher                  | 来源出版者文字，不建立组织或原作出版关系                                                           |
| Binding                    | 出版载体说明；不变成作品类型、拥有事实或本地文件                                                   |
| Number of Pages            | 用户选择保留页数且范围一致时采用，不分摊给卷、话或文件                                             |
| Year Published             | 当前版本年份，不覆盖原作首次发行日期                                                               |
| Original Publication Year  | 用户选择保留发行日期且范围一致时采用来源年份，不补月日                                             |
| Date Read                  | 合法完整日期按导出值采用；缺失或非法值留空，完成事实按下节独立判断                                 |
| Date Added                 | 平台加入日期，不当完成、发行或本地技术创建时间                                                     |
| Bookshelves                | 已选择的普通书架组织；四个固定状态沿 Exclusive Shelf 处理                                          |
| Bookshelves with positions | 核对与实际书架名称一致后保留相对成员顺序，不把序位当卷号                                           |
| Exclusive Shelf            | 使用实际固定枚举映射当前安排与已读事实，见下节                                                     |
| My Review                  | 用户选择后创建独立 Note，不当作品简介                                                              |
| Spoiler                    | 不改写作品 isSpoiler；输入中的评论标记没有本体同义字段时在结果中说明                               |
| Private Notes              | 用户选择后单独创建私人 Note，与公开书评保持区别                                                    |
| Read Count                 | 不能当完成次数；保留在导入结果说明中，不生成 N 条或 N−1 条完成记录                                 |
| Owned Copies               | 不生成 holdings、文件位置、拥有版本或空目录                                                        |

评分、当前状态和特别喜爱不能附着到 Part。已有卷只能采用适用资料、明确完成标记及所选文字；卷评分不提升为整作评分。CSV 没有同义的特别喜爱标记，书架叫 favorites 也不自动提供该值。

<a id="records"></a>

## 当前安排、阅读计数与日期

Exclusive Shelf 中，to-read 对应 planned，currently-reading 对应 active，read 对应 null，并独立表达至少一次读过。did-not-finish 表达弃读，没有同义的本地当前安排；报告该状态未采用，保留本地安排与既有完成历史，遵守[共同状态映射](../synchronization.md#import)。其他自定义 exclusive shelf 保留来源组织含义。

Read Count 包含尚在进行的阅读记录。例如 to-read、Read Count=0 的书改为 currently-reading 后，导出可为 Read Count=1 而 Date Read 仍为空，见[计数核验](../../../verification/evidence/goodreads-importer/live-export.md)。它不能用于完成总数迁移，即使当前书架是 read，也不能由 N 推出此前每条阅读记录都已完成。

Date Read 只导出一个日期，不能恢复全部逐次记录。已读状态或有效非空的完成日期可以说明存在完成事实；本地没有历史且用户选择采用时，至多初始化一条记录，已有历史默认保留。CSV 不提供足以支持逐条历史追加的明细，本扩展不提供“追加 N 次完成”。Part 只采用明确读过的布尔事实，不保存次数或日期，也不由 currently-reading 或正数 Read Count 推出完成。

Date Read 按 CSV 提供的完整年月日解析为 CalendarDate，合法值直接采用，包括每月第一日。缺失或非法日期保持 null，完成事实独立采用；非法值按实际字段格式错误报告。日期采用不生成精度提示、额外确认或记录备注。来源补齐月日的实际行为保留在[核验记录](../../../verification/evidence/goodreads-importer/live-export.md)中。

已有对象采用来源当前个人值需要用户明确选中，0、null 和缺项按各自含义处理。完成初始化沿共同的 expected.completionCount=0 基线提交；来源评分、状态和历史分别采用，不能为迁入历史清除当前状态或覆盖已有记录。

<a id="notes-shelves"></a>

## 文字与书架

My Review 与 Private Notes 分别创建 Note，标题说明来源及书目；原始文字经共同安全 HTML→Markdown 边界转换。已验证的私人备注会把换行序列化为 br 元素，逗号与双引号通过标准 CSV 转义保留；不能将它按纯文本原样显示为 HTML，也不能执行其标签或脚本。输入不包含图片字节，远端图片只能保留为安全来源链接并报告未迁入附件，不在本地迁移中隐式联网取图。

Note 关联 Entry。单卷文字关联已有所属作品，并在标题或正文保留卷名与来源范围，作为该卷的笔记呈现。只有实际正文才创建笔记，创建时间使用本地写入时间。原批次继续时跳过已完成文字，另建批次可以明确追加。

书架采用默认关闭，由用户选择迁为手动合集或普通标签；固定状态书架不重复生成组织项。书架名称不隐含评分、喜爱或阅读状态。已有同名合集不自动视为同一对象，用户可以选已有目标或在本批次创建，实际对应随批次进度保存，继续时复用。

Bookshelves 按已验证的逗号分隔表示读取，不沿用旧导入示例的空格分隔。位置列中的名称须与成员字段一致；只保留明确顺序，不能从缺席或重复位置补出成员。新集合依来源相对顺序排列，已有集合保留既有顺序并增补所选成员，不持续镜像远端书架。

<a id="interface"></a>

## 页面、默认值与执行

一个导入页面组织输入、选择、执行与结果。读取 CSV 后显示实际列和行数，用户选择对象、新增类型、来源资料、评分／阅读事实、书评、私人备注和书架。来源普通资料、评分与阅读事实默认选中，文字与书架另选；已有值默认保留。导入无需资料方案，结果可另行打开普通资料更新器。新建与继续批次遵守共同合同。

列表将名称、作者、ISBN、来源书架、对应目标、对象范围和处理结果各放在独立列中，窄宽度使用横向滚动。用户读取输入、选择范围后，直接开始完整迁移任务。

新作品使用 ingest 的 prepared 输入与独立 initial，采用有效来源字段并共同提交初始个人值。已有对象核对身份与归属后，按明确选择更新字段、个人值或历史；Note 与合集使用各自完整操作。缺少类型或卷归属、身份冲突、Part 无同义值与格式失败分别报告，其他独立项目继续。取消保留已提交对象，继续原批次不重复已完成步骤。

原始 CSV、完整行、书评与私人备注不写日志或任务摘要。正式身份、现有个人数据和输入保持独立；导入不操作 Goodreads 网站，不读取账号 Cookie、缓存或令牌，不恢复其他软件插件，也不改动用户媒体文件。

reader 与 csv 负责只读输入、表头和 CSV 结构；mapping 解释来源身份、定位线索、保留字段与个人数据；import 负责调用原生新增、采用顺序与结果。ipc 只转发完整操作，entry 装配登记，Webview 不直接读源文件或保存本地业务数据。正式 Entry／Part 引用和公开 DTO 直接引用 SDK 所属合同，不自建一套迁移模型。

实际 CSV 样例纳入本扩展的 tests/fixtures，区分公开书目字段与合成私人值。实现验收还须覆盖 UTF-8／BOM、字段换序与未知列、重复表头、引号和长正文、ISBN 包装与冲突、0 与 3.75 星、四个固定状态、Read Count 反例、日期原值采用与非法值、同目标多行冲突、Part 范围、取消与部分提交，以及真实宿主中的单页操作和独立制品。日期为第一日时正常采用，不出现精度告知、确认或自动备注。当前来源核验不代替这些实现验收。
