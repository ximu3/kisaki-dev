# YACReader Importer 接入方案

YACReader 导入器迁入漫画书库中的资料、本人记录、标签列表、实际文件和阅读位置。输入基线为 [10.4.0 源码](https://github.com/YACReader/yacreader/tree/28f92f4d8bdbb7170f6002e00bed7503356eea03)、数据库 9.16.0，依据见[源码及合成核验](../../../verification/evidence/yacreader-importer/source-and-fixtures.md)。

<a id="scope"></a>

## 用途与输入

一个本地手动迁移页面。通常只需选择一个 YACReader 书库根目录，自动读取其中的 .yacreaderlibrary/library.ydb、封面目录和实际漫画文件；不要求用户逐个提供内部文件。也可以选择一个官方完整数据库备份 .ydb，按需另选配套书库根。只迁资料和个人记录时不必提供媒体。

第三种输入是官方“导出漫画资料”生成的 .ydb。它只包含 db_info 与 comic_info，且只导出 edited=1 或 comicVineID 非 NULL 的记录；它不是全库备份，即使读过的书也可能不在里面。它没有完整文件关系、标签、喜爱和阅读列表，缺席内容保持未知。入口根据数据库实际结构区分三种用途，不凭 .ydb 后缀或文件名判断。

支持范围固定为 10.4.0 的当前输入家族，db_info.version 必须为 9.16.0，并同时满足已核验的表和列结构；这不是 PRAGMA user_version，也不是应用版本号。旧版、分支或未知结构明确报告不支持，不运行来源升级、恢复或修复逻辑。

默认目标为 Comic，输入中确属 Novel 的内容可以明确选择类型。书库中的西方漫画等是否纳入由本次范围决定，不把所有文件强制归为 ACGN。来源阅读样式不代替作品类型或分部目录，导入不要求资料方案。

本项不建立在线资料 provider，不连接移动端、服务端或账户，不恢复来源设置、图像滤镜、下载与网络服务。独立 YACReader 阅读器的 bookmarks.yacr 是另一种按文件名与大小保存的 QDataStream 私有格式，不属于本导入器的 Library 数据库输入。

## 数据库读取与记录对应

以只读方式处理稳定快照。优先使用官方完整备份；直接选书库目录时，关闭来源写入后读取一致副本，存在 WAL 时完整处理已提交数据，不能只复制主文件后忽略旁文件，也不能在活跃写入中拼接几个不同时刻的文件。无法取得一致快照时报告，不修改源库、执行 checkpoint 或把缺失旁文件当作空数据。

使用成熟 SQLite 库，固定已知查询与投影，关闭扩展加载和不可信 schema 执行；不运行来源触发器、视图、SQL 文本或外部文件表达式。限制输入大小、行数、字段长度、查询预算与资源占用，核对必要表、版本、主键形状及引用关系。不能因为来源曾声明外键就跳过关系核验。

完整书库有十张已核验表。comic 是物理文件行，comic_info 保存资料与个人记录；多个 comic 可以引用同一个 comicInfoId。评分、已读、三个书签与续读按 comic_info 读取一次，文件、标签、喜爱和阅读列表成员按 comic.id 联接。不能在联表后为每份文件重复建立同一条个人记录。

SQLite 标识保留准确整数，不能先转成 JavaScript number；超过安全整数范围的两个相邻 ID 仍须分开。不同输入书库的内部 ID、hash、名称和路径都具有各自作用域，不跨库直接合并。元数据导出没有 comic_info.id，按当前输入中唯一且合法的 hash 及明确资料上下文组织候选；重复矛盾记录不按最后一行覆盖。

未知或非法可选个人字段只阻止相应采用项，能够独立确认的书目文字仍可使用。断开的 comicInfoId、文件夹或合集引用分别报告，不能通过内联接静默丢掉它们后声称全量成功。根文件夹 id=1、parentId=1、path=/ 是来源明确的结构；其他环、孤儿和异常层级不能据此放行。

## 作品、分部与资料

来源标题、系列、作者、卷号、期号、文件和已有对应共同用于解释对象范围。comic_info.id、comic.id、库编号与 pseudo hash 用于本批次关联和步骤记录，不成为公开作品身份。同名文件或相同标题不证明是同一作品。

comicVineID 不能仅凭名字就当作可信平台身份：此版本也可能把内嵌 ComicInfo 的任意 Web 地址末段写入该列。没有进一步核实的值只作为定位线索，不拼成 Comic Vine 链接、不占用本体 source 类型，也不将单期标识直接绑定整作。

已有准确作品正常复用，不自动刷新资料。缺少目标时，以选定类型、真实名称及可准确映射字段形成 prepared 输入，经 ingest 新增，所选个人初值与最低完成随 initial 同次提交。只有路径或内部编号而缺少最低资料时报告未新增，联网补充另行发起。

作品和分部范围必须明确。来源每行通常代表一个可阅读文件，可以对应整作、卷或其他实际 Part；文件夹、series／volume／number、count、arcCount、当前页和页数都不单独证明完整分部结构。已有准确 Part 使用真实归属；只有目录线索时不批量补造卷或话。评分、喜爱、标签与合集只在其本体支持的作品范围采用，分部记录不默认为母体事实。

来源普通资料默认选中，新作品直接采用合法名称、简介、标签和已明确本地封面；已有对象默认保留，选择补空或覆盖后才更新。缺项不清除原值。作者、画师、编辑、角色与组织的平面姓名不建立主体或署名关系，多值作者和 tags 按真实换行解释，不统一按逗号拆开。

出版日期并非完成日期。此版本的 XML 载入会把缺失月日填为 1，而数据库不保留原始精度；本项不将这种显示日期直接写成精确发行日。卷期、语言、出版方、阅读样式与日期等没有直接采用项的资料保持为定位上下文，不增加来源镜像字段或整份原始数据笔记。

<a id="personal"></a>

## 评分、喜爱与已读

评分、喜爱和最低完成事实分别选择，已有个人值默认保留。评分读取原始有限数值，范围 0–5，正值乘 20 后按本体整数评分规则取整；REAL 列中的有效小数不先经来源桌面整数 getter 截损。0 是明确未评分，选中当前值采用时可清空评分；NULL 是未知。越界、字符串和非有限值不裁剪、不强制转换。

本版本默认列表编号 1 是 Favorites。选中的正向成员关系可在作品范围采用为喜爱；未加入某个物理副本不表示不喜欢整作，资料导出中没有该关系也不清除本地喜爱。多份副本对应同一作品时，正向事实采用一次。来源普通阅读列表和标签不等同于喜爱。

comic_info.read=1 表示来源文件已读，包括用户手动标记和阅读到最后一页后写入的结果。已明确对应完整 Work 时，只表达至少一次完成：本地历史为空才初始化一条未知日期记录；已有历史保持。新作品随 initial 保存，已有作品使用 expected.completionCount: 0；同一作品的文件副本不增加次数。对应真实 Part 时只采用分部完成标记。

read=0 不撤销既有完成历史，也不自动清除分部已完成；它可能是用户重置了来源阅读记录。lastTimeOpened、added、文件修改时间、备份时间和出版日期都不补作完成日期。currentPage 到达末页而 read 未成立时，不由导入器再推导完成。

hasBeenOpened 与来源“正在阅读”列表是已打开且未读完的投影，不提供计划中、进行中或搁置的明确当前安排。本项不由它们改写本体当前状态；完成历史采用也不清除已有安排。folder／reading_list 的 finished、completed 是各自容器标记，不能传播成成员或整作完成。

该数据库没有阅读活动区间或累计阅读时长。最后打开时刻和页数不能推算活动、附加时长或统计，也不能把未知时长写成 0。不同源记录落到同一作品却给出矛盾评分时报告，不能取较高值或以最后打开时间代替明确选择。

<a id="organization"></a>

## 标签、阅读列表与文字

选中的 label 通过 comic_label 的准确文件引用转为普通作品标签；comic_info.tags 是另一份换行分隔的资料标签，可独立选择。采用本体名称复用规则，空标签可以保留。来源标签颜色、全局排列和成员排列不变成标注颜色或标签命名空间。

选中的 reading_list 迁为手动 Collection。本体合集不嵌套：顶层列表保留自身直接成员，再按子列表 ordering 拼接其成员；各组内部按 comic_reading_list.ordering 排列。这与来源顶层完整阅读顺序一致。需要保留子列表时，另建“父列表 / 子列表”合集，仅包含该子列表的成员，并在说明中保留来源上下文。

当前来源界面支持顶层与子列表两层。环、孤儿或未核验的更深结构报告，不能无限递归。并列顺序使用准确源 ID 稳定补序，不声称还原来源没有规定的并列顺序。重复文件在准确映射为同一 Work 后，按合集成员唯一规则保留第一次出现的位置；空阅读列表可以保留为空合集。

同名合集不自动合并；复用已有合集必须明确选择，保留已有成员顺序并追加新成员。只有已核实的作品引用才能成为成员，不能把 Part、文件夹或物理文件编号直接塞入 Entry 关系，也不能无声替换为母体。文件夹树保留为本次路径与范围上下文，不自动变成系列或合集。

notes 与 review 分别提供“来源备注”和“来源评论”采用项。它们也可能来自内嵌 ComicInfo 资料，不能声称都是用户亲笔的私人评价。选中非空文字后，按纯文本转义为普通 Note，关联明确作品，保留有意义换行；不执行 HTML、不覆盖作品简介，也不合并同正文的独立笔记。

三个书签槽没有用户标题、摘录、批注或已保存的页面图像。成功转换的位置形成普通书签 Annotation，可以按用户选择从实际页取得图像并通过附件准备保存；图像失败与位置结果分别报告。定位失败又没有其他可保存内容时报告未迁入，不制造空 Note。

## 文件与封面

选中的真实文件通过 holdings 核验和登记，不移动或删除来源文件，不覆盖目标文件。官方数据库备份与资料导出都不包含漫画字节或封面；需要这些内容时另选已复制到持久位置的配套目录。临时解包路径不能登记为持久文件位置。

comic.path 在此来源中使用带单个前导 / 的书库相对路径，并已包含文件名；不能按操作系统绝对路径解释，也不能重复拼接 fileName。以所选新书库根重建路径，核对 basename、目录归属、实际文件及授权范围；必要时使用明确旧根→新根映射。拒绝越界、UNC、盘符注入、流名称、符号链接或重解析点逃逸，不在整台设备上按同名搜索。

来源 pseudo hash 是前 524288 字节的 SHA-1 十六进制结果，加上十进制文件大小，两部分直接连接。它可协助核对来源关联，但不是完整内容哈希：同大小文件的后半部分变化可能完全不改变此值。不能据此合并作品、证明历史内容未变或认定两个副本页序一致，也不在本体位置合同中增加哈希门槛。

封面从 .yacreaderlibrary/covers/<hash>.jpg 的准确关系读取，验证安全文件名、范围和真实图像字节后，经附件准备采用。covers/folders 下的文件夹封面不自动作为作品封面。来源 usesExternalCover 只是来源状态，不授权访问任意外部路径；缺封面与文件缺失分别报告。

同一 comic_info 对应多个文件时，来源没有记录最后打开的是哪一个副本。所选文件可以分别登记，但书签和续读须明确本次目标文件；不能按第一条、最短路径或 hash 相同自动挑选，也不把一份共享书签自动复制到所有文件。缺少目标不妨碍资料、笔记和个人记录迁入。保留已有首选文件。

<a id="positions"></a>

## 书签、页序与续读

currentPage 从 1 开始，bookmark1／2／3 从 0 开始，-1 表示空书签。书签 0 是第一页；同一来源记录中重复槽位只形成一个点。默认未打开记录也有 currentPage=1，因此只有 hasBeenOpened=1 且页值有效时才提供续读采用；0、负值、越界和非整数不夹到第一页或末页。

PDF 使用实际物理页序转换为 pageIndex。双页显示、页码标签、旋转、裁边和 UserUnit 不改变物理页身份；本项保存页起点 point=(0,0)，不声称恢复来源没有保存的页内滚动量或文字选区。

图片归档先安全枚举完整来源页面集合，再解释此版本的顺序。[阅读范围](../../projects/kana/formats.md#format-scope)内的 CBZ／ZIP 支持相应位置恢复，RAR／CBR 不在本项范围。其他归档格式按本体实际能力处理，无法可靠枚举时报告位置不支持，不影响独立有效的资料与笔记迁入。加密、损坏、重复成员及超限分别报告，不能先丢掉本体不支持的图片再重新编号。

来源图片识别由 QImageReader 的实际插件决定，按名称结尾匹配格式字符串，不要求有点；含大小写精确的 __MACOSX 的名称排除。其自然排序使用 QCollator，依赖未写入数据库的运行环境；前导零、大小写、Unicode 与标点可能产生不同顺序或并列。只有完整成员分类和顺序可以证明时才转换，例如已验证 PNG／JPEG，名称固定前后缀一致且仅数字段不同、无并列的情况。不能拿当前机器区域设置或其他导入器的比较器冒充来源排序；未知图片插件与排序上下文报告位置不支持。

在自然排序后，此版图片归档还执行双页命名启发式：例如 page1011 对应一张合并图，可能被移到 page10／page11 所在次序；不足 1000 页时按实际公共前缀和合并规则处理，1000 页起跳过。合并图仍是一张原始页面，不拆成两个 Part 或两个持久页。独立目录阅读使用不同规则，不能用它替代归档顺序。

归档页位成功时保存完整 memberPath，不保存临时数字排序号。numPages 只作交叉核对，不足以证明文件未改、图片插件一致或源页面全集正确。封面提取的排序也不总与阅读器启发式相同，不能从 coverPage 推导阅读页序。

图像型 EPUB 按此版 OPF spine、导航排除、linear 标记、单图包装及少量非图片页容忍规则解释，不能按 ZIP 图片自然排序。对实际为固定版式、能够核对完整源页面与原始 spine 出现项的输入，转换为 epubSpineItem；被跳过的导航／版权页不能导致编号压缩，同一图像重复出现在不同 spine 项时保留不同位置。重排文本、缺图、多图包装、未知插件或无法确认原始出现项时不伪造 pageIndex、CFI 或 memberPath。

位置采用使用原生完整操作，不打开阅读器、不产生会话、活动或完成记录，不改变首选文件；已有位置默认保留，明确采用后才更新。初始 progress 为空，由 Kana 按本体规则计算。准确映射为纯页点的书签可以没有标题或文字；源数据本身不提供高亮或区域框选，不能补造。

## 页面、执行与结果

页面提供书库根或数据库、可选配套根、书目范围、Work／Part 对应、类型及来源资料、私人记录、标签列表、文字、文件、书签与续读选项。来源普通资料默认选中，无须资料方案；元数据导出按实际内容显示缺项。默认选有真实 comic 关系的书目，可明确加入资料足够的孤立 comic_info，不制造占位作品。

来源名称、目标类型、内容范围、文件与结果各占一列，窄宽度横向滚动。必要目标和共享记录的文件选择在本次范围完成，不增加整批差异稿、逐项文件路径预览或事后人工配对队列。

先核对结构与范围，再执行 prepared 新增／复用、所选资料更新、个人初值、完成、标签／合集／Note、文件与定位。数据库副本、图片处理及页序工作位于事务外；Webview 不直接读源数据库或写本体。

每个本体完整操作分别提交。取消停止后续步骤，关闭页面不取消后台任务；已成功的独立资料不因某个文件缺失而回滚。结果区区分新增、更新、未变化、部分完成、跳过、失败，以及具体所选内容未迁入原因；不能把“文件已登记”当作“书签已恢复”。

新建与继续批次遵守[共同规则](../importers.md#repeat)。同批次保存源对象与已完成结果，继续不重复备注、评论或书签；未知提交先核对。另建批次可以明确追加，最低完成仍受空历史约束；本项不提供活动或时长采用。
