# W00 终审后的局部修正

本记录接续同日[最终审查](../final-review/README.md)。当前工作区修正了公共包配置未参与构建身份的问题和浏览器测试默认端口问题。工程锁尚未修改，也没有引入 fs-native-extensions；锁的必要范围与 buildId 的职责继续讨论，W00 不登记为已完成。

后续已确认保留 buildId 现有机制；工程锁的审查结论与复现见[锁设计审视](../lock-design-review/README.md)，本记录保留局部修正时的验证范围。

## 实际修改

- 公共包的源码、工具、config 目录和根 TypeScript／JSON 输入由应用工具中的同一选择函数提供，构建身份与开发监听共同消费。合法的嵌套编译选项变更现在会改变输入指纹；输出与本地状态仍不参与。
- 浏览器测试通过 Vitest 5 的公开 test.api 配置使用 `127.0.0.1:23315`，strictPort 为 false。默认正式命令不再依赖本机受保留的 63315 端口，也不需要临时命令行覆盖。

本轮保留现有 sourceIdentity 作为 buildId 的实现、候选目录交接和构建前后输入比较。局部补漏不代表已经确认输入指纹与构建标识应长期合并为同一职责，也不把两次哈希相等解释为完整的输入快照保证。

## 本机验证

环境为 Windows 10 x64、Node 24.11.1。命令均从仓库根执行。

| `pnpm check` | 类型、lint、格式与依赖边界通过；根测试 15 项、本体 Node 测试 12 项通过，其中新增 2 项输入身份回归 |
