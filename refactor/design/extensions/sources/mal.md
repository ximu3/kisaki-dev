# MyAnimeList 接入设计

MyAnimeList 使用官方 API 提供动画、漫画与小说资料，以及本人列表、状态、评分和完成日期。本文规定资料映射、plain PKCE 连接、导入和同步。

<a id="scope"></a>

## 职责与页面

| 能力         | 接入范围                                                                                   |
| ------------ | ------------------------------------------------------------------------------------------ |
| 作品         | Anime、Comic、Novel 的搜索、定位、普通资料、适用图片与直接作品关系                         |
| 制作组织     | 动画详情中 studios 的真实组织引用、名称与本作制作关系；不提供独立组织档案                  |
| 本人导入     | 官方动画、漫画体系中的本人列表与记录，漫画和小说按真实类别分流                             |
| 持续同步     | 作品状态、总评分、单一完成日期；提供手动与默认关闭的自动执行                               |
| 不提供的能力 | 角色、人员档案、配音、分部目录、公开喜爱导入或回写、自定义列表管理、累计进度与重看次数同步 |
| Webview      | 资料采集、账号、导入、同步四页                                                             |

公开作品资料和本人记录均通过官方 v2 API 读取。不提供补充聚合服务、自建服务地址、镜像或网页抓取渠道；官方未提供的档案、关系和目录不形成该扩展的能力声明。其他资料来源由本体方案独立选择。

<a id="identity"></a>

## 对象与身份

source 使用 myanimelist；sourceId 使用真实资源类别与规范十进制编号：

| 来源资源                                                                  | 本地目标                                                                |
| ------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| anime/<id>                                                                | 来源按独立作品管理的 Anime，包括不同季、独立 OVA、特别篇、短片与动画 MV |
| manga/<id>，media_type 为 novel 或 light_novel                            | Novel                                                                   |
| manga/<id>，media_type 为 manga、one_shot、doujinshi、manhwa、manhua、oel | Comic                                                                   |
| producer/<id>                                                             | 动画 studios 中的真实 Organization 引用，仅在作品上下文读取             |

动画格式中的 music 表达动画视频，不能按名称改作音频条目。独立编号的 OVA、特别篇和 MV 不自动改成另一作品的 Part。单篇漫画仍是独立 Comic；卷数为 1 不证明记录就是某系列的一卷。没有书籍类别依据的 unknown 不默认归为漫画。

实际官方响应已有 light_novel，虽然本次取得的 OpenAPI 枚举说明尚未列出；读取必须接受已经核验的实际值。

官方漫画作者引用未区分个人与创作组合，不据此自动建立 Person 或 Organization。官方也没有通用人员、角色和 producer 详情端点，不声明相应根搜索、resolve 或按档案身份直接读取的能力。

studios 的 id 与 name 可以在真实动画上下文中提供组织端点与名称；不由组织通常业务补出出品、出版或其他职责，也不从名称反推另一来源身份。

<a id="search"></a>

## 搜索、定位与读取

作品名称搜索使用官方 /anime、/manga，书籍候选补齐 media_type 后按 Comic／Novel 分流。独立搜索保持来源顺序和真实分页，过滤后为空而上游仍有下一页时继续读取。

名称 resolve 完成当前查询所需的有限候选范围，再交给共同 matching；不能按第一项或唯一名称结果宣布已对应。明确 MAL 身份仍须核对资源、类别和实际范围。只有编号而没有资源类别时，不在 anime、manga 等表之间猜测。

官方分页使用实际 paging.next。下一页地址须仍属于官方服务及对应读取路径，凭据不随任意外链转发。预算耗尽、页面重复或后续页失败不产生“完整结果”；按共同 ExecutionFailure 和 partialResult 处理。

已知作品身份可以直接读取详情。动画上下文中的组织仅声明 relatedEntries.organization 的 name、externalLinks，省略其 identitySources；它不提供无作品上下文的组织 refs 读取。该差异沿既有 provider 能力合同表达，不增加私有定位码或扫描全部作品来反查组织。

<a id="fields"></a>

## 普通字段与语言

| 来源值                               | 采用                                                                          |
| ------------------------------------ | ----------------------------------------------------------------------------- |
| title、alternative_titles 与实际别名 | name、aliases；按明确语言及 preferredLanguages 选择，缺少匹配时使用来源主名称 |
| synopsis                             | description，转为共同 Markdown                                                |
| 作品页面、studios 引用的组织页面     | 相应对象的 externalLinks，不作为其他对象或版本的身份                          |
| 官方 nsfw                            | white → false，gray／black → true；缺失或未知值不默认安全                     |
| start_date、end_date 与发行状态      | 当前作品的 releaseDate、releaseEndDate、releaseStatus，保留实际日期精度       |
| 漫画与小说 num_volumes               | 正值可提供 declaredVolumeCount；0 按来源定义表示未知，不写成明确零            |
| 漫画 num_chapters                    | 正值可提供 declaredChapterCount；小说没有该本体字段                           |

发行状态分别将未开始、正在发行、已结束映射为 planned、ongoing、finished；来源明确的暂停、取消值按同义值采用。不能用当前时间、最后编号或个人完成状态推断发行状态。

alternative_titles.ja 作为来源提供的名称形式参与显示和别名。originalName 与 originalLanguages 需要原作依据，普通标题语言和播出时区不能证明作品原始语言。

num_episodes 是来源总量，average_episode_duration 是平均单集时长；不分别填入正片集数和整部时长，也不相乘补造总时长。不提供页数、标题标志、来源未结构化给出的角色身体资料、人物性别／逝世日期或组织解散日期。

MAL 的普通介绍可能没有保留下来的剧透标记。不根据剧情内容猜删，也不宣称没有标记的文字无剧透。来源明确保留的遮蔽块在转换前连同内容移除；不把完整信息框、统计或未采用字段附加成新的简介。

<a id="relations"></a>

## 关系、职责与标签

动画详情的 studios 提供 studio 关系及组织端点。anime 上下文的 organizationWorks 声明固定 scope：[{ roles: ['studio'] }]；成功数组及 [] 都回答这份制作公司名单。MAL 的关系能力限于本节列出的制作公司、作品联系和标签，漫画作者引用及连载杂志仍按来源字段保留。

作品关系使用完整关系读取，保留直接联系，不使用推荐或同系列推断：

| 来源关系                                                        | 本体解释                                                            |
| --------------------------------------------------------------- | ------------------------------------------------------------------- |
| Prequel／Sequel                                                 | prequel／sequel                                                     |
| Side story／Parent story                                        | sideStory／mainStory                                                |
| Summary／Full story                                             | summary／fullStory                                                  |
| 明确的衍生及其反向                                              | spinOff／spinOffOrigin                                              |
| Alternative setting／Alternative version                        | related，保留来源版本称谓；不从宽泛版本分类推导本体的不同演绎或重制 |
| Adaptation、Character、Other 等只有关联、缺少可靠方向的已知含义 | related，并保留来源称谓；不从媒介或日期猜改编方向                   |

作品关系来自详情中明确请求的 related_anime 与 related_manga，覆盖本次官方字段范围，关联书籍补齐实际类型。不能把 recommendations 当作作品关系；未取得所需完整范围时不提交关系集合，未知枚举也不能统一降为 related。只读取直接端点及判断所需事实，不递归展开资料图。

作品标签只采用官方实际返回的 genres，名称按原文保留，不猜中文译名。不把统计人气、个人 tags 或连载杂志当作公共作品标签；缺少独立依据时不提供标签 description 或 isNsfw。字段未请求、缺席和失败不解释为空集合；完整返回的明确空集合沿共同读取合同处理。

<a id="parts-images"></a>

## 分部与图片

官方 API 没有实际分集、漫画卷话、小说卷或附加内容目录，不声明 Part 字段或相关关系。作品总数、标题里的卷号、主题曲列表和预告视频不生成 Part。

作品 primaryImage 使用官方 main_picture 及实际 pictures。大图、小图和 JPEG／WebP 变体按同一素材归并，优先使用实际提供的高分辨率版本，不猜 CDN 路径。

不声明 backdropImage、titleLogo 或 iconImage，也不提供角色、人员或组织图片。独立图片浏览只覆盖可搜索的作品。下载、解码、缩略与采用沿[公共图片合同](../../domains/attachments.md#images)，不保存私有图片库。

<a id="account"></a>

## 应用配置与本人连接

公开官方资料使用项目登记的 Client ID，不要求用户登录。允许用户明确覆盖为自己的公共客户端 ID；它与本人 token 分开保存和展示。发行制品使用项目正式登记的默认应用。

本人连接使用 plain PKCE 直连与固定 loopback；建议使用 127.0.0.1:43821/oauth/mal/callback，并与应用登记完全一致。监听失败明确结束，不换端口、接管其他进程或退回业务 deeplink。授权状态只存实例内存，核验成功后再保存凭据。

通过 /users/@me 确认本人稳定 ID。access token、refresh token 与有效期按实际响应保存；刷新后的账号必须一致，轮换值原子替换。失效时由用户重新连接，不在后台反复弹浏览器。

连接同时绑定本次授权的 Client ID。更换资料采集配置不能让新 Client ID 用来刷新旧令牌；页面标明重新连接的需要，只有新的完整授权成功后才切换本人授权上下文。

官方凭据只发送到明确的官方应用／账号请求，不发送给图片 CDN 或普通外链。换账号停止旧连接的任务与自动触发；断开清除凭据，保留本地条目和记录。

账号页说明：MAL 没有可写的逐条可见性参数，新记录沿用站点清单设置，不提供逐项私密开关或私密承诺，也不自动修改账号隐私。

<a id="import"></a>

## 本人清单导入

官方动画列表和 manga 列表分别完成分页。后者按实际类型分到 Comic／Novel；全部范围不能只拼接五种状态筛选，因为实际存在无状态记录。来源记录按资源身份去重，既有本地对象复用，新增沿 ingest 采用资料与所选个人初值。

支持手动导入与默认关闭的自动补齐；用户选择范围、字段、资料方案和可选本地手动合集。自动导入只补缺项，不覆盖已有个人记录，不因远端移除删除本地条目或成员，不维护“曾经导入过”的排除名册。

| 本人值                                                  | 本地采用                                             |
| ------------------------------------------------------- | ---------------------------------------------------- |
| plan_to_watch／plan_to_read、watching／reading、on_hold | planned、active、onHold                              |
| is_rewatching／is_rereading=true                        | active；不凭次数或重看标记生成历史                   |
| completed，且没有有效重看标记                           | 按共同规则初始化完成事实、清除当前状态；已有历史保留 |
| dropped                                                 | 状态不采用；其他所选字段独立处理                     |
| 已确认存在的完整列表记录中，所请求 status 为空          | 清除当前状态，不删除完成历史                         |
| score=1–10；score=0                                     | 前者乘 10，后者为未评分                              |
| 合法完整 finish_date                                    | 按共同历史初始化规则采用；部分日期不补齐             |

在已确认的完整个人记录投影中，MAL 会省略清空后的 status、finish_date；这与整个 my_list_status 不存在、字段未请求或请求失败不同。后几种情形不能据此清除本地值。

start_date、累计卷话／集数、重看次数、评论和自由 tags 不转换为本地历史、分部标记或 Note。num_episodes_watched 只给出数量，并未证明哪几集完成；即使另有目录，也不假设它必然表示连续前 N 集。

MAL 列表只提供其声明的个人状态，favorite 保持本地管理，不参与该来源的导入或同步。加入列表、计划和已完成分别按对应状态规则采用。

<a id="sync"></a>

## 状态、评分与完成日期同步

只处理明确选择、已经绑定真实 MAL 作品身份的对象。以本地为准，手动与自动执行使用同一投影；连接、导入和启用另一项自动功能都不会隐式开启同步。

状态沿[共同规则](../synchronization.md#status-and-progress)由当前安排与完成历史形成。当前 active 已被来源重看状态表达时保留该细分；明确转为计划、搁置、完成或空状态时，将重看布尔值与状态作为同一状态表达一并处理，不能留下仍令平台视为进行中的标记。

本次真实请求已经确认：MAL 的 status 空字符串可以清除已有状态，保留评分、数量和其他字段；动画与书籍均支持。只清除不存在的记录是无需修改，不创建记录。

总评分的有效来源区间为 1–10 整数。入站乘 10；出站本地 10–100 按最近十分制整数、居中取较高值，87 写为 9，本地保留 87。null 写为 0；本地 0–9 不在来源有效评分区间内，不夹到 1 分，也不改作未评分。

完成日期取本地最早已知完整日期，使用 finish_date；没有已知日期时发送空字符串清除。本次在动画、小说两条端点均完成了写入、回读和清除，不能再因 OpenAPI 漏列参数而判定不支持。日期修改不替换本地历史，也不回写开始日期。

创建与更新按真实差异分别处理：

| 操作                             | 动画列表                | 漫画／小说列表       |
| -------------------------------- | ----------------------- | -------------------- |
| 已有记录独立更新／清除评分       | 提供                    | 提供                 |
| 已有记录独立更新／清除完成日期   | 提供                    | 提供                 |
| 已有记录独立清除状态             | 提供                    | 提供                 |
| 没有记录，仅有正评分要写入       | 提供；接受默认 watching | 提供；实测保持无状态 |
| 没有记录，仅有完成日期要写入     | 提供；接受默认 watching | 提供；实测保持无状态 |
| 选中了可表达的非空状态及其他字段 | 按所选状态创建          | 按所选状态创建       |
| 只有清除动作且没有记录           | 无需修改                | 无需修改             |

动画默认状态属于来源的原生创建行为。状态未选时，评分或日期仍可正常创建；本次选中状态且目标为空时，其他有效字段可以创建，状态明确报告未同步，不能把默认 watching 当作清空结果。

同步只执行来源支持的字段操作。测试中的 DELETE 用于经授权清理测试项，不用于运行期清除单个字段。

completed 与进度分别写入所选字段，作品完成与分部完成独立采用。每次写入后核对实际结果，再保存确认值；平台当前联动依据见对应验证记录。

<a id="pages"></a>

## 配置与内部组织

资料采集页管理默认／自定义 Client ID、名称搜索是否包含敏感作品、请求超时和安全读取重试，并提供独立联网测试。搜索包含敏感作品默认开启；关闭只影响名称发现，不裁剪明确身份读取或本人清单。官方 API 和认证地址固定，不提供补充服务或镜像地址配置。

单次超时默认 20 秒，读取重试默认 2 次；写入、授权码交换和结果不确定的刷新不盲目重放。语言统一来自资料方案，不另设 preferRomajiTitles。保存与联网测试分开，普通重置与移除配置／秘密分开。

账号页负责连接、续期状态、本人摘要与断开；导入页负责手动导入及独立自动补齐；同步页负责对象／字段范围、手动执行和默认关闭的自动执行。各页结果说明未采用字段和来源限制。
