# VNDB 角色发行范围与实例验证

验证日期：2026-10-11。[实际请求样本](2026-10-11-character-scope.json)保存四次公开 API 查询及官网角色规范的有限事实摘录。四次 POST 均返回 HTTP 200、more 为 false；没有使用账号凭据、读取非公开页面或执行远端写入。

## 发行限定是作品角色关系的范围

[角色编辑规范](https://vndb.org/d12#6)将未限定发行的关联解释为 All (full) releases；特定发行可以各自具有角色定位和剧透等级。[Kana API](https://api.vndb.org/kana#post-character)通过 vns.role、vns.spoiler 与 vns.release 返回这些事实，不能把同一 VN 的第一条记录当作唯一答案。

三个角色的完整关联查询核对了以下事实：

| 角色               | 2007 年原版 r174 | 2008 年 Ecstasy r541 | 其他实际范围                               |
| ------------------ | ---------------- | -------------------- | ------------------------------------------ |
| c1868 二木佳奈多   | side             | primary              | 英日双语 r18401 与日语 r22721 也为 primary |
| c1871 笹濑川佐佐美 | side             | primary              | 英日双语 r18401 与日语 r22721 也为 primary |
| c1875 朱鹭户沙耶   | 未列出该发行     | primary              | 后续日语版与含日语的多语版均列为 primary   |

这些 v5 发行记录均标为 official，具有日语，当前 VN 的 rtype 均为 complete。r3748 是多作品包装，但 c1875 的该条关联明确属于 v5，不能由包装中同时列出其他 VN 就推导她出现在那些作品中。

v5 的 va 查询共返回 27 行，其中三个角色各有原语种缺省范围下采用的配音记录，note 均为空。此处只核对角色端点与既定配音采用规则的衔接，没有重新验证所有人物的类型、署名或全部自由文本。

已确认[采用规则](../../../design/extensions/sources/vndb.md#character-scope)：覆盖正式原作语种版本，以最高定位归并，保留版本差异。上述三个角色分别形成一条 main 关联，后续新增角色不被首发日期排除。剧透标记采用共同的保留保护规则；这里只含无剧透的版本差异样本，跨版本剧透差异另用合成场景检查。

另一次按 v17 查询角色的实际响应有 16 条角色记录，more 为 false，每条都包含当前作品的直接关联，其中 8 项具有非零剧透等级。部分角色同时属于其他作品，作品入口必须只取当前 VN；同名但 c 身份不同的记录也不能按名字去重。该样本确认了完整分页终点及当前作品过滤，不代表所有作品都只需一页。

## 实例不能一概折叠为一个角色

[实例规范](https://vndb.org/d12#2)包含年龄、形态、平行世界、不同创作者演绎和身份剧透等不同原因。它不是与 Staff.aid 相同的署名机制，不能统一视为别名。

规范直接使用 c34 与 c3529 作为平行世界实例的例子。实际 API 响应中，两者同名，但生日分别为 [2, 3] 与 [2, 4]，作品关联也不同；两条身份和各自资料应分别保留。角色 API 没有实例关系字段，本次没有建立、推断或抓取全站实例网络。

## 验证范围

样本和投影检查用于验证设计规则，没有实现或运行完整 provider。三个实际角色分别检查最高定位、反转来源行顺序、作品与角色两种读取范围，结果一致。另有 12 个合成场景检查 null 发行、角色与剧透归并、非官方与译文版排除、多语版、试玩、部分发行、正式补丁、多作品包装及必要资料缺失等分支，均符合本次采用规则。

真实样本覆盖 null 发行、官方完整版、含原作语种的多语版、版本定位变化、后续新增角色、组合包装以及独立实例身份；试玩、非官方、部分发行、补丁和读取失败分支使用合成资料，未取得对应真实边界样本。完整分页、网络失败和最终 note 呈现仍需后续 provider 实现验证。
