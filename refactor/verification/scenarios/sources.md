# 来源扩展与平台操作验收

验证来源合同、账号、导入与出站同步。

环境、证据与完成条件见[验收标准](../acceptance.md)，各场景引用对应设计规则。

<a id="records"></a>

## 个人记录导入与原生写入

### 导入与出站投影

A05、A16、A22 和 A27 验证[个人记录导入与同步](../../design/extensions/synchronization.md)：明确导入可以创建没有本地文件的新作品。Finished 或有效完成日期只为没有历史的作品初始化完成事实，Playing 与完成日期能够形成 active 和过去的记录；已有历史不被单一日期覆盖，重复状态导入不追加。来源放弃状态报告无法映射，已有本地状态和历史保持，新建作品仍为未设置；不替换为搁置、不删除条目，其他所选字段独立采用，VNDB 的 Dropped 与 Wishlist 并存也不改用 planned。同步采用当前状态优先的投影和最早已知日期，本地数据不因平台写入失败回滚。远端修改不自动写回本地，手动同步仍核对平台现值，失败后重试采用最新本地值。只有清空值且平台无记录时不创建；删除本地作品退出范围但保留平台记录。

### 平台原生写入

A05、A22 和 A27 验证[平台原生写入](../../design/extensions/synchronization.md#writes)：正常提交选中字段，接受默认状态、日期、进度、次数和可见性联动，不提交未选原值压制联动，不补偿或改账号设置；结果说明实际变化，本地值与历史不被反向改写。没有本体同义值、无法表达的值或清除、需要额外操作未选条目的前置条件仍分别报告，不进入网络重试。Bangumi 仅评分可以创建并默认进行中；只选分集且父收藏不存在时不另建父记录，实际分集更新的父计数联动正常接受。想看状态下不能保存的正评分仍报告未同步，不改状态凑出分数。

MAL 与 AniList 的来源写入分别按 [MAL 同步规则](../../design/extensions/sources/mal.md#sync)与 [AniList 联动规则](../../design/extensions/sources/anilist.md#coupling)验收。MAL 动画独立评分／日期创建接受 watching，书籍可保持无状态；已有状态和日期正常清除。AniList 正常提交 CURRENT／COMPLETED，接受自动日期、补满进度及 REPEATING 完成的次数增加，不要求原进度已满；完成日期被选中才同次写入，未选时不附带保护值。已完成状态不重发，未知结果先回读，空状态不伪装为 CURRENT，累计值不生成本地分部或完成历史。高级评分模式的正式总分回写仍需实际验收，不因模式本身关闭入口。

### 本体提交与失败

新建条目与初始个人值原子提交，变更订阅不能观察到先建空状态、稍后补写来源记录的中间结果。初始个人值与 metadata 候选分开，provider 不提供私人字段。ingest.add 返回 alreadyExists 时不采用初值，已有对象通过 entries 的当前值操作与 completions 的历史操作修改。评分已采用而完成记录条件失败时，保留评分并报告历史操作未完成；不自动刷新基线重放，也不把同一来源项目的独立操作报告为共同原子提交。仅采用完成日期使用历史新增，保留当前状态；新增完成并清状态使用 recordCurrent，两个结果共同成立。

### 自动导入与自动同步

自动导入和自动同步分别默认关闭，连接不触发导入或推送。出站同步由启用、启动和相关本地变化触发，不负责远端清单的周期读取；本地未变化的手动全量同步仍能发现平台差异。换账号成功后旧任务停止后续调用，两项自动功能关闭且不沿用旧确认值；换账号失败保留旧连接。关闭页面、关闭自动开关、明确取消和断开连接分别按合同执行，不伪称撤销已经提交的修改。

A05、A16、A22 和 A27 验证[自动导入](../../design/extensions/synchronization.md#automatic-import)：启用、启动及运行期间的定时检查按当前完整清单补齐本地缺项，已存在对象不重复创建或覆盖个人值。只有父作品存在时仍能识别缺少的真实分部，目标合集只加入合法 Entry。删除本地对象后，远端仍在所选范围时可以再次导入；没有持久的已处理或删除排除名单，清理技术缓存不改变这项结果。远端移除不删除本地对象或合集成员，已有记录的完成历史清空后也不会被自动导入补回。覆盖完整分页、局部失败、配置快照、并发执行合并、账号变化和关闭后停止触发，自动导入不隐式启用或扩大出站同步。

## TMDB 的对象、字段与本人操作

同组验收覆盖 [TMDB 接入范围](../../design/extensions/sources/tmdb.md#scope)：作品目标仅为适用影片与范围一致的标准季；TV 只提供季查询上下文，即使只有一季、已完结或集数相同，也不生成 TV 作品候选或等价绑定。标准季跨多个实际季度时保留未匹配，不截取前 N 集、按年份猜边界或将整剧绑定到一季。扩展不生成剧集组候选或绑定，不接受组标识作为可读取目标，也不通过组接口实施隐藏回退。已明确身份和本地归属的分集可以在没有同源作品身份时直接更新字段，清空缓存与重启后仍按标准季集身份读取；改名、改编号和重排不产生新分集，不扩大更新范围。通用身份的离线查找、应用链接及备份仍沿本体合同执行。

TMDB 的[本人连接](../../design/extensions/sources/tmdb.md#account)验证一次 v4 授权及 v3 session 转换；应用令牌或一次私密读取成功均不作为本扩展已完成本人连接的依据。个人记录和混合列表导入只采用适用动画影片，不将 TV 成员拆为季，也不把单集评分作为完成。人物与公司提供名称搜索，播出机构只按身份或实际关系读取；分别核对公司与网络身份、实际字段缺席、季范围署名及原版配音约定。

TMDB 的[完整季名](../../design/extensions/sources/tmdb.md#search-and-names)由扩展使用真实父标题与季名形成，搜索、定位和字段读取在相同语言条件下保持一致；已经带完整父标题时不重复添加。查询词和本地名称不混入来源识别资料，名称相同仍不能绕过季身份和范围冲突。保持现有 SourceEntry 字段，不增加展示别名字段或 TV 本体实体；普通 name 的写入仍按所选采用方式执行。

TMDB 的[普通资料映射](../../design/extensions/sources/tmdb.md#fields)验证影片、标准季、分集、人物及两类组织的实际字段，未提供的用途不以空值清除。影片日期从原作正式公开或发行记录核对，不能直接套用院线优先的主日期；原版分钟片长保留其取整精度，不相加分集生成作品总量。Released 不映射为发行结束，adult=true 仅提供正向敏感标记，false 不清除本地标记。图片分别使用海报、背景、logo、剧照和主体图片；季不继承整剧图片。关系验证实际季署名、人物反查的明确季范围、公司仅有依据的影片参与和季自身播出机构；合集不推成前后作。零号季不混入其他季，episode_type 不当作本体分类。预设中移除 TMDB 的 workExtras 和 Part.type 来源，同时保留已知分部的公共字段读取。

TMDB 的[影片导入与同步](../../design/extensions/sources/tmdb.md#import)覆盖四类本人清单的分页、动画过滤、重复身份复用、所选字段采用、明确未评分与缺席的区别，以及可选手动合集加入。入口范围保持为导入与个人字段同步。

待看 true 的入站采用设置 planned，false 保留当前状态；出站只有 planned 对应 true，其他状态对应 false，均不生成完成事实。评分 POST 的原生联动分别验证：两字段均选时先评分、后待看；只选评分时接受待看变化；已有评分无需变化时不重发。未选字段保持不直接写入，账号设置不受影响，跨端点部分成功分别报告。

公开 API 与游客评分已有[实测](../evidence/tmdb/live-api.md)，[本人接口实测](../evidence/tmdb/account-api.md)覆盖代表性半分值、收藏、待看及私密列表读取。正式验收补齐分页、页面、任务和本体集成，并按来源的生效条件判断结果。

TMDB 的实测回归样本覆盖 200／201 确认与实际写入结果区分、半分代表值往返、异常小数的新建与修改差异、有界回读和 DELETE 撤回。返回成功但未确认目标值时不能记录同步完成，也不能先建另一评分再修改。游客 Account States 的 401 不转为未评分，游客空列表的 404 不推广成普通账号空值合同。Network 重复身份不生成重复组织或关系；SVG 候选与详情 PNG 地址分别核对实际格式。上述接口证据不能替代完整扩展和本人账号验收。

TMDB 的[完整配置与页面](../../design/extensions/sources/tmdb.md#application-access)验证成人搜索默认开启、手动关闭只影响名称查询、20 秒超时和 2 次安全读取重试；API 访问配置、联网测试与本人连接分别操作。四个页面通过私有 IPC 发起完整业务，页面关闭不取消任务，自动导入与同步分别配置且默认关闭。实现只将本次浏览器授权所得的 user access token 用于 session 转换，私人操作由该连接的用户凭据确定归属，不以应用令牌回退读取。当前同一账号组合下应用令牌也能读取私密列表的实测结果保留，不要求接口一定拒绝这类请求才能通过验收；项目默认凭据的实际可读范围、用户覆盖、配置快照和恢复默认各自遵守边界。

共同线性评分入站按实际值换算后取最近本体整数，中点向上；十分制 8.25 → 83，不先改成出站半分值。TMDB 出站按 0.5–10、步长 0.5，87 → 8.5 且本地仍为 87；0–4 报告无法映射，不夹到边界，不当作未评分。普通用户 session 的代表值已完成[限定核验](../evidence/tmdb/account-api.md)，正式扩展仍按完整取值与取消合同验收。

## 已定类作者与本人账号范围

A03、A05 和 A27 验证 RanobeDB 的原作 author 署名：主体已明确为 Person 或 Organization 时，分别形成 personWorks.creator 或 organizationWorks.creator；主体类型未知时保持原有不自动创建规则。团体作者不降为 other，局部插画或编辑仍使用各自职责和范围。

A22 验证 Google Books 的本人书架：两个不同 Google sub 中相同 shelf ID 保持独立；同一 sub 的正常刷新保留范围，换账号后不沿用旧选择与确认值。请求使用已核验连接的 /mylibrary，不把 sub 作为 Books user ID 写入 URL，书架显示名称变化不改变其身份。

## 图片来源

[SteamGridDB](../../design/extensions/sources/steamgriddb.md) 与 [Fanart.tv](../../design/extensions/sources/fanart.md) 分别验收完整图片范围、真实分页与计数、明确身份、语言及配置快照。SteamGridDB 不按名称首项自动对应，四类用途不固定尺寸，默认包含 NSFW、排除恶搞与闪烁、允许静态与动态。Fanart 的影片、TV／季、Artist 与 Label 分别核对；普通季度读取不继承整剧图片，手动素材选择不创建对象或保存绑定。个人 key 单独读取的成功不代替项目 key 和组合模式核验。

## Steam

[Steam 接入](../../design/extensions/sources/steam.md)验证 GetItems 逐项状态与 BBCode 正文、SearchSuggestions 的仅游戏过滤和真实总量、无伪造名称分页、无旧接口回退、地区与语言分离，以及三类图片。拥有库与愿望单分别导入，拥有不设置状态；累计时长通过独立的[总量核对](../../design/domains/games.md#duration)形成补记绝对值，不创建活动或后台覆盖。覆盖真空、不可访问、换账号、自动补齐缺项与无 Sync 页面，特殊权限样本不能由正常账号推定。

## 来源页面

## Bangumi

A05、A18 和 A27 验证 [Bangumi 的对象与搜索范围](../../design/extensions/sources/bangumi.md)：series = false 的单卷和独立小说分别对应，来源搜索不交付卷或自动替换成父作品；已有分部身份仍可定向读取。单卷已读不生成作品完成记录，单卷评分不提升为作品评分，updated_at 不变成完成日期，缺少空状态值时不通过删除收藏模拟清除。SP 默认按来源分类创建，用户更正为 Extra 后再次刷新保留同一身份与本地种类；仅选择分集范围时不扩大为附加内容更新，也不重新创建同身份分集。

A03、A05 和 A27 验证 [Bangumi 的原配读取](../../design/extensions/sources/bangumi.md#cast)：官网 CV 类别分别支持日本原作与中文原作，译配和真人演员类别不转成 voiceActor。API 的混合 actors 数组不能替代来源页面的类别判断；解析必要标记失败时不退回全收。多个原配与三方关系身份保留，反向读取不将配音扩展到其他作品，职业字段不产生本作工作。

A03、A05 和 A27 验证 [Bangumi 的主体参与范围](../../design/extensions/sources/bangumi.md#staff-scope)与[反向读取](../../design/extensions/sources/bangumi.md#read-paths)：书籍版本组中的专属署名不因 eps 为空而进入主体名单，同一主体在主体资料中的其他实际工作继续保留。必要范围读取完成后，未注明版本的署名按本来源约定采用；读取失败不进入这个缺省。没有来源编号的明确出版社名称不制造身份，连续出版方更替不截成最早一家，也不形成组织沿革关系。

人物与组织、通常职业与本作岗位分别处理。摄影监督、美术监督、歌曲演出不被统一成导演或配音；源岗位细项在所选 note 中保留，不因普通字段为空而改变成员。组织反向列表中的译版参与仍被排除，人物反向配音仍核对实际作品、角色与官网类别；普通工作接口不能替代角色工作。作品关系中“书籍”“动画”等不推导改编方向，未知关系不转换为 related。

A05、A18 和 A27 验证 [Bangumi 标签采用](../../design/extensions/sources/bangumi.md#tags)：默认公共标签全取、用户标签按当前作品 count 取前十，不能按全站 total_count 排序；同值保留来源顺序，截取后再按 nameKey 合并去重，不因重复而额外补项。关闭用户标签只保留公共标签，公共标签为空时不阻止已开启的用户标签分支。修改设置不主动删除或更名本地标签；单卷、本人收藏标签与其他已保存关系不被静默并入作品公开标签。

A03、A05 和 A27 验证 [Bangumi 普通字段](../../design/extensions/sources/bangumi.md#ordinary-fields)：原始信息框可补足派生解析字段缺席的明确资料；角色月日生日、单位不明的三围文字、组织成立日期分别保持原义。作品首次发表与首册日期、作品总量与分部声明分开；eps、volumes 与 duration_seconds 的未知零值不清除既有资料。名称偏好不翻译正文，不将转写当作英文名，也不改变 originalName 或原作语种。

A05、A18 和 A27 验证 [Bangumi 正文](../../design/extensions/sources/bangumi.md#description)与[图片](../../design/extensions/sources/bangumi.md#images)：显式 mask 块连同嵌套链接和图片整体移除，普通删除线和未标记文字保留；未映射信息框不追加简介或自动生成标签。图片尺寸版本只产生同图候选，卷封面不提升作品，父图不补作分集图片；没有来源依据的图片用途不声明支持。覆盖真实正文样本、转换失败及采用后正文图片引用的一致性，现有格式文档和地址核对不代替这些验收。

<a id="vndb"></a>

## VNDB 本人记录

A22 验证 [VNDB 本人记录](../../design/extensions/sources/vndb.md#account-fields)的来源限制：评分及清空自动维护 Voted，随标签变化产生的公开或私有变化按来源事实呈现；扩展不提供逐条可见性设置，也不修改全局标签隐私。未选业务字段保持不直接写入。

完整完成日期仅在 1970–2099 年间可以写出。部分日期和需要清空的远端日期报告无法映射，两侧均为空时无需清空请求。分页覆盖后续批次，仅需计数也请求至少一个结果。来源拒绝在界面与扩展结果中保持失败；已有[账号读写验证](../evidence/vndb/account-roundtrip.md)作为 HTTP 依据，正式实现另行验收集成行为。
