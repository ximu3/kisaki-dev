# TMDB 实际接口核验

核验日期：2026-10-16。本轮使用用户提供的 v3 API key，直接访问官方 API，记录 123 次可采信的 API 请求及 2 次图片 HEAD 请求。凭据仅在测试进程内使用；[结构化记录](2026-10-16-live-api.json)只保留端点模板、公开测试参数、状态和必要摘要。

覆盖公开资料与一个新建游客会话的影片评分，没有连接本人账号。游客仅作为本次核验工具，不改变正式设计中不提供游客登录或评分入口的决定。本轮没有修改扩展运行代码、应用设置或本地媒体库，也不代表完整应用已经验收。

## 评分的实际表现

评分测试始终使用同一个独立游客会话和 movie/372058。[评分写入](https://developer.themoviedb.org/reference/movie-add-rating)、[删除](https://developer.themoviedb.org/reference/movie-delete-rating)和[游客评分列表](https://developer.themoviedb.org/reference/guest-session-rated-movies)分别调用，记录请求确认与实际回读，不将两者合并成一次成功。

| 输入或操作                       | 请求结果              | 实际回读                                             |
| -------------------------------- | --------------------- | ---------------------------------------------------- |
| 0.5、8.5、10                     | 201，业务状态 1 或 12 | 200，能准确读回相同评分                              |
| 0                                | 400，业务状态 18      | 诊断要求大于 0；不能用 0 撤回评分                    |
| 10.25                            | 400，业务状态 18      | 诊断要求不大于 10                                    |
| 0.1、0.24、0.26、0.49、0.51、8.6 | 400，业务状态 18      | 诊断要求 0.50 的倍数                                 |
| 新建 0.25、0.75、8.25、8.75      | 201，业务状态 1       | 本轮有界复查仍返回 404／34，没有取得该评分记录       |
| 已有评分改为 0.75、8.25、8.75    | 201，业务状态 12      | 能读回这些四分之一分值；部分即时回读仍是旧值         |
| 已有 8.5 改为 0.25               | 201，业务状态 12      | 两次有界复查仍为 8.5                                 |
| DELETE 撤回                      | 200，业务状态 13      | 评分列表恢复为初始空态时的 404／34；后续再次复查相同 |

新增与修改的表现存在差异，错误提示也不足以解释全部行为。因此本轮没有把“四分之一分值可以成功写入”定为统一能力，也没有声称成功响应后未读到的值永远不会出现。具体延迟和逐次结果保留在结构化记录中。

0.5、8.5、10 的往返与接口诊断支持采用 **0.5–10、步长 0.5** 的出站规则；用户随后已确认该设计，普通用户 session 下仍须复核。不能为了写入异常小数先新建另一分值再修改，也不能只因收到 success=true 就记录同步完成。读到实际四分之一分值时，应按实际值处理入站转换，不能先篡改成半分值。

本体评分为 0–100 整数；8.25 转换后是 82.5，已确认按最近整数、恰好居中向较高值取整，采用为 83。该入站舍入已写入[共同评分合同](../../../design/extensions/synchronization.md#ratings)；出站按确定的来源刻度另行投影，不反向修改本地。设计确认没有改变本页的实际测试范围。

## 认证、回读与清理边界

官方 [Account States](https://developer.themoviedb.org/reference/movie-account-states) 列有 guest_session_id 参数，但本轮同一个有效游客凭据调用该端点得到 401／3；评分写入和游客列表读取则成功。不能把这个结果推成普通用户 session 也不可用，更不能据 401 填充未评分、未收藏或不在待看。

评分列表可短暂保留旧值。后续实现需要有界回读和真实结果判断，不能因为第一次读到旧值立即重发写入。游客空列表本轮返回 404／34，只能结合这个明确的测试场景解释，不能为普通账号清单或单项状态建立“404 等于空”的通用规则。

所有测试评分均执行了 DELETE，最后一次返回 200／13，之后列表及延后复查都恢复到初始空态响应。游客会话本身没有删除端点；本轮未声称会话已被撤销。本人账号没有连接，也没有进行本人评分、收藏或待看写入。

初始测试脚本曾捕获尚未赋值的游客会话变量，相关 18 次请求不作为来源合同证据；修正为明确的共享凭据对象后重新完成上述核验。报告与仓库文档均检查不含应用凭据和游客会话值。

## 尚未覆盖的验收

- 一次 v4 浏览器授权、用户令牌转 v3 session、本人身份、换账号和撤销。
- 本人私密清单、完整分页、实际账号状态及普通用户 session 的评分新增、修改和撤回。
- 收藏、待看写入，评分对待看的实际影响，以及仅提交所选字段、接受原生联动的完整流程。
- 扩展安装与启动、页面、任务寿命、取消、断网、429 和配置变更。

本轮应用 key 覆盖公开资料与游客测试；本人授权及私人接口的独立结果见[账号实测](account-api.md)。完整运行按[来源设计](../../../design/extensions/sources/tmdb.md#verification)验收。
