# Bangumi 职责与反向读取

验证日期：2026-10-13。使用官方配置仓库与四条匿名公开 API 查询，不连接账号、不修改来源数据。[观察数据](2026-10-13-staff-read-paths.json)保留实际身份、岗位、范围和源码定义的相关投影。

## 岗位含义与共同分类

官方 [bangumi/common](https://github.com/bangumi/common) 提供 subject_staffs.yml、subject_relations.yml 等配置。此次固定读取的树为 2ee87b9995353f77cf02e390e8635bf97dbc1fa2，具体文件 URL、哈希及相关定义保存在观察数据中。前轮《葬送的芙莉莲》动画 862 项参与中的岗位名称都能在相应动画定义中找到。

来源将摄影监督、美术监督、作画监督分别定义为摄影、美术、作画方向的岗位，不能因为都有“监督”就统一为导演。动画“原画”的英文定义是 Key Animation，人物原案是 Original Character Design，主题歌演出是歌曲表演；这些内容支持[职责映射](../../../design/extensions/sources/bangumi.md#staff-roles)中对作画、角色设计、音乐与配音的分别处理。

配置中的部分岗位名称并非一一对应：动画有两项都叫“制作助理”，英文细义分别是 Associate Producer 与 Production Assistant。当前 v0 名册用岗位文字表达关系，不能仅凭同名恢复未返回的岗位编号或推导制作人身份。

组织反向列表里的 subject/305429 与前轮作品侧读取一致，eps 为“西班牙版”。它必须继续经过同一主体参与范围，不能因为从组织页发起读取就变成原版出版关系。

## 关系与验证边界

来源作品关系定义包含前传、续集、外传、主线故事、总集篇、不同演绎，以及世界观、联动等联系；按[作品关系规则](../../../design/extensions/sources/bangumi.md#work-relations)采用具体本体语义。前轮实际响应还有“书籍”“动画”等只表示媒介的直接关联，不能从这些文字恢复改编方向。

本材料验证了端点、返回结构、样本身份及来源岗位含义，未逐一读取反向列表内的全部作品，也没有验证所有岗位的生产映射、授权接口或完整扩展。普通数组已取得不等于所有候选都可以直接写入本地。
