# 字体输入

Noto Sans SC Variable 5.3.1 与 Noto Sans Mono Variable 5.3.0 来自对应 Fontsource npm 包，使用 OFL-1.1。`inputs.json` 固定交付文件的摘要，资源工作流验证包版本和全部字节，并保留各包的 LICENSE、CSS 和 metadata。

字体按来源包的完整字节与名称装配，由桌面宿主提供给使用者。字体资源管理与阅读使用分别遵循[字体](../../../../../refactor/design/domains/appearance.md#fonts)和[阅读](../../../../../refactor/design/domains/reader.md)合同。
