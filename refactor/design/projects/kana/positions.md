# Kana 源位置

本页是源地址、计数、映射、顺序及原始页面几何的技术合同。Kisaki 的持久编码由本体定义。

<a id="addresses"></a>

## 格式源地址

源位置必须对应明确的内容源和解释规则。显示章节、重排页码、包装 DOM、高亮节点和加载批次不构成源身份。只要源字节和解释条件未变，重新打开、修改字体或调整视图都不能改变地址。

Kana 负责生成和解释地址、检查内容范围并恢复位置。消费方可以校验纯值结构，但不另建格式树或解码器。

| 来源                | 采用的源身份                                | 技术解释                                                                                                    |
| ------------------- | ------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| EPUB                | 原始 spine 出现位置及标准 CFI               | 使用完整源 CFI 点位。源内容树参与寻址；展示注入节点不参与。范围的两端各自有完整地址                         |
| TXT                 | 规范编码名称与 offset                       | 按确定编码解码后的 UTF-16 边界，保留换行、空白及 Unicode 组合形式；自动检测只用于首次确定编码，不成为保存值 |
| FB2                 | nodePath 与可选 textOffset                  | XML 根元素为路径起点；按下方源逻辑树寻址，非当前 HTML 节点编号                                              |
| MOBI6               | byteOffset 与可选 textOffset                | 去除记录尾部附加信息、解压并按源记录顺序拼接后的原始标记字节流                                              |
| KF8                 | documentIndex、byteOffset 与可选 textOffset | documentIndex 为源 skeleton 表索引；字节位置相对按原始 skeleton/fragment 表重建、尚未作显示改写的内容文档   |
| PDF                 | 原始零基 pageIndex                          | 页内几何使用有效可见页面、UserUnit 和文档固有 Rotate；用户显示变换另行应用                                  |
| 图片目录或归档      | 相对内容根的 memberPath                     | 使用规范 / 分隔，保留源名称的大小写及 Unicode；成员身份与显示排序分开                                       |
| EPUB / KF8 固定页面 | 原始 spine 项或 skeleton 文档索引           | 必须确有固有页面，不用当前重排页数代替                                                                      |

TXT 使用 WHATWG Encoding 规定的编码名称和解码规则，采用默认错误替换行为并消费匹配的 BOM。解码结果保留原有换行、空白和 Unicode 组合形式，不额外进行 CRLF 或 Unicode 归一化。首次自动检测只确定 encoding，不把“自动检测”保存为位置条件。用户重新选择编码与按已存编码恢复分别处理，不能以一种编码显示文本，却用另一种编码解释 offset。

FB2 遵守 XML 1.0 的字符引用和行结束规则，不加载外部实体。源逻辑树保留元素和文字，排除注释及处理指令；CDATA 按文字处理，排除节点后相邻的文字合并。空字符串不占节点编号，实际空白仍保留。nodePath 从 XML 根元素开始，逐级使用逻辑子节点的零基索引；属性和 namespace 不属于子节点。文字位置以 UTF-16 计数，定位元素节点时可以省略 textOffset。

MOBI6 地址基于去除记录尾部附加信息、解压并按源记录顺序拼接的原始标记字节流。KF8 使用源 skeleton 表索引，并按原始 skeleton 和 fragment 表重建内容文档；寻址发生在显示改写之前。

没有 textOffset 时，byteOffset 指向明确的元素起始标记。有 textOffset 时，byteOffset 指向原始字符数据中合法编码字符或字符引用的起点，textOffset 相对于其展开后的文本，且不能跨越标记。地址不要求落在当次解析 token 的开头，也不能从渲染 Text 的长度反推字节位置。

文字偏移不能切开代理对。节点、地址和范围的顺序按源内容解释，不能根据字节数、路径字典序或 quote.length 推测。解析修复改变显示顺序时，源映射仍须成立。组合 MOBI/KF8 文件的两套地址体系各自独立，既有地址不能换用另一体系恢复。

<a id="selection"></a>

## 文字选区与原始页面几何

一次连续文字选择同时交付匹配的源定位和当时提取的文本。有可靠源文字地址时，使用非空的半开范围；只有固有页面几何可用时，使用按实际选择顺序排列的页面与文字四边形。选择可以跨章节或页面，但不持久化显示页码。几何范围不保证日后能重新提取完全相同的原文。

页面几何先按格式解释规范朝向、有效边界和尺寸，再映射到以左上角为原点的 0–1 坐标。显示旋转、缩放、裁边和双页布局不改变源页面身份。PDF 的解释包含 UserUnit 和文档固有 Rotate。

矩形和凸四边形必须位于页面内且不退化。可以规范等价的顶点起点，但不能改变外层片段的选择顺序，也不能修补实际越界或自交的形状。图片目录和归档通过 memberPath 保留源名称的大小写及 Unicode，成员身份不随显示排序变化。

<a id="source-mapping"></a>

## 源映射与呈现转换

每种格式先确定规范源内容，再生成可呈现结构。源映射记录哪些原始节点、字节区间或页面对应当前的文字与元素，跟随内容片段生存，不依赖临时 URL、HTML id、浏览器 Text 节点分片或高亮节点。

原始字节流和解码序列可以在逻辑上连续，实际按块读取、解码并保存必要索引；不要求把整份文档拼接成常驻大字符串或 ArrayBuffer。重新生成内部文本块时仍须解释相同的合法源地址。

| 格式  | 必须先固定的映射                                                                 |
| ----- | -------------------------------------------------------------------------------- |
| EPUB  | package → spine 的本次出现 → 原始内容树 → 展示片段；同一 href 的不同出现不能合并 |
| MOBI6 | 原始解压字节流 → 编码字符／字符引用 → 文本和元素 → HTML 修复后的展示节点         |
| KF8   | skeleton 索引 → 按原始表重建的文档字节 → 字符及标记 → 展示节点                   |
| FB2   | 源逻辑节点路径 → 转换后的正文、注释和资源节点                                    |
| TXT   | 固定编码的完整解码序列 → 有界文字块及其起始 offset                               |
| PDF   | 原始页及规范几何 → 当前页面变换与文字层片段                                      |

组合 MOBI/KF8 不能因默认选择 KF8 而丢弃已有 MOBI6 地址的恢复能力。带有已存地址打开时，使用该地址指定的实际内容分支；没有位置时可以采用文件的优选呈现分支。跨编码字节、字符引用、多字节文字和代理对的映射由格式拥有，不能从最终字符串长度反算。

CFI 断言用于验证地址，不以断言或摘录搜索自动改绑到邻近内容。过滤掉不可执行内容不改写源节点编号；没有可呈现对应、节点不存在或偏移越界时明确报告，不能把下一段当作原目标。

定位、选区、搜索与标记共用该映射和源顺序。搜索中的大小写等匹配转换另外保留到源文字的对应；结果不保存搜索用字符串的偏移。纯图片没有文字能力，不能用空正文假装成功完成文字提取。

[TXT／FB2 源地址试件](../../../verification/evidence/kana-source/source-addresses.md)已对 16 份自建文件执行 64 次关闭重开，验证全部样本位置在重新解码、解析和展示分块后保持一致。该结果覆盖源映射机制，不代表完整正文提取、真实长书或所有规范编码已经通过。

XML 入口采用[Expat](formats.md#xml)，通过标准本地实体目录解释正常 XHTML 实体，同时禁止加载任意外部实体。源解释完整性、CFI 关键结构与字节映射的依据见[联合格式验证](../../../verification/evidence/kana-formats/format-sources.md)；实体处理及解析器选择见[格式与输入验证](../../../verification/evidence/kana-formats/format-inputs.md)，参考实现的能力差异见[Foliate 对照](../../../verification/evidence/kana-foliate-review/reassessment.md)。编码、声明与按需加载由[完整输入链试件](../../../verification/evidence/kana-xml-entry/entry.md)验证；大书索引、完整格式转换与编码符合性继续按正式验收要求检查。

<a id="native-targets"></a>

## 源目标与原生布局的对应

导航沿以下职责关系完成：

1. 格式解释公开源位置，确定本次内容及源目标。
2. 按需取得内容，在实际展示文档中建立对应，得到 Element、Range 或原始页面几何。
3. 视图完成布局与移动，取得当前真正可见的范围或页面点。
4. 格式使用同一对应关系生成真实 ReadingLocation，Reader 采用状态后结束操作。

原生目标只在本次内容占用内有效；若展示文档经过序列化或重新创建，必须针对真实的新文档绑定。不能把先前 Document 中的 Range 当成后来 iframe 中的目标，也不在 DOM 卸载后读取已经自动变化的端点来覆盖源位置。源码、索引和可见 DOM 的寿命不必相同。

加载结果按本次取得的内容占用释放，搜索结束不撤销仍被视图使用的字体、图片或文档引用。不可变解析事实可以共享，可变展示 DOM 由实际视图持有；取消一个消费者只撤销自己的需要，Reader 关闭才结束本实例全部工作。不向任意消费者提供按章节编号执行全局 unload 的权力。

源目标交接由格式、资源和视图内部协作完成，按需复用已取得的字节、解析事实与索引。公开位置继续使用所属格式的源地址。

## 源顺序、阅读路径和屏幕排列

三种顺序服务于不同目的：

| 顺序     | 用途                                                 | 不随什么变化                         |
| -------- | ---------------------------------------------------- | ------------------------------------ |
| 源顺序   | 解释地址、比较范围、排列标记和搜索结果               | 当前布局、上次跳转路径、资源加载顺序 |
| 阅读路径 | 普通 next／previous 应去哪里，正文与独立注释怎样衔接 | 屏幕左右排列                         |
| 屏幕排列 | 单页／双页、从右向左、竖排、连续滚动中的实际可见位置 | 不反过来改写前两者及原始页面身份     |

EPUB spine 定义默认阅读顺序并标识 non-linear 内容。规范允许普通遍历跳过这些独立内容，用户通过链接访问时仍须呈现目标；具体遍历策略由阅读系统选择，见[spine 规则](https://www.w3.org/TR/epub-rs-33/#sec-pkg-doc-spine)。

正常翻页沿正文路径，明确声明的独立注释等辅助内容仍可通过目录、链接、搜索和已有标记抵达。EPUB 未声明 linear 时仍属于正文路径，附录也不因名称或内容角色就自动被排除。FB2 按格式定义区分主要 body 与独立注释 body；该含义可核对本方案采用的 [FictionBook schema](https://github.com/gribuser/fb2/blob/4d3740e319039911c30d291abb0c8b26ec99703b/FictionBook.xsd)。文件名含 notes、目录层级或弹窗外观都不足以决定正文归属。

例如源顺序是“正文 A—独立注释 N—正文 B”：普通翻页和连续滚动从 A 接到 B；从 A 连续选到 B，摘录只取该正文路径实际经过的内容。N 的真实源位置不变，搜索仍可命中它，源顺序中的标记排序也不重排为用户的访问历史。

相关操作遵守同一组规则：

| 操作或状态                    | 已确认行为                                                                                               |
| ----------------------------- | -------------------------------------------------------------------------------------------------------- |
| 普通翻页与 start              | 正文路径连接其主要单元，start 指向正文起始；普通移动在当前路径边界停住                                   |
| 明确定位独立内容              | 在主阅读视图中呈现真实目标并形成正式跳转；其内部仍可翻页，到独立路径边界停下，由既有返回操作回到之前位置 |
| 正文跨章节文字范围            | 两端都属于正文时，按同一正文路径投影原文，不夹入被该路径跳过的独立内容                                   |
| 独立内容中的文字范围          | 在格式确定的同一独立路径内提取；不把不同独立内容或正文与辅助内容拼成一个范围                             |
| 默认全文搜索                  | 包含可呈现正文和独立内容，按源顺序交付真实命中，不需要先打开注释                                         |
| 正文位置的 progress           | 描述正文路径中的结构位置，精确程度由 estimated 表达；分母不可靠时为 null                                 |
| 明确进入独立内容后的 progress | 返回 null，不显示伪造的正文百分比；临时查看则继续沿已确认规则保留主阅读进度                              |

路径归属从源结构和两个端点确定，不保存在点击历史或新的持久 flowId 中。EPUB 的每个 non-linear spine 出现形成自己的独立范围，FB2 的独立 body 内仍可按自身结构连续阅读；正文里正常呈现的注释不因为有 noteref 链接就自动被抽走。临时查看的可见范围可以更窄，但保存的端点仍必须在关闭后独立解释。

两个端点属于不同路径时，不构成连续文字范围，按既有 locationUnavailable／notRenderable 处理。纯形状解析仍只负责已有值结构，是否落在同一路径由文档恢复核对。没有足够源语义的格式或异常结构需先解决解释规则，不凭文件名或猜测创造路径。范围、搜索和进度共同采用这些含义。

重复 spine 项是另一个边界：完整 CFI 已指明出现位置时严格按它恢复。普通 href 只指向资源、没有出现身份时，若目标仍为当前 spine 出现对应的资源，保留当前出现；否则选择该资源在正文 linear 路径中的第一个 spine 出现，没有正文出现时选择 spine 顺序中的第一个 non-linear 出现。选择只依赖源结构与当前明确上下文，不按最近访问、屏幕方向或响应顺序变化。随后在该出现中解析 fragment，成功返回完整地址；fragment 无效时失败，不改选另一次出现。该规则不用于纠正错误的持久 CFI。

“上一页”和“返回刚才的链接入口”有不同含义。注释往返需要的返回位置属于本次导航状态，不进入 Annotation 或文件位置编码。
