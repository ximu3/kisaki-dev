# VNDB 对象身份验证

验证日期：2026-10-11。依据 [VNDB Kana API 官方文档](https://api.vndb.org/kana)和公开接口实际响应。请求、时间、HTTP 状态及响应保存在[公开身份样本](2026-10-11-public-identity.json)中。

## 已验证的事实

| 请求                                             | 实际结果                                                         | 结论范围                                                   |
| ------------------------------------------------ | ---------------------------------------------------------------- | ---------------------------------------------------------- |
| POST /producer，筛选 type = in，返回首条记录     | HTTP 200；p15 为里見しば，type 为 in                             | producer 可以表示个人，不能按 p 前缀统一对应组织           |
| POST /release，筛选 producer = p15，返回首条记录 | HTTP 200；r40 对应 v103，p15 的 developer 和 publisher 均为 true | 同一个人可以作为游戏的开发主体和发行方出现                 |
| POST /staff，筛选 id = s81，返回前三条记录       | HTTP 200；三条结果都使用 s81，但 aid 不同，more 为 true          | 职员查询按署名返回结果，结果行数不是人物数量               |
| POST /staff，同时筛选 id = s81 与 ismain = 1     | HTTP 200；返回一条主名记录，包含 aliases，more 为 false          | 可以按人物身份读取主名与别名，不必把每个署名建立为独立人物 |

官方文档将 producer.type 定义为 co（公司）、in（个人）和 ng（业余团体）；staff.id 标识主档案，aid 标识署名。上述 s81 样本验证了人物多署名，但不能据此认定所有 Staff 都是人物。[追加类型验证](staff-types.md)已发现 Company 类型的 Staff 主档案。

## 别名搜索与作品署名

追加请求与实际响应保存在[职员检索样本](2026-10-11-staff-search.json)中，三次请求均返回 HTTP 200。

| 请求                                              | 实际结果                                                                           | 结论范围                               |
| ------------------------------------------------- | ---------------------------------------------------------------------------------- | -------------------------------------- |
| POST /staff，搜索 Koiwai Sayuri                   | 返回 s81、aid 11554、ismain false，署名为小岩井 小百合                             | 非主名可以检索到同一人物身份           |
| 同一搜索增加 ismain = 1                           | 返回空列表，more 为 false                                                          | 搜索阶段直接限制主名会漏掉该别名结果   |
| POST /vn，按 staff.aid = 11554 筛选，返回首条记录 | 返回 v11301，标题为 ALIA's CARNIVAL!；va.staff 使用 s81、aid 11554 和小岩井 小百合 | 作品内的实际配音署名可以与人物主名不同 |

人物详情可以按 id 与 ismain 查询主档案；搜索应保留别名匹配，再按人物 id 对应结果。本次作品查询只验证了人物与署名，没有请求配音角色端点，不作为完整配音关系样本。

## 对设计的影响

来源对象应按实际主体类型对应本体人物或组织，人物艺名按同一 staff.id 归并。producer ID 与 staff ID 仍是不同来源记录，不能仅凭同名推断是同一个人。

已确认的人物名称规则见 [VNDB 专门设计](../../../design/extensions/sources/vndb.md#names)：本体人物名来自主档案并沿既有语言规则采用，别名进入 aliases，作品实际署名保留在人物工作关系的 note 中。人员列表显示统一人物名，关系详情呈现本作署名。

[人物职责](../../../design/domains/relations.md#roles)已确定复用 creator 表达以个人身份署名的游戏开发方，人物不新增 developer。programmer 只采用明确的程序工作署名，不能从 developer 推导。人物采用与组织含义一致的 publisher 表达实际出版／发行责任，适用于四类作品。开发和发行标志分别映射，不能互相推导；本样本中 p15 的两项明确署名对应 creator 与 publisher。

本次只验证公开对象身份、上述参与事实和一个别名检索链路，未验证完整字段、分页遍历、账号授权、个人列表读写或扩展运行。前三条职员结果和首条作品结果都是有界样本，不作为完整名单。
