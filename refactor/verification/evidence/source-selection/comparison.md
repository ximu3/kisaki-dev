# 来源名单调查与取舍建议

调查日期：2026-10-15。对象为调整前目录中的全部 30 个资料与平台来源，表中序号沿用调查时的编号；[当前目录](../../../design/extensions/catalog.md#catalog)经后续 AniDB 取舍保留 17 个来源；Goodreads 因属于网站导出型导入器，在文末另列。本页保留调查依据及已确认的名单取舍；AniDB 的后续核对见[记录](../mangaupdates-anidb/live-api.md#anidb)。各来源的具体能力与实施验收仍分别核对。

本次按 ACGN 的实际用途评估，N 以轻小说为目标。一般图书、真人影视或泛社交平台的总体规模，不直接算作 Kisaki 的资料收益。比较同一作品时分别看名称、正文、角色与创作者、真实分部、版本、图片和个人记录，不把“都收录同一作品”视为完全替代。

[结构化核验记录](2026-10-15-research.json)保留请求地址、时间、结果、摘要和必要公开样本。没有使用个人账号凭据或执行私人数据写入；YMGal 使用其官方公开示例的应用凭据取得 public scope，只读取公开资料。本仓库中的核验材料不包含令牌、认证头、完整简介、用户清单、站点会话或图片正文。

## 证据与判断的边界

- 官方合同说明接口允许表达什么；真实响应说明本次对象实际有何内容。字段存在、接口返回 200、更新时间较新，都不能独自证明资料完整。
- 网站样本、接口样本、检索缓存和需要凭据才能核验的能力分别标明。网页访问被拦或匿名配额不足，不解释为网站停服、没有数据或正式客户端无法使用。
- 样本包括《CLANNAD》《近月少女的礼仪》《葬送的芙莉莲》《四叶妹妹》《刀剑神域》《小书痴的下克上》与《Re:Zero》的适用对象。它们用于检验语义与实际增量，不构成全站覆盖率统计，也不代表长尾作品都一样完整。
- 不把 API 的 v0、beta、edge 或文档仓库更新时间单独当作淘汰条件。维护成本还包括凭据、限流、主体分类、作品粒度、网页采集、上游依赖和用户记录的完整操作。
- 本次没有长期可用率测试。私人登录、刷新、分页完整性、写入副作用和实际安装验收，仍按来源逐项设计完成；本页不冒充这些验收。

## 已确认的来源范围

当前确认保留 17 个来源：VNDB、Bangumi、YMGal、MangaDex、TMDB、SteamGridDB、Steam、IGDB、MyAnimeList、AniList、Google Books、RanobeDB、MangaUpdates、NDL Search、itch.io、Wikidata、Fanart.tv。

本轮确认将其余 12 个来源移出官方维护范围：NeoDB、ANN、Annict、Kitsu、Shikimori、TheTVDB、SIMKL、Open Library、MangaBaka、BOOK☆WALKER 日本、BookWalker Global、しょぼいカレンダー。理由逐项见下文；移出不等于判定平台失效，也不承诺用其他平台接管其个人历史。

这个组合保留四类独立价值：ACGN 作品与人物图谱；中文、英文、日文及翻译版本资料；真实分集、卷册与话目录；用户已有的主要清单与游戏持有库。两项图片来源分别服务游戏和动画，维护职责较窄。来源数量不作为先验目标，也不把未保留项全部改名为后续必做项目。

这 17 项仍有具体接入条件：AniList 的用途条款适用性、Google Books 的正式项目配额、IGDB 的应用凭据、Fanart.tv 的项目 key 等不能省略。保留代表值得投入，不代表这些环节已经完成。

## Google Books 的多语言究竟是什么

### 已确认的三种语言版本

以下三条都是《刀剑神域》第一卷的实际公开书目，标题与简介使用各自版本的语言；它们不是同一条 API 记录切换显示语言后的三个译文。

| 版本     | Google Books ID | 出版信息核验                                 | 正文证据                                                               |
| -------- | --------------- | -------------------------------------------- | ---------------------------------------------------------------------- |
| 日文     | CPlnPgAACAAJ    | アスキーメディアワークス；ISBN 9784048677608 | [日文书目与简介](https://books.google.com/books?id=CPlnPgAACAAJ&hl=en) |
| 繁体中文 | y2orDwAAQBAJ    | 台灣角川；ISBN 9789862373996                 | [繁体书目与简介](https://books.google.com/books?id=y2orDwAAQBAJ&hl=en) |
| 英文     | fBZVDgAAQBAJ    | Yen Press；ISBN 9780316560856                | [英文书目与简介](https://books.google.com/books?id=fBZVDgAAQBAJ)       |

日文和繁体页面使用 hl=en 仍保留各自语言的正文。英文记录在中文界面参数下仍提供英文简介。网站界面语言不能当成资料已翻译的证据。

[Volume 合同](https://developers.google.com/books/docs/v1/reference/volumes)的 title、subtitle、description 是单个字符串，language 表示该卷内容的语言；[langRestrict](https://developers.google.com/books/docs/v1/reference/volumes/list)筛选书籍语言，不生成译文。Discovery 的公共参数与 volumes.list 参数没有通用的“把这条书目的标题和简介翻译成目标语言”的选项。

因此可确认“有多语言书目和对应语言简介”，不能承诺“任意作品都能返回中英日三份简介”。这次实证了繁体中文，不据此推算简体覆盖。书目语言也不等于原作语言，同名、同卷号或相近封面不构成不同版本自动合并的充分证据。

### 接入限制与保留理由

本次 volumes.list 的匿名调用得到 HTTP 429；结构化错误指向默认项目的每日配额值为零。停止该路径后，通过独立公开书目页面确认内容。这个结果说明本轮未完成带正式项目 key 的接口验证，不说明这些语言的数据不存在，也不证明所有 Google Books 客户端都不可用。

Discovery 中还存在 series.get、series.membership.get 和 seriesInfo。它们的存在不能替代权限、实际对象和成员完整性的验证，本轮不把它们计为已经可用的轻小说系列目录。

Google Books 值得保留的实证增量，是样本中的繁体中文卷简介、当地出版信息及版本身份。它与 RanobeDB 的系列结构、NDL 的日文书目核对互补；不会因为 Google 的一般图书收录量大就扩大 Kisaki 的 N 范围。

## 同一作品对照带来的重要修正

### 中文简介需要按字段比较

《CLANNAD》游戏的公开响应中，Bangumi subject 13 的 summary 为日文，YMGal ga10008 的 introduction 为中文；Steam app 324160 的中文短简介也存在，但不能把一份商店短文视为全部来源的完整替代。《近月》另验证了 YMGal 中文正文与 VNDB 英文正文。

这支持保留 YMGal 作为中文补充；不支持“Bangumi 从来没有中文简介”或“YMGal 每一条都是全网独有”这类更强结论。YMGal 的 public 应用授权与游戏、角色、人物、组织普通字段仍沿[已确认设计](../../../design/extensions/sources/ymgal.md)。

### 轻小说的作品、卷和发行不能混用

RanobeDB 的 Series 1234 返回按顺序关联的 Book；Book 5151 继续区分日、英、德发行以及原版与翻译署名。该书目有英文和日文简介，但整部 Series 的 description 为空。AniList 的 NOVEL 51479 则有整部作品的英文介绍和角色关系，本次 volumes、chapters 为 null。

Google Books 与 NDL 提供出版版本资料；Open Library 的 Work 也可能只对应某一卷。由此不能拿首卷简介填充整部作品，不能把声明卷数展开为真实卷，也不能因为来源叫 Work 或 Volume 就按字面直接映射。这些差异说明保留 RanobeDB 与 AniList 有明确的互补价值。

### 角色、作者和关系数量要看真实内容

Kitsu 《芙莉莲》46474 的分集资源有 28 条，本轮读取前三条；相同对象的 characters 与 staff 关系分别返回空。这个样本不能证明 Kitsu 全站没有人物资料，却足以反对把规格里出现关系名直接当作该作品已有完整图谱。

MangaUpdates 的 CLAMP 作者档案有 gender=Female，但没有正式个人／组织类别；AniList 也以 Staff 返回 CLAMP。与 MangaDex 一样，岗位或性别字段不能替代主体类型。来源数量增多会增加这些解释工作，不能以“有独立 ID”掩盖它。

### 图片与平台库分别衡量

SteamGridDB 的游戏 grid／hero／logo／icon 和 Fanart.tv 的动画标志、背景有明确使用场景。Fanart.tv 样本的图像类别与数量说明它确有内容，不能直接证明质量优于 TMDB；保留建议基于专门用途和较窄适配职责。

itch.io 当前官方合同能读取购买、领取、礼包与赠送形成的持有库，并支持面向本地应用的 PKCE。这个价值无法由另一份游戏介绍补回。相对地，SIMKL 的官方规则把它定位于带同步的追踪接入，不能为了补几项元数据而只实现资料抓取。

## 对原名单与后续设计的影响

本页已确认退出官方维护的来源仍可作为普通外部链接出现在资料中。保留一个真实外部标识，不等于暗中启用该站提供者。已保留扩展也不能借聚合渠道恢复已排除的来源能力。

落实本次名单调整时，同步核对默认资料方案、辅助材料的实际消费者、来源身份写法、个人记录对接范围、工程交付数量与验收表。不能只删除目录行，却保留隐含网络依赖或同名的残缺预设。

本轮来源调查没有替代导入器的逐项核验；随后已完成[十五项输入格式调查](../importer-selection/comparison.md)，并确认保留十三项。导入器按真实迁移需求、受支持输入版本和无法替代的个人整理判断；译本按语言维护与质量判断，不与在线资料来源共用淘汰标准。

Goodreads 只在当前目录中承担用户 CSV 导出的迁入。本次官方旧帮助链接不可直接读取，导入／导出入口要求登录；没有执行私人导出，也没有因此推定功能已经消失。它与 Google Books 的在线书目读取不是同一种候选能力，官方公开 CSV 样例及现行导出夹具的核验边界见[导入器调查](../importer-selection/comparison.md)。
