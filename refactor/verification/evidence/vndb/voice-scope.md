# VNDB 配音范围验证

验证日期：2026-10-11。三次公开 POST 请求均返回 HTTP 200，原始请求与响应保存在[配音样本](2026-10-11-voice-scope.json)中。另通过 GET /schema 保存[当前 API 字段定义](2026-10-11-api-schema.json)。语义依据 [Kana API 官方文档](https://api.vndb.org/kana)。

## 字段能力

当前 /vn 的 va 节点只声明 character、staff 和 note。没有单独的配音语言或发行版本字段。staff.lang 不等于该条配音记录的语种；note 为自由文本，没有语言枚举合同。

另于同日直接读取[源站职员编辑规范](https://vndb.org/d16#2)，HTTP 200，其 Primary language 被定义为 “Native language”。[作品编辑规范的 Cast 节](https://vndb.org/d2#3.2)同样返回 HTTP 200，只说明链接声优与角色，没有约定备注不写语种就代表原作语种。人物母语不能作为配音筛选依据；未标语种按原作语种采用是本接入另行确认的约定，不是已验证的源站保证。

## 首发无语音、后续加入配音

v11 为 Fate/stay night，原作语言为 ja，作品日期为 2004-01-30。作品 va 返回 30 条人物—角色记录，非空备注中包含 Realta Nua。

读取本作原作语种的官方完整、非补丁发行，得到 14 条记录，more 为 false。最早记录 r350 于 2004-01-30 发行，voiced 为 1，按官方定义表示无语音。2007-04-19 的 Realta Nua 记录 r353、r1858 的 voiced 均为 4，表示全语音。

样本说明作品级配音可以来自后续版本，不能把“只保留首发内容”直接当作配音采用规则。上述日期和状态均是 VNDB 当前记录，不表示独立核实了发行历史。

## 同一作品名单包含不同语种

v7014 为 Dangan Ronpa: Kibou no Gakuen to Zetsubou no Koukousei，原作语言为 ja。va 返回 37 条记录，实际备注包含 Japanese 和 English (Uncredited)，人物 lang 包含 ja 与 en。

这个样本证明作品级配音名单会包含译配。仅凭它属于同一 VN，就将整个 va 数组称为原作语种名单并不成立。人物语言不能用作配音语言的等价替代，备注文字也不能被表述为接口提供了稳定的语言筛选字段。

## 已确定的目标与采用约定

已确定[作品与原作语种范围及来源约定](../../../design/extensions/sources/vndb.md#voice-scope)：只记录作品正式采用的原作语种角色—声优关系，不收录译配，时间先后不作为独立筛选条件。来源明确标注其他语种时排除，未标语种时按作品原作语种采用。因此 v11 的 Realta Nua 或空备注记录不会仅因未注明 Japanese 而被排除。

[补充备注样本](voice-notes.md)记录了明确语种、括号版本说明与空备注的预期采用结果。约定依赖源站标明译配，可能误收漏标记录；公开样本只支持这些具体结果，不表示完整扩展实现或源站全量资料已通过验证。
