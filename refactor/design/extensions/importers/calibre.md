# calibre Importer 接入方案

calibre 导入器迁入书目、本人选择的记录与自定义字段、分组、资料笔记、文件及可转换标注。输入基线为 v9.16.0、提交 61c4027d2bfe737e0177e09952ee4942042a5892，SQLite 与 OPF 等格式依据见[源码及合成核验](../../../verification/evidence/calibre-importer/source-and-fixtures.md)。

<a id="scope"></a>

## 用途与对象范围

提供手动导入页面，迁入所选漫画、小说及其记录、整理和文件。书库与独立 OPF 均沿[共同流程](../importers.md#flow)以本地已知资料形成 prepared 输入，新建合法作品或更新明确目标；已有对象默认保留本地。联网补充独立发起，不登记在线资料 provider、账号连接、持续同步或源库写回。

calibre 的 Book 表示一项书库书目，可以包含多个格式，也可能对应单卷、出版版本或合订本。导入先核对实际粒度，再通过全部有效 ISBN／外部身份对应 Comic、Novel、ComicVolume 或 NovelVolume。类型与归属必须一致，身份冲突按冲突报告。

新作品由用户选择漫画或小说，类型没有默认值，可以批量设置。未对应的独立作品按来源已知资料新增。分卷长篇的单册只处理已有准确对应的卷；没有母体或明确分部对应时，不从标题、series、series_index、作者或文件夹造作品母体及目录。非虚构、工具书与不明范围不以 Novel 兜底。

series 可以是独立作品系列、作者选集或长篇中的分卷分组；它与 EPUB 的 collection/group-position 一样不能普遍证明卷身份。分卷记录中的评分、状态及喜爱不能提升为整作个人值；明确已读只设置对应 Part 的完成标记。单卷笔记关联已有所属作品，并保留来源卷名和范围。合订本的一个书目身份不自动展开为多卷。

## 输入系列与只读边界

| 输入                                             | 识别与可用内容                                                                                                                              |
| ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------- |
| 完整书库副本                                     | metadata.db 的 SQLite schema 28、必要表与列；书库目录中的格式文件、cover.jpg、可选 .calnotes/notes.db schema 1 及 resources；本项最完整输入 |
| calibre 随书 metadata.opf 备份                   | OPF package 2.0 与 calibre 元数据；普通字段、自定义列及实际存在的 calibre:annotation 包装；它不包含独立 notes.db 或 last_read_positions     |
| Save to disk／calibredb export 的 OPF 与相邻文件 | 当前 metadata_to_opf 结构；同一导出 basename 的 OPF、格式和封面按来源导出合同配对；可用内容以实际字段为准，普通导出不补造批注和续读数据     |
| 单独用作资料的 OPF                               | 用户选择“仅采用资料”后，以有效文件字段形成 prepared 候选，新建作品或更新明确目标；不将评分、自定义私人列或批注当普通资料                    |

“迁移书库记录”与“仅采用资料”表达输入用途；两种用途的新作品都可以直接采用合法本地资料，联网补充另行选择。CSV、HTML 书目目录、calibredb list JSON 和泛用 EPUB 内部 OPF 不在本次输入系列中，不能只因包含 title 就当作 calibre 备份。

书库输入须来自源程序与内容服务器停止写入后的完整一致副本。导入器先在任务私有目录固定数据库及其存在的 WAL／SHM 文件组，使用 SQLite 自身读取提交状态，不只复制主文件后忽略 WAL。变化中的输入、缺失或无效的必要日志不能拼凑成有效书库，也不启动 calibre 修复、升级或恢复。电子书从用户选定的持久书库位置登记，数据库私有副本目录不是正式媒体位置。

Node 侧使用宿主 Node 的 node:sqlite 只读连接，关闭扩展加载并设置 query_only 与 trusted_schema，显式查询已知普通表；不加载 calibre Python、插件、数据库触发器函数或 FTS tokenizer，不执行输入提供的 SQL、模板与脚本。自定义表名只由验证过的正整数列 ID 构造，参数值绑定。按任务预算分批读取和交付，正文与资源按需取得，每批之间响应取消，不把整库与所有正文一次送入 Webview。正式制品须验证源库含 FTS／自定义 tokenizer 时普通表仍可读，不能以移除用户表来解决读取问题。

OPF 使用命名空间感知的成熟 XML 解析器；关闭外部实体与外部资源，不运行 XML 中的内容。普通自定义值和批注包装按数据解析，datetime.datetime 只读取已知数据形状，不实例化类。必需结构不兼容在写入前拒绝；可选字段缺失按未知处理，选中的可选内容损坏只报告对应部分。

## 身份、书目与版本

books.id、books.uuid、library_id，以及 OPF 中 calibre／uuid scheme 都是来源内部身份，用于固定输入与同一批次中的关联和步骤对应，不注册为公开来源身份。可用的 ISBN 按本体规范校验并统一为 ISBN-13；其他 identifiers 只有实际类型和值符合已确认来源合同才采用，不把任意 key 或 URL 自动变成正式来源。

多个版本可能对应同一本体对象，多个格式也可能属于同一书目。先汇总目标，再核对来源个人值；冲突不能靠行序或最后修改时间覆盖，同一 Work 的完成初始化至多执行一次。公开身份可以正常复用，明确再次迁入的 Note 或历史仍沿共同规则新增。

| 来源内容                                                   | 采用规则                                                                                          |
| ---------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| title、排序标题、作者文字                                  | 名称及查询线索；明确选择保留名称时更新同范围对象，排序文字不成为别名                              |
| authors、publisher、author_sort                            | 展示实际署名及版本出版者；不凭名字创建 Person／Company 或猜测原作职责，人员资料主要由所选方案取得 |
| identifiers、languages                                     | 使用已验证的正式身份及语言值；未知标识保留在结果说明中，不构造身份空间                            |
| comments／dc:description                                   | 书目简介，安全转换后只在明确选择保留简介时采用，不默认创建私人 Note                               |
| pubdate／dc:date                                           | 当前书目出版日期；不能把单卷或再版日期覆盖为母体首次发行日期                                      |
| timestamp、last_modified                                   | 来源加入／修改时间，不当完成日期、活动区间或本体技术创建时间                                      |
| cover.jpg／OPF cover 引用                                  | 明确保留封面且范围一致时，经 attachments 正式接收；卷封面不自动替换整作封面                       |
| books_pages_link                                           | 与格式和算法有关的页数缓存，不当作品页数、已读进度或目录；文件技术信息由本体正常探测              |
| conversion_options、插件数据、book_storage、额外 data 文件 | 不执行转换、恢复插件或把任意额外文件当阅读内容；实际所选但无同义去向的内容说明未迁入              |

软件库迁移与纯资料 OPF 均默认选入可准确映射的普通字段，新对象使用 prepared 新增。已有对象默认保留，用户明确选择补空或覆盖时更新；缺席字段和关系保持原值。自定义列没有通用的“复制全部字段”，明确同义字段的采用规则见下节。

## 评分、自定义列与完成事实

本人评分只从用户明确选择的“本人评分字段”采用。calibre 内置 rating 可能合并下载来源的公共评分，因此默认保持不选。内置与自定义 rating 均按实际 0–10 存储值解释：0 表示未评分，1–10 乘 10，7 即 3.5 星并迁为 70。完整书库中，评分列存在而该书没有关联值时也表示未评分；OPF 未提供评分项或所选列缺席时表示未知。每次采用一个所选评分列的值。

自定义列按 custom_columns 的 datatype、normalized、is_multiple、display 读取。normalized 列通过独立值表和关联表取值，普通列按 book 读取；不能把含逗号的标签再次切开。OPF 使用 #value#、当前序列化的 is_multiple／is_multiple2 与已知日期包装。标记删除的列不恢复，composite 计算模板不执行；仅有导出的静态文本时，可以由用户明确选择作为文字保存，不能将模板结果直接解释成完成事实。

一个配置区域列出实际可用字段，用户为需要的语义选择列并设定必要映射，不猜 #read、#favorite、标签名或栏目显示名。

| 明确选择的语义 | 合法来源与处理                                                                                                 |
| -------------- | -------------------------------------------------------------------------------------------------------------- |
| 本人评分       | 内置 rating 或一列 rating；不把普通 int／float 不经量尺约定当评分                                              |
| 当前安排       | text／enumeration 的实际值映射为 planned、active、onHold 或 null；未映射值只影响该项                           |
| 特别喜爱       | bool 的 true／false；缺项是未知，false 只在明确采用已有个人值时清除                                            |
| 已读事实       | bool 或用户明确映射的枚举值；true 表示至少一次完成，false 不删除历史，null 不当 false                          |
| 整作完成总数   | 用户明确选定的 int 列，非负安全整数；只在 Work 的空历史上初始化，不向已有历史追加总量                          |
| 一次完成日期   | datetime 列；有效值可说明一次完成，合并已读或总数时不重复计数；总数为 0 却有完成日期等矛盾单独报告             |
| 私人文字       | comments、text 的所选列；html 安全转 Markdown，short-text／long-text 保留字面文本，markdown 按安全正文边界处理 |
| 标签与手动分组 | text／enumeration／series 等明确值；按整理规则采用，不推导状态、喜爱或卷归属                                   |

本项没有统一内置阅读状态、逐次完成历史或实际阅读时长。last_read_positions.pos_frac 即使为 1，也不生成完成记录；批注时间、最后阅读时间与加入时间不变成完成日期或活动。阅读页数、打开次数和自定义数值不伪装成实际区间；本项自定义列只采用上表已声明的语义，不按列名推断累计时长及其单位。

日期列按本次选定的日期时区解释，默认当前系统时区，可在列配置中修改。calibre 的 OPF datetime 包装使用 UTC，不能直接截取前十位而错一天。已知未定义日期 0101-01-01 和正常空值按未提供处理；合法日期直接采用，包括每月第一日，不增加精度提示、确认或自动备注。

新 Work 的个人值和初始完成记录放在 initial 中与条目共同提交。已有 Work 默认保留；明确采用当前值后使用对应完整操作，初始化空历史携带 expected.completionCount: 0。总数与一个完成日期同时存在时只给其中一次填写日期，其余未知。Part 只保存完成布尔事实，不保存卷评分、完成次数或完成日期。多个格式不会重复初始化记录。

## 标签、系列和资料笔记

整理默认关闭，可将所选 tags／自定义多值列采用为普通标签，将所选 series／自定义分组／user_categories 采用为手动合集。来源值按同一输入内的准确关联解析；已有同名合集不自动视为同一对象，用户可以选已有目标或在本次创建。

series_index 只提供该来源系列内的顺序，不改卷号或正式 Part 顺序。系列里的独立作品可按该顺序成为合集成员；多个卷归属同一 Work 时，该 Work 只出现一次，结果说明无法保留逐卷成员与顺序，不为此新建独立作品。已有合集保留原成员顺序并增补本次成员。

user_categories 保存“值＋所属字段”的引用，按实际值表／关联表取得本次成员，并集后建立静态合集；不把它的数字槽位当 book ID。层级名称保留来源全名，不创建本体没有的合集嵌套。虚拟书库、saved search 和基于模板的分类不转换成动态合集，也不执行 calibre 查询语言；没有成员明细时不猜测当前成员。

.calnotes 的 Note 属于作者、标签、出版者、series 或自定义分类值，不属于每一本关联的书。用户选择“资料笔记”后，一条源笔记创建一篇独立 Note，标题保留实际主体或分类范围；已有确定的 Entry 身份才建立关联，否则允许无关联保存。不能把作者笔记复制给所有作品，或把标签／合集强行变成 Entry。正文中的 calres:// 资源按声明的 hash、资源表和目录读取，经 attachments 保存并改写正式引用；不保留对来源缓存的依赖。

自定义私人文字及无法定位的批注可以关联对应 Work；仅有 Part 对应时关联其母体并保留实际卷名。comments 仍是书目简介，两者不混用。源笔记的 ctime／mtime 和批注 timestamp 不冒充本体创建时间；需要保留的来源时间作为正文出处，并明确原含义。正文或图片独立失败分别报告；远端图片不在本地迁移中自动下载。

## 格式文件与封面

完整书库按 books.path＋data.name＋小写 format 扩展名解析实际路径，不按标题重新猜文件名。用户可以指定持久书库根或明确的旧根与新根映射；核对路径、符号链接／重解析点、实际存在和本体支持格式后，通过 holdings 登记。每个实际文件保持独立身份、位置及必要 Part 关联；EPUB 和 PDF 不共用坐标，多格式不产生多部作品。

当前导出代码将 OPF 和格式保存为同一 basename，封面由 OPF 的实际引用确定。该配对规则只用于用户选择的 calibre 导出目录，不能扩展为任意相邻同名文件。孤立 metadata.opf 没有 data 表或明确资源引用时，不推算其书籍文件；仍可迁入独立资料和文字。

仅在 Part 已准确对应时建立该卷文件关联；其他情况保持所属 Work 下的文件，不以 series_index、阅读百分比或目录章节补关联。文件夹、ZIP 容器和 EPUB 目录不是作品目录。缺失或不支持的某种格式不阻止独立记录、其他文件和所选文字迁入；不制造可用的空文件登记。

封面与正文图片分别准备并持久保存。现有文件首选与续读位置默认保留，不因为源库中只剩一种格式就改写人工首选。导入不改写电子书元数据、不把批注嵌入 EPUB，也不移动或删除源文件。

## 批注、书签与续读位置

annotations 按 book、format、user_type、user 分域；last_read_positions 按 book、format、user、device 分域。页面分别列出两表中真实存在的使用者，默认可选本机批注 local／viewer 与本机阅读位置 local，缺席时不自动取另一人的数据。同一选定位置使用者的多设备记录按有效 epoch 取最近一条；同一时刻的不同位置报告冲突，不按行号决定。来源默认的占位使用者也是独立值，不与 local 合并。

只读取所选使用者的未删除批注。removed 是删除墓碑，不恢复为笔记。highlight 使用独立 start_cfi、end_cfi 和 spine_name；bookmark 使用 pos_type 与 pos；续读属于文件位置，不新建成一枚书签。颜色、来源界面样式和目录标题路径不成为本体持久样式。

calibre 的 CFI 与标准 EPUB package CFI 不能原样互换。书签／续读的首段表示渲染后 spine 序号，高亮端点从渲染 Document 起算；源程序还会整理 spine、替换封面正文并修复部分 HTML。迁入按以下明确范围执行，不以“能解析成字符串”判定定位成功：

| 来源位置                                                             | 转换与去向                                                                                                                                                     |
| -------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| EPUB 的正文文字端点，成员与原文树关系能够确定                        | 读取同一 EPUB 的 container、package、spine 和实际 XHTML；将来源端点解析到源节点与 UTF-16 边界，再重新编码标准 CFI。高亮保存完整起止锚点、原始 quote 与用户批注 |
| EPUB 书签／续读中的文本或源元素点位                                  | 先按当前已验证 calibre spine 规则确定原始成员，再解析、重编码；书签创建点位 Annotation，续读更新该文件位置                                                     |
| EPUB 修复／变换影响节点，但有唯一、可证明的源映射                    | 转换器必须把映射落实到实际原节点及边界后再采用；唯一 ID 断言可用于核对，不能只凭全文搜索或近似摘录改绑                                                         |
| calibre 文档／视口空间偏移、被替换的封面、无法唯一回到原成员或原节点 | 没有同义源位置；所选摘录、批注或有意义的书签标题保存为 Note，定位项报告未迁入                                                                                  |
| MOBI／AZW、PDF、FB2、TXT 等经 calibre 转换后的 CFI                   | 不转为这些原格式的字节地址、固定页码或 TXT offset；文字按 Note 保存，位置不迁入                                                                                |

转换不能只删除一个前缀或把 spine_index 插入固定模板。必须确认 package 中的实际 spine 路径、成员出现位置、来源与原始节点对应、UTF-16 边界、两端先后和完整范围；重复成员、路径改写、HTML 修复、实体、CDATA、换行与来源高亮包裹节点都纳入实现。失去精确来源关系时不能跳到首页、搜索相近句子或静默夹取坐标。

同一文件的判断来自实际输入关联与文件核对，不给正式位置增加 hash／contentRevision，也不按同名或同作品迁移到另一版本。转换时有 quote 可核对其指向，但不能由 quote 反推出丢失的精确范围。书籍曾在原位修改而来源没有历史版本信息时，本项不承诺证明历史字节一致；沿本体源位置语义处理当前可定位性。

合法续读坐标通过 holdings.files 的完整操作保存；来源 pos_frac 保留为输入事实，不直接充当 Kana 算法的显示进度，初始显示进度为 null，正常阅读后再由内核取得。位置采用不改变 Work 状态、完成记录、Part 已读或首选文件。已有位置默认保留，明确采用后才覆盖对应文件。

无法转换时只保存实际存在的人类可读内容，保留来源书目／卷和格式背景。没有摘录、用户文字、图像或有意义标题的纯定位失败项不创建假笔记。同批次继续复用已完成的批注或文字引用，另建批次明确追加时再创建，不按正文或位置合并不同事实。

## 页面、默认值与执行

一个页面完成输入、书目范围、字段映射、文件根、执行与实际结果。OPF 可选择迁移用途或仅资料用途。列表将书名、作者、ISBN、来源 series、目标、对象范围、格式和结果各放一列，窄宽度横向滚动，不增加整批差异审稿或逐项配对向导。

新作品类型由用户选择，来源普通资料默认选中。本人评分字段、自定义个人列、私人文字、资料笔记、整理、文件、批注和续读由用户明确选择，默认关闭；选中后只显示与该内容有关的配置。已有个人值、普通资料和位置默认保留，采用来源值另选。结果提供另行联网补充入口，导入不依赖资料方案。

开始后固定输入和映射，先核对身份与归属，再使用 prepared 与 initial 新增，或按所选范围更新已有对象，随后完成个人值、历史、文件、Annotation／Note 和整理。图片准备与正式内容提交遵守本体附件完整操作；创建 Annotation 前核对实际文件属于目标 Work，不靠两个外键分别存在。

每个本体完整操作分别提交，部分文件或批注失败不撤销已完成的作品与文字。取消保留已知结果，关闭观察页面不取消任务。结果和[批次进度](../importers.md#repeat)分别保存，继续原批次跳过已完成步骤，未知提交先核对；原始数据库行、私密正文、整份 annotations JSON 和源配置不写日志。
