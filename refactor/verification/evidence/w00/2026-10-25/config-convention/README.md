# 通用配置归属与辅助配置迁移

本轮基于 `93a06c29beddb41b1083549c004ab830fcc29ff5` 的当前工作区，落实已确认的[配置归属规范](../../../../../design/engineering/conventions.md#configuration-layout)。默认工具入口、明确共享的基线和工具专用目录保持原职责，内部配置按所属工程及工具归组，不以文件数量区别对待。

## 变更范围

八个公共包的 17 份辅助类型配置移入各包的 config/typescript；消费者样板的 1 份工具类型配置采用相同布局。同步更新根项目引用、tsdown 的库配置路径、消费者检查命令、源码覆盖检查和开发监听。现有开发回归改用新路径继续验证配置错误与恢复，没有新增重复的布局测试。

根工程、本体、33 个官方扩展及私有 Rust 工程已按配置职责核对。实际默认入口、共享 tsconfig.base.json 和原生工具位置保持；没有辅助配置的工程不增加空目录。通用规范、具体布局、作者模板合同和验收要求同时更新。模板和四个独立项目的正式实现状态不因本轮规范更新而推进。
