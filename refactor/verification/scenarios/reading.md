# Kana 与阅读宿主验收

使用固定格式输入与完整文档验证源定位、实际呈现、交互和发行消费，并记录真实浏览器版本。复杂出版物、辅助技术和完整阅读过程各自取得证据。

环境、证据与完成条件见[验收标准](../acceptance.md)，各场景引用对应设计规则。

<a id="settings"></a>

## 格式、设置与布局

A12 在漫画与小说中分别覆盖固定页面、可重排文本和混合文档。同一文档可使用的版式与控件不因 Work 类别而改变；固定页面中的文字选择与高亮按实际文件能力工作。先按文件、作品、全局选取本体完整 ReadingPreferences，再由阅读接入转换内核输入；混合内容不重选配置、不建立新会话，也不丢弃合法章节。

A12、A18 和 A29 按[本体阅读偏好](../../design/domains/preferences.md#reading-values)验证 flow、pages、text 与 colors 的完整值、默认值、单位和保存。原始页编组与正文分页分别可调，支持正文双面、独立插图单面；两种内容使用同一阅读流。document 明确跟随文档规则，不被当成缺失或上一级继承；原始页方向、正文主书写模式、段距及对齐按各自合同解释。

A12 和 A27 验证[偏好与内核边界](../../design/domains/reader.md#settings-boundary)：主应用类型、默认值与存储校验不引用或派生 Kana 设置，不因内核默认值变化而改变初始化或保存值。接入把 document 配色转成原书选择及已解析区域外底色，把 theme 转成内核 custom 的完整颜色对，把字体库引用转成本次字体资源；解析结果不回写原书或主题偏好。准备阶段引用不可用时保留主应用选择并明确回退，内核不读取应用资源身份或配置层级。内核接口变化只通过经核对的接入适配，不能自动迁移偏好或丢弃一个合法呈现选择。

A12 按[内核呈现设置](../../design/projects/kana/settings.md)与[排版规则](../../design/projects/kana/layout.md)核对实际行为：原始页 spread 形成左右对页组，连续浏览可以同时看见多个组；正文 pagesPerView 为 2 时形成左右生成阅读面，竖排同样遵守该含义。连续正文保留但不采用分页面数，正文内的普通插图不自动变成固定阅读单元。文档明确页位、从书中间打开、中途原始插图及混合边界均遵守配对规则，空位不增加源身份或进度，实际布局不反写偏好。

A12 验证正文基准字号有效改变正文并保留标题、小字和 ruby 的层次，行长沿实际行方向解释，留白同时适用于分页和连续正文。表格、诗歌、代码和图片保持自身结构；明确阅读配色成对采用前景与背景，原始页面保留本色。仅改根字号或给全部元素同一字号，不能代替这些断言。

## 样式转换与作者输入

### 读者样式覆盖

A12、A18 和 A27 按[读者样式](../../design/projects/kana/styles.md)验证所选字体覆盖普通阅读文字并保留强调与后备字体，私用区同码位冲突不会替换书内特定字形；最小现有元素可能整体保留原字体，不为保护字形插入改变作者上下文的包装。普通正文行高实际覆盖绝对声明，段距沿逻辑块方向采用且不双倍叠加，标题、注音、代码、数学、诗歌与表格保持相应结构。保留图形还包括实际依赖的继承与背景，不能只跳过 SVG 标签。

按[统一转换次序](../../design/projects/kana/styles.md#conversion)核对语义／盒范围、作者基准、按属性保护和反复更新。正文覆盖不借修改 HTML 根一起放大 rem 图形；零字号保持源含义。行内 important 和伪元素覆盖使用已确定的优先级，撤去读者写入后恢复的是完成必要展示转换的基线，CSS 对作者原值的读取仍然成立。普通字号调整保留源节点、Range 和焦点，不通过重新创建语义文档换取干净样式。

复杂背景保留实际绘制关系，注册自定义属性、普通 token、currentColor 和图形字形分别保持其含义；颜色保护不自动冻结普通文字的字号。伪元素参与样式转换，但不成为摘录文字。多投影采用相同的源交互状态，只有语义文档具有真实焦点；原生动画、读者属性过渡和 readView 的当前帧保持按同一布局次序衔接。

可读资格覆盖 visibility 的后代恢复、display:contents、源字号与透明度、尚未驻留与作者隐藏的区别。原生空白容器只回答必要的空白行为，不移动用户 Selection，不用整章 innerText 重建源地址；保留区间、折叠区间和正文结构分隔分别对应来源。自动范围分类、完整语法、动画、复杂出版物和支持环境分别验收，已有[组合场景](../evidence/kana-style-conversion/conversion.md)保留其实际范围。

### 作者样式输入

A12 和 A27 按[作者样式输入](../../design/projects/kana/styles.md)验证外部样式表、style 元素与 style 属性保留各自基址、层叠层、条件和出现次序，嵌套导入不按网络完成顺序采用。普通变量中的 URL 按实际使用位置解释，注册属性遵守自己的计算值规则；命名空间 URI、条件语法与普通字符串不误作待加载资源。优先保持相对目录关系和原属性；必要改写仍保留作者属性选择器、受支持的 attr 读取、命名空间、属性有无与权重。读者设置从作者基准派生，不累计采用上一次覆盖结果，也不冻结全部计算样式。实际资源传输与整包部署另行验收，受控 HTTP 对照不代替它们。

### 阅读配色

配色分别核对本体 document／theme／custom 的保存恢复及内核 document／custom 的公开输入。原书配色保留作者颜色与文档画布，缺省黑字不直接铺到宿主暗底；明确阅读配色成对覆盖普通文字与色块，避免浅字白底，允许统一原书的颜色区分。图像与依赖背景的图文组合保留必要整体关系，链接仍可识别，标记投影独立。内核 document 仍需要区域外 background，不能借该分支覆盖正文 foreground；没有判别分支的旧颜色对不构成另一种输入。

## 资源传输与取消

A12 和 A27 按[资源加载与部署](../../design/projects/kana/resources.md)验证浏览器与 Electron 共用包内 Service Worker，内容请求保持目录关系并由授权资源拥有者交付，不要求宿主解析书内成员。同源资产、专用作用域与 Electron 协议能力满足公开接入条件，缺少必要能力时明确报告 assetUnavailable；模块导入不登记 worker。内容 CSP 与实例、成员权限共同限制加载，越界和失效请求不回到网络。关闭一个 Reader 撤销其内容地址和读取，不影响其他实例，也不注销仍在使用的静态登记；worker 重启不丢失仍存活的合法资源拥有者。分块传输、背压、预算、取消、已有 PWA、版本作用域、登记冲突与清理均须在实际接入中验证，局部机制试件不代替整包及维护窗口验收。

交付采用[原生可转移流](../../design/projects/kana/resources.md#streams)，没有按浏览器切换的 chunk 备用协议；借入缓冲保持有效，排队和在途读取遵守各自限额。取消或中途失败不交付部分成功，一个释放失败仍等待其余释放。覆盖元信息尚未就绪时关闭、拥有者消失、活动 worker 中断、存活端点的正常慢操作，以及同页独立库副本分别路由。登记存在不能代替安装完成，取消打开不发布迟到入口；旧版本消费结束后清理其登记，不影响新版本与 PWA。临时对象创建或写入失败时停止输入并清理，不转为整份内存快照；原生内部预读和后端容量不得被误报为已经受某个总 MB 上限控制。

## 呈现、浏览器范围与分页

A12 和 A27 按[呈现与交互机制](../../design/projects/kana/layout.md)验证按实际阅读面建立完整章节投影，各面共用同一源解释、格式索引和 Reader 状态。横排和两种竖排均形成正确的左右阅读面，相邻片段无缺字或重复，源范围跨面连续，起始空槽位不插入源内容节点。各面字体和设置由同一次布局采用，附加 DOM 占用计入预算并正常释放；辅助技术不重复交付全文，焦点与逻辑源位置保持一致。显式一／双面不因窗口变窄而切换或缩小字号；无法形成阅读区域时以 layoutUnavailable／insufficientSpace 结束该次操作，既有 Reader 不因此结束，failure 不被写成该局部失败。隐藏与恢复、重排后的源落点、同轴接续、换轴时的惯性与焦点分别核对。

Kana 的终态浏览器验收覆盖[范围与维护窗口](../../design/projects/kana/README.md#browser-versions)：Chrome、Edge、Firefox 常规通道的当前稳定版，macOS Safari 当前正式稳定版，WebKitGTK 当前稳定系列最新维护版，以及 Electron 最近三个稳定主版本的最新稳定更新。记录每次发行实际验证的运行时、系统与构建，不以 Kisaki 单条运行线代替三条 Electron 线，不以 Windows WebKit 测试构建代替 Safari 或 WebKitGTK。普通自动分栏通过不代替显式分页、复杂作者样式和完整输入验收；移动端、ESR、扩展稳定通道及长期固定旧版分支不构成另行维护范围。运行不查询在线最新版或只按 User-Agent 拒绝打开。

正文根基准与作者元素计算字号的比例在绝对字号、相对字号和重排后保持；正文根 16px、局部段落 14px、目标基准 20px 时，该段应为 17.5px，不被强制为 20px。固定图像尺寸不随普通文字统一放大，原始源位置不变。ReadingView.forwardDirection 与 pageSlots 对应已采用布局，固定页面数非空、连续重排为 null，视口里同时可见多个组不改变该字段的含义，主应用不据此回写偏好。

A12、A14 和 A27 按[作者断页规则](../../design/projects/kana/layout.md)与[分页支持边界](../../design/projects/kana/layout.md)验证格式结构和 CSS 能力。章节切换、固定源页及格式页位形成正确阅读顺序；单面只产生可见阅读面，连续正文保持连续流。

支持的 CSS 断页核对前后内容、间距和源映射，相邻 before 与 after 按同一边界处理。外部 CSS、style 元素和 style 属性均进入相同流程。Firefox 当前的强制断页缺口按已声明限制验收，并保持自然流、自动分页、内容、定位和选择可用；解析成功本身不代表排版支持。

## 选择、焦点与辅助技术

A12、A14 和 A27 验证指针选择从起点到跨章由同一拥有者协调，反向、链接单击、双击选词、原生投影、失焦与取消不会形成第二个正式选区。复制固定当次源范围，异步读取与用户激活条件正确衔接，失败保留选区且不写入部分文字；宿主输入框和其他 Reader 的选择不受影响。键盘、触控、辅助技术及真实剪贴板权限属于完整验收，局部 caret 或载荷构造通过不能替代。

A12、A14 和 A27 按[语义文档与焦点机制](../../design/projects/kana/interaction.md)核对同一内容出现的语义入口唯一，显示副本保留精确命中但不形成第二套键盘焦点或原生选区。跨面时只调整稳定语义文档的显示偏移与位置，不能重建 iframe 而丢失节点身份；重排后源目标、实际聚焦元素及可见焦点保持。顺序焦点操作遵循平台与用户键盘设置，包括 Safari 适用的 Tab／Option-Tab 行为；内容与宿主控件通过相应操作可达，默认遍历能够完成时不被额外处理器接管。链接点击与文字拖选分别处理，原生激活不按 click.detail 为零猜测，也不重复触发源动作。

实际辅助技术必须分别验证标题、链接、语言、虚拟游标、跨章连续阅读、参考查看与焦点返回。DOM 焦点不冒充正在朗读的源位置；章节释放不能只按像素视口判断。原生无障碍树的一次入口检查不代替 NVDA、VoiceOver、Orca 等实际流程，也不要求隐藏副本在浏览器内部完全没有对应树。

[完整输入方案](../../design/projects/kana/interaction.md)进一步规定原生改选入口、手势取消、跨章迟到结果、桌面长按与拖柄、IME／控件优先、完整复制与本体通知。A12、A14 和 A27 在实现中核对这些同一动作的连续过程，不为每个输入重新建立选区模型。

辅助技术按稳定语义范围验证连续朗读，并通过明确导航接续章节或页组；仅滚动、预取或预算压力不得淘汰活动语义范围。宿主同步按键回调验证局部优先、同步返回和单次处理，主应用通过公开入口接入，不读取私有 iframe。

## 整包消费与文档执行边界

A12、A23、A27 和 A28 按[整包接入](../../design/projects/kana/distribution.md)验收单入口的真实代码与声明、worker／WASM、完整资产清单和独立 tarball 消费。缺失 JS／Wasm、版本错配或 HTML 回退不能作为成功加载；不同 Reader 的 PDF／ZIP 执行范围、资产地址和关闭相互独立。构建完整复制实际依赖闭包，接入提供必需的 assetsBaseUrl；Kisaki 只映射偏好、持久位置、标记和产品会话，不导入私有格式源码；实际保存与重开保留位置及 Annotation，产品会话正确收尾。

A12 和 A27 按[内容文档职责](../../design/projects/kana/layout.md#documents)验证正常排版、点击、资源加载与执行边界共同成立：内容 CSP 在书籍内容进入活动文档前建立，书内脚本与事件属性不执行，资源从本次授权入口读取，书籍样式不影响宿主。sandbox 参数可以满足实际事件接入需要，不以是否出现 allow-scripts 单独判定通过；启用该参数时仍须证明内容执行限制成立，不把同一个条件重复当作多份保障。宿主业务与系统能力不注入书籍内容。

## 阅读路径与操作完成

重复 spine 的普通 href 按[出现选择规则](../../design/projects/kana/positions.md#order)验证：当前资源的第二次出现内跳转仍保留第二次出现；从另一资源跳入时选择正文路径的第一次出现；只有 non-linear 出现时选源顺序第一项。片段错误不改选其他出现，已有完整 CFI 始终严格恢复指定出现。

A12、A14 和 A27 按[阅读路径与运行边界](../../design/projects/kana/api.md)验证正文 A—独立辅助内容 N—正文 B：普通阅读与 A 到 B 的摘录经过正文路径，搜索和标记仍可访问 N；明确进入 N 后在自身路径边界停住，正文进度为 null，返回历史仍有效；临时查看不改变主进度。正文与独立路径不能形成同一个连续文字范围，源地址和标记排序不受访问历史影响。

A12 验证必要正文或页面未就绪、字体失败后允许回退、取消及窗口变化下的完成条件：只有实际可读目标与必要布局成立才采用新位置；fonts.ready 完成不能冒充字体成功。移除兄弟内容或表格行后仍有相同源端点，不足以证明巨大章节分片有效。搜索与预取使用余量，取消搜索不释放正文仍在使用的资源；根输入确认变化时以 sourceChanged 结束 Reader 并保留最后可信位置，普通局部失败不扩大为整实例结束。

## 格式、文字、地址与索引

A12、A14 和 A27 按[格式解析与输入](../../design/projects/kana/formats.md)验证共用 Expat 语法后端与本地标准实体目录：正常 XHTML 字符实体、内部声明覆盖、FB2 源树及编码结果一致；任意外部读取不会发生，需要不可取得实体的正文明确失败，未使用的外部声明不被一概拒绝。取消、资源上限和解析失败不发布部分源内容。CFI 严格恢复完整源含义，MOBI／KF8 在转换前保留原始分支和字节地址，HTML 修复不改写这些身份。

XML 扩展编码使用已确认的固定 libiconv 与 CP932 映射校正，核对 BOM／声明一致性、合法别名、未知名称、非法与截断字符、原生及转码路径、EPUB 编码限制和工作线程中的实际接续。原生编码不加载转换脚本或 Wasm；转换资源失败、预算、取消、读取失败与 sourceChanged 分别保留真实类别，读取收尾完成前不报告成功。发行校验包括固定编码名数据、许可与对应源码、校正、重建步骤和可替换资产；不根据候选测试数量声称完成所有编码符合性。

CFI 另核对精确数字、完整转义和范围、真实 package／spine 路径、原 XML ID、重复出现及嵌套引用链、空文字槽和严格文本断言。显示 Text 拆分、包装、重建与重排后仍回到完整源端点；未知扩展参数、side bias、alt 和媒体终点不能被截掉或改绑。书内范围链接采用起点，持久文字范围保留两端；合法源值与是否可呈现分别判定。[扩展机制记录](../evidence/kana-cfi/cfi.md)不替代完整 EPUB 符合性、真实出版物或跨章节交互。

固定 KF8 验证原始版式、固有视口、skeleton 页面身份、FDST 资源、内部链接和页内字节地址。压缩方式、RTL 与缩放改变呈现，源文档编号保持稳定；缺少有效视口时失败，文字能力按源内容判断。

页面就绪核对实际 HTML 根与几何。[二进制与三引擎试件](../evidence/kana-kf8-fixed/fixed.md)提供关键路线依据，真实出版物、双页与方向交互、复杂样式、支持方言和完整 Reader 继续按正式阶段验收。

原文和搜索按[带来源的文字流](../../design/projects/kana/content.md#text-flow)验收：跨 Text、存储块和章节保留空白、字素、规范化与源范围对应；独立路径和注音分支不交错拼词。隐藏内容移除、空白折叠后形成的匹配不能被原始字符串预筛漏掉，excerpt 保留原文。验证消费者暂停和完整摘录所需的实际读取，并复用既有源地址与资源测试，不重新建立一套定位权威。

[源索引](../../design/projects/kana/formats.md#indexes)核对有状态解码、XML 派生记录、按页索引和上下文驻留，暂存写入须完成后才能被读取；原书位置不依赖缓存块编号。性能验收测量真实热数据、解析峰值与单次结果，容量调参不成为新公开偏好。[结构进度](../../design/projects/kana/formats.md#progress)核对页序、TXT 的完整分母、重排估算、重复 spine 和独立路径；加载或改字号不切换进度权重，100% 不产生完成记录。

图片容器按字节类型与必要元信息建立页表，ZIP 和目录采用同一自然排序，保留成员的大小写及 Unicode 身份；支持类型、SVG 来源、固有方向和动画的单页身份按所属解码器验收。已识别的损坏或未支持图像不能靠删页改变后续编号。完整图像与出版物执行相应回归，已有[格式组合证据](../evidence/kana-format-integration/integration.md)保留其实际范围。

URL 验证打开阶段的 Range 或单响应快照选择，包括强 ETag、If-Match、CORS 可见性、HTTP 解码、实际字节预算、取消和临时文件收尾；输入发布后不拼接新版本或切换为另一份快照。明确来源变化与普通读取失败分别分类。图片目录和 ZIP 使用同一固定自然排序，覆盖大小写、Unicode 十进制数字、前导零、超安全整数与目录分组；持久 memberPath 不随页序变化，损坏页不通过删页和重编号掩盖。机制试件不能代替固定 KF8、完整源映射及真实大输入的验收。

## 作品内容列表

A12、A18、A19 和 A29 验证[阅读器实时内容列表](../../design/domains/reader.md#work-navigation)：主按钮、分部、单文件和深链打开后，均可浏览当前作品的完整资料与文件。漫画分别按作品卷序、作品话序和所选卷的收录顺序导航，小说按卷序导航；文件视图按完整文件顺序，每个文件只显示一次。只显示未读的第 3、5、8 项时，下一项仍指向完整范围的第 4 项，不跳到第 5 项，也不因未加载而漏掉目标。

新增分部、重排或改变漫画收录后，列表与后续相邻项采用当前正式事实，不保留打开时的冻结清单。详情与阅读器的筛选互不驱动，切换查看方式不换文件。没有分部时可直接阅读；合订文件不能由入口推定当前卷或话，同文件复用不归零、不增加重叠活动，也不自动跳过。下一项缺失、失联、归属变化或加载失败时准确反馈，已发出的请求不改投新目标。末尾停留，同作品切换保留视图，跨作品切换清除旧筛选及从属范围；这些操作均不自动传播完成状态。
