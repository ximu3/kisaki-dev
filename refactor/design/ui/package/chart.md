# 通用图表

`/chart` 使用 Unovis 1.7.1 官方 Solid 适配。XY 容器承载折线、面积、分组柱、堆叠柱、散点、坐标轴、Tooltip 和 Crosshair。单图容器可承载环图。图形与反馈部件作为子组件加入相应容器。统计视图拥有查询、数据聚合、单位、可见系列和动作，向容器提供名称及可读摘要。

## 系列与主题颜色

主题提供[五个图表色槽](../../domains/appearance.md#tokens)。第一槽是单一指标的默认数据色。表示同一指标的折线与面积可使用同槽，面积采用较弱密度。活动热力图以同色深浅表达量级。仅在数值本身代表成功、警告或失败时，才采用相应的业务状态色。

并列类别通过稳定的系列键绑定颜色。例如，图表可以将游戏与动画分别绑定第一、第二槽。采用默认分配时按声明的系列次序分配五个槽。更多系列可以循环使用并以标签、线型或标记区分，调用方也可指定系列颜色。过滤、排序及图例隐藏改变可见集合时沿用原映射。切换主题用新分支在原槽位的颜色重绘。柱、线、图例标记和提示内容共用系列身份。这个约定让同一条线在切换日期范围后仍可辨认。[图表配置与主题色槽示例](https://ui.shadcn.com/docs/components/chart)

主题容器把正式呈现变量映射到引擎样式。坐标文字取文字色，网格取边界色，提示表面取浮层色、圆角与阴影。Unovis 的内部色号由适配层处理。使用严格样式 CSP 的宿主在首次导入图表家族前按引擎的公开方式设置 nonce。[Unovis 主题](https://unovis.dev/docs/guides/theming/) · [Unovis CSP](https://unovis.dev/docs/guides/csp/)

## 交互、更新与释放

图例用具有名称和按压状态的按钮报告对系列的操作，宿主决定显示结果。Tooltip 与 Crosshair 将数据格式化为文本节点，来自资料的标签字符按文字显示。读屏名称、摘要或文字替代随数据更新。

Solid 适配创建图表、登记子组件、更新数据与配置，在拥有者结束时销毁实例并释放观察与提示。布局回调交付只读尺寸、边距等几何结果，实例和渲染 DOM 由适配持有。公开配置沿用工具的公开类型。制品汇总实际使用的声明，并显式声明生成结果仍引用的类型依赖，使仓库外 NodeNext 与 Bundler 项目都能完整检查。[Solid 接入](https://unovis.dev/docs/intro/) · [声明依赖处理](https://tsdown.dev/options/dependencies)
