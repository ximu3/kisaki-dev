# W05 公共 UI 验证

2026-11-05 在 Windows x64 验证 `@kisaki3/desktop-ui@0.1.0-dev.0`。消费者使用 Solid 1.9.16、TypeScript 6.0.3 和 Chromium 156.0.8078.4。范围是 [W05](../../../implementation/work-packages.md#w05) 在 A18–A20、A23、A29、A31 中承担的公共组件断言。

## 制品与运行

`pnpm exec turbo run test:consumers --filter=@kisaki3/desktop-ui` 构建组件、声明与普通 CSS，生成并检查 tarball，再将 UI 包及对应的 desktop-appearance 制品安装到仓库外的[独立 Solid 工程](../../../../clients/desktop/packages/desktop-ui/tests/fixtures/consumers/solid)。消费者直接导入组件家族和样式，在 Bundler、NodeNext 下完整检查全部公开声明，并执行类型感知 lint。浏览器构建使用成品 CSS，初始模块图与按需打开的图表、Markdown 和拖拽模块分开。

| 边界       | 实际操作与结果                                                                                                                                                                                                                                   |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 表单       | 读取 FormData 与实际校验结果。文本、选择和勾选在原生重置后与草稿一致，阻止重置会保留修改。禁用 fieldset 会移除提交项，已失效的必选项使表单无效。用 Chromium 的输入法协议在组合中改变外部值，再提交最终文字。                                     |
| 键盘与浮层 | Combobox 用方向键浏览、Enter 采用、Escape 放弃查询，结果集改变仍保留已选标签。嵌套模态逐层归还焦点，被阻止的关闭保留编辑器。验证菜单跳项、按文字定位、上下文菜单、Popover、Tooltip、Toast 和 Tabs。                                              |
| 视觉       | 对照既有工程 `e311fe7c` 的按钮变体、尺寸与输入密度。成品在亮暗两套外观下检查了禁用、选中、悬停、按下、键盘焦点和字段错误。默认 14 px 基准下普通按钮高 24.5 px，150% 缩放后为 36.75 px。浏览器默认正文边距仍为 8 px，宿主覆盖主色后按钮随之更新。 |
| 图表       | 在加载图表前提供 CSP nonce。XY 和单图容器实际渲染 SVG，图例控制序列，数据变更更新图表。Crosshair 提示中的标签字符按文本呈现，离开视图释放两幅图和提示。                                                                                          |
| Markdown   | 用编辑命令修改选区并撤销，在输入法组合中接收宿主更新。两个预览独立呈现表格、只读任务列表和脚注。原始 HTML 作为文字，未映射图片显示替代文字且无网络请求，普通链接交给宿主。卸载编辑器时宿主收到引用失效通知。                                     |
| 拖拽       | 键盘与指针移动共用稳定目标。筛选子集保留隐藏槽位，多选保留组内顺序。真实边缘滚动使源行卸载后仍能落下，网格取消与不可用目标保持原顺序。写入冲突由宿主采用最新顺序，结束列表释放监视与播报区域。                                                   |

本机 `pnpm check` 和 11 项独立消费者检查通过。运行报告及亮暗控件、按钮状态和图表截图位于包内 `test-results/consumers`。组件的浏览器支持以[桌面 Chromium 能力基线](../../../design/ui/package.md#delivery)为准；产品窗口和扩展视图的实际组合随各自工作包验收。
