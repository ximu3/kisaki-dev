# 控件、表单与内容导航

<a id="presentation"></a>

## 基础呈现

Button 执行动作，默认使用 `type="button"`，调用方显式选择提交或重置。Link 使用带目标地址的原生链接，保留复制地址、修饰键和浏览器导航行为。普通、危险、描边、次要、透明、链接或文字外观，以及紧凑和图标尺寸，按[现有体验](../components.md#existing-ui)核对。次要按钮与次要徽标都可使用主题的 `secondary` 色对。

作者提供内容、图标、名称和状态。只有图标的按钮也要具备独立可访问名称。Badge 表示简短标记，Separator 表示内容分隔。Spinner 表达进行中的工作，Progress 使用原生进度语义表达已知或未定进度。Alert 与空状态呈现调用方提供的消息和动作。Image 展示宿主交付的 URL，当前来源缺失或加载失败时呈现替代内容，来源变更后加载新图。图片的取得与撤销归宿主。

<a id="forms"></a>

## 字段与原生表单

Field 关联可见标签、说明、错误与实际控件。说明固定解释字段用途，错误状态可访问且保持原有布局。FieldGroup 使用 fieldset 与 legend 组织相关字段。提交校验汇总和错误定位遵循[表单反馈](../components.md#validation)。

| 控件            | 值与交互                                                                                                    |
| --------------- | ----------------------------------------------------------------------------------------------------------- |
| Input、Textarea | 按原生元素编辑字符串，保留输入法组合、选区、复制粘贴和撤销。组合结束后再与宿主采用的文本对齐。              |
| Checkbox        | 布尔勾选决定提交项。部分勾选可表达一个集合的状态。                                                          |
| Switch          | 用独立的开关接口和原生可勾选输入表达启用或关闭，提供开关名称、键盘操作和表单接入。                          |
| RadioGroup      | 用同一表单拥有者下同名的原生 radio、fieldset 和 legend 表达一个字段的互斥选择。选中项提供提交值。           |
| Select          | 使用原生 select 与 option。单选收起时显示所选名称，展开后可显示选项说明。多选以同一个字段名提交各个有效值。 |
| Combobox        | 让用户输入查询，在结果中选择一个有稳定值的选项。查询、当前选项和宿主交付的结果集分别表达。                  |
| Slider          | 使用原生 range 的范围、步进、键盘与数值，交付浏览器按约束采用的值。                                         |

原生属性作用于真正参与编辑、校验与提交的控件。name、form、默认值、required、disabled、fieldset 禁用与外部表单归属按实际组合生效。FormData 按原生控件的提交规则取值，约束校验决定正常提交能否继续。受控选择中禁用或缺失的选项退出有效选择，界面与提交值反映其余可用项。

受控模式由宿主提供当前值，非受控模式由组件和原生控件接续默认值。用户编辑后报告实际输入，宿主可采用、规范化或拒绝该输入。受控控件在本次编辑完成后反映宿主最终值。原生 reset 完成后按默认状态报告重置结果，受控宿主接续这一结果或提供自己的值。被阻止的 reset 保留原有输入。组合中的文本由输入法持有，同值回写应保留光标和撤销历史。[HTML 表单](https://html.spec.whatwg.org/multipage/forms.html) · [表单分组](https://www.w3.org/WAI/tutorials/forms/grouping/) · [Solid 响应式属性](https://docs.solidjs.com/concepts/components/props)

Combobox 把 DOM 焦点留在输入框，方向键浏览已加载的可选项，Enter 采用活动项，Escape 退出查询并恢复已选标签。键盘引用指向真实渲染的目标。异步加载、空结果和失败由宿主提供，翻页或更换查询结果保留仍有效的已选值和名称。表单提交该项的稳定值，必填校验定位到可见控件。[Combobox 交互模式](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/)

## 分段选择与页签

SegmentedControl 切换少量并列模式，例如阅读器的单页与双页、趋势图的日／周／月。它独立呈现一个有可访问名称的按钮组，每项使用 `type="button"`，以 `aria-pressed` 表达当前模式。调用方提供稳定值、标签、可选图标和禁用状态。空间较窄时可只显示图标，项目的可访问名称仍然完整。

Tab 进出整组。进入时优先聚焦当前可用项，方向键在可用项之间移动焦点，Enter、Space 或点击采用该项。重复激活当前项保留选择。暂时不可用的已选模式可以同时显示选中和禁用，焦点移至可用项，实际设置由宿主决定。分段选择放进表单仍只报告模式变化，原生提交与重置由表单字段参与。[按钮按压状态](https://www.w3.org/WAI/ARIA/apg/patterns/button/) · [分组与键盘焦点](https://www.w3.org/WAI/ARIA/apg/practices/keyboard-interface/)

Tabs 导航具有各自面板的内容。页签、列表和面板共享本实例的身份，tab 与 tabpanel 互相关联。Tab 进入当前页签，方向键沿列表方向在可用页签间移动，Home 与 End 定位首末。可立即呈现的面板支持随焦点激活，需等待内容时可用 Enter 或 Space 明确激活。首次激活时挂载内容，切换回已访问面板保留其局部编辑状态，移除页签时释放相应内容。[Tabs 交互模式](https://www.w3.org/WAI/ARIA/apg/patterns/tabs/)

Collapsible 使用原生披露控件呈现可展开的内容。Table 提供表题、表头、行与单元格等表格语义，窄宽度下通过水平滚动访问所有列。ScrollArea 提供可聚焦的原生滚动视口。行身份、选择、查询和虚拟几何归实际视图。
