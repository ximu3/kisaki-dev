# Koodo Reader Importer 接入方案

Koodo Reader 导入器迁入作品资料、喜爱、最低完成事实、书架、私人文字、累计时长及可转换的位置。输入基线为 [v2.4.6](https://github.com/koodo-reader/koodo-reader/releases/tag/v2.4.6)、提交 1fd0cc7f151916447d396e0c8a2c036180992cab，以及 Rangy 1.3.0；格式依据见[合成核验](../../../verification/evidence/koodo-importer/source-and-fixtures.md)。

<a id="scope"></a>

## 用途与输入

提供一个本地手动迁移页面，迁入用户明确选择的漫画与小说。文件后缀不能决定作品类型；PDF、EPUB 都可能属于任一类型，其他书籍不为了迁移笔记而伪装成 ACGN 作品。导入器不提供资料 provider、源账号登录、持续同步或源应用恢复。

支持以下两类输入，页面一次选择一种：

| 输入                                                       | 识别与范围                                                                                                                                              |
| ---------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 当前 SQLite 备份 ZIP，或源程序关闭后取得的一致数据目录副本 | config/books.db 为书目入口，按选择读取 notes.db、bookmarks.db、words.db 与 config.json；book/、cover/ 是可选资源，单数目录名有实际含义                  |
| 官方笔记／高亮 JSON、CSV，及其多书 ZIP                     | 明确的字段、exportType、书籍关联与文字；JSON 根为数组，CSV 使用真实表头和标准引号解码；多书 ZIP 有 all.json／all.csv 时只读取这一份，不能再叠加各书文件 |

备份按必要 SQLite 表、列、值形状和配置结构识别，不因 ZIP 名称、appVersion 或用户填入版本号接受未知结构。支持的是本页列明的当前家族；旧 JSON 全库备份、浏览器内部 IndexedDB 文件、任意 localforage 库及源插件私有库不属于本输入。

普通“导出书籍”得到的媒体 ZIP 不含完整资料与记录，不当作全库备份。用户可以另行提供实际媒体，依文件规则核对。HTML、Markdown、TXT 或 PDF 形式的笔记展示导出不作为结构化记录输入，也不从排版反推源键和位置。

归档根必须唯一，允许明确的单一外层目录；不从多份备份或嵌套 snapshot 中自行选择。没有 books.db 的全库输入拒绝，缺少可选数据库仅影响所选范围。普通路径模式可能没有内置书籍字节，不能因此把整份书目判坏。

## 只读解析与本次关联

SQLite 使用受维护的读取库和只读连接，启用 query_only、关闭 trusted_schema 与扩展装载，不执行来源 schema 中的触发器或脚本，不迁移、修复或回写源库。目录副本须先具备一致性；不能将仍在变化的主库文件与任意时刻的 WAL 拼接为成功输入。

只查询本页需要的字段。books、notes、bookmarks、words 是各自数据库里的实际表名；不读取 plugins.db 的代码和配置，不恢复 sync.json、账号、AI 服务、第三方 token、字典、字体、背景或阅读器主题。未知可选列保持未知；必要结构损坏在写入前拒绝，独立可选值无效只影响该值。

config.json 是外层对象，其配置值本身通常又是 JSON 字符串。favoriteBooks 等列表、shelfList 等映射和 recordLocation 等对象分别解码、校验；不能将双层 JSON 当作一层，也不能把解析失败解释成空列表来取消喜爱。源 dumpConfig 会省略未存储的配置，因此缺席与明确空值不同。

Note.date、WordHistory.date 是以 JSON 文本保存的日历对象，Note.tag 是 JSON 数组；SQLite 声明 color 为 integer，但当前颜色实际可为 background-#HEX 之类的字符串，不能按列亲和性强制转为整数。

Book.key 只在本次输入内关联笔记、书签、书架和配置。相同键、相同有效内容在一个输入集合内只处理一次；同键矛盾、重复 JSON 属性和互相冲突的成员不能按最后出现值覆盖。独立导出依书目键与同一输入来源关联，不以分书文件名、bookName、行号或数组位置代替身份。

归档成员、SQL 文件、行数、JSON 深度、CSV 单元格、正文、图片与展开总量均有明确预算。拒绝穿越、绝对成员路径、盘符、链接、重复成员和目标文件系统下的名称冲突；只读所需字节，不执行包内代码。错误只记录有界标识及安全原因，不输出完整配置、源行或私人文字。

## 作品、分部与本地采用

Book.key 用于源书籍记录的内部对应。Book.md5 与导出的 bookMd5 是整文件 MD5，用于本次实际文件核对。作品通过准确的公开身份对应，版本、合集和不同作品按各自语义区分；同名或同摘要的记录保留这些区别。

目标按本次明确的本地 Work／Part、已登记文件的真实归属及合法公开身份对应。只有文件归属和作品范围无歧义时才复用；hash 用于核对字节，源键与摘要仅在本批次中用于继续执行，不建立新的公开 external ID。

没有对应作品时，以本次选定 Comic 或 Novel 类型、真实书名及可准确映射的来源字段形成 prepared 输入，经 ingest.add 新增。有效喜爱与初始完成事实随 initial 提交。最低字段或对象范围不足的项目报告未迁入，已有对象默认保留；联网补充不作为导入前提。

来源一本书不一定是一整部作品。单卷只关联准确的原生 Part；没有准确卷归属时，文件可以关联已明确的 Work，不能把该卷“已读”升为整部作品完成。EPUB 目录、PDF 页数、文件列表和书架都不生成卷话结构。合订文件可以保留为实际 Work 文件，但没有准确范围时不补造多个分部跳转点。

独立笔记导出没有完整书目库。bookName 可提供真实书名，bookAuthor 保留署名文字，bookMd5 只能核对实际文件。用户可在执行前为书组明确已有目标或新作品类型；没有真实名称和归属的记录报告未迁入，不把 Unknown book 兜底文字创建成作品。

<a id="metadata"></a>

## 可选来源资料

来源普通资料默认选中，新对象直接采用有效字段；已有对象默认保留，明确选择补空或覆盖后才更新。缺失与空白不清除已有资料。

| 来源                               | 对应                                                                                      |
| ---------------------------------- | ----------------------------------------------------------------------------------------- |
| name、description、实际 cover 字节 | 作品名称、简介、封面；简介确有内容时按实际文字采用                                        |
| author、publisher                  | 可选“来源资料笔记”中的署名与出版社文字，不仅凭名字创建 Person／Organization               |
| format、size、page、charset、path  | 文件识别线索；page 是源解析的页数，不是卷数、已读页数或完成次数；charset 不成为作品原语言 |

Book 行没有本项可直接采用的个人评分、公开作品 ID 或发行日期。源键即便看似毫秒时间戳也不转为加入日期；文件修改时间、最后位置 timestamp 和笔记创建日同样不用于补全发行日或完成日。没有准确主体与参与依据时不生成角色、人物、组织或作品关系，用户可以另行联网补充。

## 喜爱、完成事实与累计阅读时长

favoriteBooks 的明确成员关系对应特别喜爱。只有有效、明确的列表才能解释成员为 true、非成员为 false；配置缺席或损坏时不回答。deletedBooks 默认排除软删除书籍，用户可另选这一范围；迁入不在本体重放源删除。

recordLocation 中严格的字符串 percentage="1" 是当前源界面使用的 Done 值。选中采用完成事实，且书籍范围确为整部作品时，只能为空历史初始化一条未知日期记录。已有对象使用 expected.completionCount: 0；已有完成历史不追加。准确对应一卷时只采用该 Part 完成标记。

这个值可由“标记已读”写入，也可能来自翻到末页，不能声称是手动确认、逐页阅读、100% 收集或一次有日期的完整阅读。0.99999 即使显示四舍五入为 100%，仍不是源 Done。没有完成值不撤销本体历史，未读操作也不重放为清除历史。

中间百分比、recentBooks、recentAdd 和书架名不自动变为计划、进行中或搁置。源“标记已读”只改变百分比，可能保留旧位置，也可能没有任何位置；完成事实与续读分别处理，不能由 Done 补造末页。

readingTime 保存每本书累计秒数。选中“采用累计阅读时长”后，将有效非负整数秒精确换为安全整数毫秒，按所选书籍的明确 Work 归属归集，通过[共同附加时长合同](../../domains/records.md#duration)采用为 comic_records／novel_records 的 additional_duration_ms。

不同 Book.key 的计时桶分别保存各书的实际累计；同一输入中的重复书键只计一次，矛盾值不择新、不取最大。多个所选书籍归属同一 Work 时，先求这些独立桶的总和，再对该 Work 执行一次总量采用，不能逐卷覆盖同一附加值。页面将覆盖范围称为“所选来源书籍累计时长”，不把未选择书籍的时间算入完整来源总量。没有准确 Part 不妨碍采用已经明确属于该 Work 的时间，也不生成卷的附加时长。

新作品的来源总量随 initial 写入；已有作品默认保留，明确采用时以本次已保存的实际阅读活动量为基准，设置“来源总量减实际活动量”的附加绝对值，不在原附加值上再加一遍。来源总量较小、值非法、换算或归集溢出时报告该时长未采用，不删除活动或生成负数。

readingStats 是按日、按书的汇总，可能与 readingTime 重叠，一次跨日计时也可能归入提交日。本项只采用上述明确累计值，不把日汇总再相加或当作累计值的回退；日汇总不迁入，不为它创建阅读概况笔记。附加值进入作品累计阅读时长，但不生成 Activity、期间统计或热力图，也不把统计日及最后位置更新时间当作完成日。

## 书架与文字

shelfList 的每个已选书架建立普通手动合集；排序名称取 sortedShelfList 后接未列入的实际书架，成员按保存数组顺序。导入不重跑源列表动态排序，不把书架名当作系列、类型或阅读状态，不创建嵌套合集。

来源没有可直接绑定本体合集的公开 ID。默认建立本次选定合集；复用已有合集须由用户明确选择，不能只按同名合并。已有成员次序保持，新成员按源次序追加，同一实际 Work 在同一合集只保留一个成员。真实空书架可以保留；成员因作品失败或范围未选而缺失时报告对应结果，不宣称完整迁入。

Note.text 是源保存的摘录，Note.notes 是输入框中的私人普通文字。源保存摘录时已处理部分空白，导入只保留实际保存值，不重新抓原文补成声称更完整的引用。普通文字转为安全 Markdown，保留换行、标点与有意义的空格，不执行其中的 HTML、公式或本地文件链接。

笔记／高亮导出保留以下差异：

| 来源值                      | 采用                                                                                 |
| --------------------------- | ------------------------------------------------------------------------------------ |
| 备份 tag 数组               | 如选择保留笔记上下文，按独立标签文字写入该笔记或批注正文                             |
| JSON／CSV 导出的 tag 字符串 | 源导出已用逗号连接；原标签自身可能含逗号，因此保留这段标签文字，不声称恢复了独立标签 |
| date 日历值、chapter        | 可选可读上下文，日期保持原日历精度；本体 created_at／updated_at 仍是实际写入时间     |
| color、styleType            | 使用本体统一标记样式，不增加逐条颜色字段，也不把颜色映射为作品标签                   |
| 高亮导出没有 notes          | 只保留真实摘录，不能从另一条同名书记录补私人批注                                     |

笔记标签和全局 noteTags 不提升为作品标签。空正文与未知值分别处理；源字面量 notes="annotation" 是其手绘记录的专用标识，不能保存成用户写下的“annotation”。手绘画布的限制见下节。

位置准确转换时，建立一条本体 Annotation：摘录进入 quote，用户文字进入 content；书签 label 可作为标题，已保存的点位附近文字可作为 quote，不生成文字高亮范围。一次记录不会同时重复创建 Annotation 与同内容 Note。

缺文件或位置不可转换时，已选摘录、批注或书签标签迁为关联 Work 的普通 Note，并报告定位未迁入。只有失效位置、没有可保留文字或实际图像的记录不造空笔记。words.db 可另选为每本书的摘词 Note，保留 word、sentence、chapter 和真实日历日；不复制词典、释义插件或制成虚构学习记录。

## 实际文件与封面

先核对输入根下 book/{key}.{format.toLowerCase()}，缺少时再核对明确提供的旧 path／新根映射。只访问授权根，正确解析真实路径与链接，不遍历整机搜索、不从远程路径下载书籍。源 format 只是线索，实际格式与可读性由本体文件能力核验。

归档中确有媒体时，用户先选择持久内容目录，再复制并核验；不覆盖目标已有不同文件，不将备份解包临时路径登记为 holdings，也不把用户书籍存进 attachments。已有媒体默认原位登记，文件首选保持。

采用源位置必须有同一实际文件的可靠对应；有效完整文件 MD5 不符时不借书名或文件名继续绑定坐标。没有有效摘要时，只有明确确认仍是那份未改动的原文件，才可进入位置转换；这种确认不构成密码学证明。文件关联、书目和文字迁入独立于位置是否成功。

封面按完整 key 与扩展名核对实际字节，不照搬源 startsWith(key) 的宽松前缀匹配。例如 key=12 不能选中 123.png。多个不同封面候选使用普通图片选择，不能擅选第一个或最大图片；确认的本地图片或有效内嵌图片通过 attachments 正式接收。远程地址不自动请求，图片失败单独报告。

## 阅读位置与标注边界

Note.cfi 与 Bookmark.cfi 通常保存 JSON.stringify(recordLocation)，其中含 chapterDocIndex、chapterHref、text、count、percentage、page、xpath 等源定位字段。导入器先解释该结构，再按下述可转换范围构造 Kana 位置，并用实际文档验证恢复。

| 来源位置                                             | 本项处理                                                                                            |
| ---------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| 原 PDF 的高亮 range.page／coords                     | 核对同一实际 PDF 后，将零基页码及 PDF 用户空间坐标转换为本体页面文字选区                            |
| PDF 的续读与点位书签                                 | 仅在来源原页模式已明确确认时，校验 chapterDocIndex 与实际页数，采用该页起点；未知模式默认不采用位置 |
| CBZ 漫画的 chapterHref                               | 精确核对实际归档中的完整成员路径，采用该成员页面起点；不把双页视图当作合并页                        |
| EPUB、TXT、FB2、MOBI、KF8、HTML、重排 PDF 的渲染位置 | 本项不转为本体文字锚点；已选文字仍迁为 Note，文件登记独立进行                                       |
| 手绘画布、任意嵌入脚本、未知旧位置形状               | 不执行、不转为可编辑本体标记，不把未知坐标或空内容伪装为成功标注                                    |

PDF 高亮的 coords 由源 PDF viewport.convertToPdfPoint 生成，单位是 PDF 用户空间，不能再当屏幕像素归一化。读取实际有效 CropBox、UserUnit、文档 Rotate，将每个矩形的四角变换到可见页面左上原点的 0–1 坐标，再按本体四边形规则排序。保留每行一个 quad 及原行序，不合成一个大矩形；非有限、越界、退化或无法确定的几何报告不采用，不截断修补。

当前备份的 CommonTool.configList 与 dumpConfig 不包含 convertPDFBooks，缺席不能证明该书未使用 PDF 重排。页面因此为所选 PDF 点位提供明确的“这些位置来自原页阅读”确认，默认关闭；这只说明来源模式，不能绕过页码、摘要和归属校验。已有 page／coords 的 PDF 高亮依自身明确结构解释，不要求用这一确认补造证据。未知 PDF 模式仍可保留书签文字。

CBZ 以精确 chapterHref 为主。源页列表按完整成员名自然比较，图片扩展名过滤区分大小写，.PNG 可能没有进入源页列表；不能先按本体支持格式删掉成员，再套用源索引。仅有数值索引、成员缺失／重名，或排序受未知 locale、大小写及 Unicode 并列影响时，不在本项猜页位。其他 CBR／CB7 等归档可按本体实际能力登记文件，本项不据 CBZ 探针承诺其位置恢复。

EPUB 高亮使用 Rangy 1.3.0 的 saveCharacterRanges，其索引依赖渲染正文、CSS 可见性、空白和源转换。续读使用可见块索引与生成的 XPath，旧 cfi 也可能指向渲染 DOM。本接入只迁移这些记录的实际文字，并报告位置未迁入；源文件、摘录或百分比不足以恢复原文锚点。扩大位置支持须先确定可复现的源 DOM 到原文映射，再修订接入合同。

Fabric 手绘画布含路径、文字、缩放与画布尺寸，不对应现有原生区域标注。当前不迁入其可编辑形态、不装载或执行来源 Fabric 对象，也不把它自动栅格化为声称是原文截图的图片；结果明确报告选中的手绘记录未采用。

续读保存到实际文件，初始本体进度为空，之后由 Kana 解释；不照抄源百分比，不打开文件、不开始活动、不改变当前安排或完成事实。已有位置默认保持，明确选择才更新。同一文件多个矛盾来源位置不取最大值、不按键时间戳择新。

## 页面、执行与结果

一个页面选择输入、书籍范围、漫画／小说类型与本次采用。默认排除 deletedBooks，来源普通资料默认选中；喜爱、完成、累计时长、书架、笔记／高亮、书签、摘词、文件和续读分别选择，默认关闭。无法恢复的所选文字定位可降为普通笔记并报告，导入不要求资料方案。

来源标题、格式、目标类型、作品／分部范围、文件状态与结果各占一列，窄宽度横向滚动。独立导出的书组在当前表中指定明确目标。仅在所选能力需要时呈现持久目录、路径映射、PDF 原页确认或来源文件确认。未选内容与正常缺席不产生无关问题提示。

开始后固定本次选择，先核对必要结构、重复关系和同一目标的矛盾事实，再进行原生新增／复用、所选来源资料更新、个人值与空历史、附加时长、合集、文件、标注及文字采用。异步文件与附件准备不放进数据库事务；Webview 不直接读源库或写本体库。

结果保留新增、更新、未变化、部分完成、跳过、失败与所选内容未迁入的明确原因。每个本体完整操作独立提交，取消停止后续步骤，关闭页面不取消后台任务；没有整批差异预览、第二份采用稿或整库回滚。

新建批次、继续原批次与未知提交沿[共同规则](../importers.md#repeat)处理；同批次复用已完成的文字、标注与对象引用，不重复追加。最低完成和累计时长仍遵守自身采用规则，另建批次时重新表达本次意图。
