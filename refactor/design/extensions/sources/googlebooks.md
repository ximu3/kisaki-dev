# Google Books 接入设计

Google Books 为已明确的书目或系列补充资料，并对已有对应目标提供本人记录导入与同步。本文规定出版版本、字段、身份授权、书架操作和页面职责。

<a id="scope"></a>

## 职责与页面

Google Books 定位为明确书目范围的资料与个人记录补充来源：读取已经明确对应的 Comic／Novel 及真实卷，不从缺少类别与粒度区分依据的出版记录自动发现本体对象。不提供 Entry 名称 search／resolve、未对应书目的自动建库或 workVolumes／workChapters／volumeChapters，不增加 Part 搜索或配对向导。

提供账号、资料采集、导入、同步四页。导入用于手动采用已经对应的个人记录；不提供没有新增对象用途的自动导入开关。同步提供手动与默认关闭的自动执行。

| 来源资源或能力       | 已确定边界                                                                                                         |
| -------------------- | ------------------------------------------------------------------------------------------------------------------ |
| Volume               | 出版书目资源；按实际内容范围对应整作或真实卷，不按资源名直接转为 NovelVolume                                       |
| Series 与 membership | OAuth 已读通，API key 单独访问返回 401；仅使用已经明确对应作品的 Series 范围，不自动把所有 Series 建成作品或卷目录 |
| authors、publisher   | 文字署名，没有可读取的独立人物／组织 ID，不自动创建档案或参与关系                                                  |
| 本人书架             | 作为手动个人记录导入范围；已验证喜爱与三个阅读书架的独立成员操作，不新建未对应作品或卷                             |
| 本人评价             | 只从 userInfo.review 读取；平台均分不是本人评分，没有公开评价写入方法                                              |
| 阅读位置与注释       | 虽有 API，坐标与云书籍绑定；不映射成本地文件位置、活动、标注或 Note                                                |
| 云端购买和正文       | 不下载购买内容、上传文件或建立本地 holdings，不处理购买与 DRM                                                      |

<a id="identity"></a>

## 出版书目与本地目标

source 使用 googlebooks，Volume 身份为 volume/<id>，保留来源 ID 的大小写。已明确范围的 Series 独立使用 series/<id>，不与 Volume 共用裸编号。

同一卷的日文、繁体中文和英文出版记录可能各有不同 Volume ID 与 ISBN。它们是版本记录，不自动成为三部小说，也不因标题中都有“1”就宣布为同一卷。对已知本地目标补字段时，核对来源身份、内容范围和已采用版本；语言偏好不自行更换版本。

ISBN 必须先核对字段类型和校验位，用于对应实际出版物。Google Books 的 isbn: 查询得到多项时不能取第一项；书名唯一结果同样只是候选。合订本的 ISBN、介绍和总页数不分摊给所含各卷，合订范围也不自动等于整部小说。

当前 API 的 printType、subject 与语言筛选只能缩小出版记录范围，结合已核验详情仍没有稳定的整作筛选规则。公开 search 只返回 Entry，本方案因此不声明独立搜索或来源内根定位，不增加书目候选类型、Part 搜索或归属向导。已经明确整作范围的 Volume 或 Series 可以作为相应 Entry 的根读取；已经明确 Google Volume 身份的卷，通过 Part refs 读取，无须制造 Google 的作品根身份。明确对象可以是已保存对象，也可以是同一次新增中由其他来源确定的作品与卷；本 provider 的补充读取不要求对象事先存在于本地。

在已确认作品的 Series 范围内，可以完整读取成员并为本体已选卷提供字段候选，最终成员名单仍由本体方案选定的关系来源决定。合订、单期、节选和范围不明的出版物不作为单卷候选；不会据此新建卷、话或新增作品绑定。

printType=BOOK 不足以证明它属于漫画或叙事小说。readingModes、是否可购买、是否有电子版、页数和封面也不能完成分类；非虚构、杂志、画集及无法确定范围的书目不得默认导入。SeriesInfo 缺席不证明它是独立单行本。

实测 The Yoru Sumino Collection 是包含七部独立小说的作者作品集，却与 SAO、芙莉莲一样使用 ORDERED_COMICS_SERIES；不能把它建成一部 Novel 并把成员当卷。SAO 轻小说使用 Comics & Graphic Novels / Light Novel 分类，《我想吃掉你的胰脏》小说纸书甚至使用 Manga 分类。因此不按 seriesType、分类前缀、标题共同前缀或自动读简介来判断类型与整作范围。

多个可以按 ID 成功读取的书目，以相同 ISBN 查询却实际返回零项；名称检索正常。不能据未检出声称书目不存在，也不改取其他版本或首个近似标题。不新增独立 ISBN 解析贡献或跨来源出版版本登记系统。

## 资料字段与图片

| 来源值                                       | 采用边界                                                                              |
| -------------------------------------------- | ------------------------------------------------------------------------------------- |
| title、subtitle                              | 对应该书目范围的 name，按来源结构组合完整名称；查询词和删卷号后的标题不能成为作品名称 |
| description                                  | 该 Volume 的介绍，HTML 转共同 Markdown；不把单卷介绍提升为整作简介                    |
| pageCount                                    | 该版本所覆盖内容的声明页数；仅对范围一致的整作或卷采用                                |
| language                                     | 当前版本语言，不能填入作品 originalLanguages                                          |
| publishedDate                                | 当前出版版本的日期，不直接覆盖本体原作首次发行日期                                    |
| industryIdentifiers                          | 经校验的出版物定位依据；不能作为跨版本作品的唯一键或批量复制给成员                    |
| canonicalVolumeLink、infoLink 及实际相关链接 | 对应目标的 externalLinks，保留实际来源含义                                            |
| imageLinks                                   | 该 Volume 的真实封面候选，不形成背景、标题标志、人物或组织图片                        |
| maturityRating                               | 仅在来源值及本地目标范围一致时采用其敏感含义，不从所选图片推导                        |

originalName 与 aliases 只采用同一目标具有明确依据的原名与名称集合，缺少依据时保持未回答。作者、出版社、分类和价格保留书目原义。本来源的正式资料能力为本节列出的普通字段和图片，主体图谱与标签继续由具备相应能力的来源提供。

多尺寸 imageLinks 属于同一实际图片时归并，使用来源返回的可访问地址，不能修改 zoom 参数或猜 CDN 路径制造不存在的高清版本。图片下载不携带账号授权头，解码、预览及正式采用沿公共附件合同。

只有当前根身份已明确为相同作品 Series 时，才按该成员关系解释 bookDisplayNumber 为卷编号；没有这一上下文时不把其他分组的编号写入 Part。orderNumber 只用于排序。实测 SAO 的编号 23 对应 orderNumber=22；已登记成员从 21 跳至 23，不补造第 22 卷。普通轻小说也使用 COLLECTED_EDITION，不能按这个词直接判定合订。

Series 根只提供实际 title 与 imageUrl 的名称、代表封面，不从首个成员补造介绍、原作语言、日期、声明数量或发行状态。三个不同 Series 的 bannerImageUrl 实际指向同一张通用漫画拼图，已读取图片核对；不提供 backdropImage，不采用该默认素材。

membership 使用实际 nextPageToken 完整读取；成员常是简略 Volume，实际语言、分类、ISBN 和页数需要补读详情。SAO 两页取得 27 个不同成员，全部补读成功。书架成员按实际分页与总量核对，处理重复、空页及并发计数变化；需要根据缺席写 false 时必须已经完整读取相应范围。失败不冒充空集合，独立成功资料可进入 partialResult。

## 应用配置与本人连接

公共书目需要有效的 Google Books 项目访问配置及配额，不强制用户连接个人账号。保留自定义 API key 配置，发行默认项目也必须实际可用；不能把无 key 请求得到的配额错误当作全站无资料，更不能拿 OAuth Client Secret 充当 API key。

本人连接使用项目登记的官方 Desktop 客户端，S256 PKCE 与动态 loopback。普通用户无须自行注册开发者应用。现有 Web 客户端保持原用途，不用于替代新 Desktop 客户端；OAuth 参数、令牌和实际凭据不得进入页面普通 DTO、日志或核验材料。

图书范围使用 https://www.googleapis.com/auth/books，身份范围使用下文的 openid 与 email。Books 没有单独只读 scope，账号页准确说明它包含图书管理权限；具体读取和写入仍由用户启用的操作决定，不随连接自动执行。

当前 Bookshelf.list／get 实际没有返回旧说明中的 selfLink，books-only tokeninfo 也没有用户标识。正式连接按用户已同意的范围请求 books、openid、email，不请求 profile。Google ID token.sub 用于稳定识别 Google 账号，邮箱只用于显示；不把 sub 冒充 Books user ID，个人接口使用 /mylibrary，无须伪造 Books 用户编号。

按官方 OpenID 配置验证签名、issuer、audience、有效期及本次 nonce，并核对实际授予的 books、openid 与 email 范围；刷新时核对同一 sub。换账号、刷新、取消、断开与秘密提交沿[共同连接合同](../private-data.md#connection)，新授权成功前保留旧有效连接。

当前 Desktop 客户端实际要求 token／refresh 请求附带其桌面 client_secret；补齐正确配置后交换及刷新均返回 200，S256 保持不变。这类桌面配置随应用交付，不能宣称桌面程序能将其保密；它与 Web 客户端的保密 secret 不同。用户令牌与自定义凭据仍由 secrets 保护。

本次使用的自有 OAuth 应用尚未通过 Google 的应用验证；正式发行前需要完成实际权限要求的应用验证与公开分发条件，不能把 API 测试成功当作应用已获验证。

单册资料使用仅允许 Books API 的专用 key。免登录 Volume 读取和名称查询可用，Series 与 membership 只有本人 OAuth 可用；凭据条件按操作分别处理，不因系列需要登录而关闭免登录单册读取。测试配置不写入仓库，发行默认配置与配额由项目维护。

<a id="personal"></a>

## 书架与本人记录

本人书架按已核验的 Google 账号 sub 与 shelf ID 识别，实际请求使用该连接的 /mylibrary 端点，不需要 Books user ID。sub 限定本扩展的账号上下文，不作为 Books 用户路径参数，也不按本地化书架名称匹配。0 是 Favorites，2／3／4 分别是 To Read、Reading Now、Have Read；购买、评过分、最近浏览和任意自定义分类有各自含义，不能统一折算成阅读状态。

导入必须先对应每个 Volume 的真实粒度。单卷的喜爱、星级和已读不能提升为整作评价或完成事实；本体卷没有评分和喜爱字段时，这些值报告不采用。书架只作为来源范围，可将适用作品加入用户选定的本地手动合集，不自动按书架名称建立合集镜像。

userInfo.review.rating 的 ONE、TWO、THREE、FOUR、FIVE 分别对应本人评分 20、40、60、80、100；NOT_RATED 与没有取得本人评价分别处理。没有官方评分写入入口，不提供评分同步，也不调用网站内部评论接口。

实测同一册可以同时存在于 0、2、3、4；重复加入喜爱不会产生第二个成员，逐项移除也不改变其余书架。不能自设 completed 高于 active 或 planned 的优先级，也不把允许共存的过去读过与当前安排压成一个互斥值。

成员增加、移除和排序是实际书架操作；其是否能作为某个本体个人字段的同步，要同时具备同义值和真实对象对应。自定义书架管理不与状态同步混为一体。Discovery 没有创建、改名或删除书架的方法，不把 clearVolumes 作为普通同步或清理入口。

具体书架的 PUBLIC／PRIVATE 按来源读取，不能提供并不存在的逐项私密开关。

不把 userInfo.updated、acquiredTime、评分时间或位置更新时间当作完成日期，不从页码、百分比或阅读位置推算卷完成情况。云端位置与本地 EPUB／PDF 坐标不互换。

## 导入到已有对应目标

手动导入先完整读取用户选定的书架，再以真实 Google Volume 身份查询已有作品或卷。未对应、范围冲突及同一来源记录落入多个本地目标时分别报告，不通过名称首项或新建占位卷补救；不自动刷新已有普通资料，也不维护平台镜像或曾导入名单。

| 来源事实                           | 已对应整作                                | 已对应卷                   |
| ---------------------------------- | ----------------------------------------- | -------------------------- |
| 完整 Favorites 成员关系            | favorite；缺席为 false 需要完整读取       | 没有卷喜爱字段，不采用     |
| 只在 To Read／Reading Now 之一     | planned／active                           | 没有卷当前状态，不采用     |
| 同时在 To Read 与 Reading Now      | 当前状态无法唯一解释，不采用该字段        | 不采用当前状态             |
| Have Read 成员                     | 按共同规则初始化未知日期的完成事实        | isCompleted=true           |
| 完整 Have Read 范围中明确未标记    | 不删除作品完成历史                        | 明确采用卷标记时可写 false |
| 本人 ONE…FIVE 星级／明确 NOT_RATED | 20…100／未评分；review 缺席不冒充明确清除 | 没有卷评分字段，不采用     |

读过可以与当前计划或在读共存。唯一当前安排存在时保留该安排，并单独初始化过去完成；只有 Have Read 而无当前安排时沿已完成规则采用。两个当前安排冲突时仍可独立采用可靠的完成事实。三个阅读书架都没有该书时，不据此清空本地当前状态或历史。

初始化携带 expected.completionCount:0，已有历史保留，不用技术时间补日期。多个版本对应同一本地目标时，不对状态、星级或喜爱投票、取最高值或自设优先级；不能形成唯一投影的字段报告未采用。

可将实际对应的作品加入选定本地手动合集；卷不成为合集成员，也不因采用卷标记附带改动父作品合集。购买、最近浏览和自定义书架只决定来源范围，不作为喜爱或完成值。

## 本地到平台同步

只处理明确选定且具有唯一 Google Volume 对应的作品或卷。Series 没有同义私人记录，作品状态与喜爱不能分摊给其全部成员。多个版本无法确定唯一目标时报告身份范围问题，使用已有身份编辑明确，不增加配对向导。

| 所选字段         | 出站操作                                                                     |
| ---------------- | ---------------------------------------------------------------------------- |
| 作品喜爱         | true 加入 0，false 移出 0                                                    |
| 作品状态 planned | 加入 2、移出 3；4 按是否有完成历史设置                                       |
| 作品状态 active  | 加入 3、移出 2；4 按是否有完成历史设置                                       |
| 作品状态 null    | 移出 2、3；有完成历史则加入 4，没有则移出 4                                  |
| 作品状态 onHold  | 没有同义安排，该状态投影报告不能同步，不改三个阅读书架；其他所选字段独立执行 |
| 卷完成标记       | true 加入 4，false 移出 4；不主动改 2、3 或父作品                            |

4 只表示是否读过，不承载次数、日期和完整历史。作品状态被选中时，2、3、4 是该投影的明确范围；喜爱独立选择，卷标记只对应自身 Volume 的 4。写前读取当前成员，只提交差异，新增当前安排后移除不再对应的安排，再设置 4。多个请求不构成远端事务，结果分别核对。

平台正常联动照常接受，不恢复未选字段，不反向生成本地历史，也不循环补偿来制造无法同时存在的值。结果未知先有界读回，已一致的布尔投影不重写。评分、完成日期、位置、注释、评论、书架结构和顺序不提供同步入口；clearVolumes 不进入同步，删除本地对象不删除远端成员。

自动同步默认关闭，沿共同启用、恢复、范围和所选个人字段变更触发。完成历史变化会重新计算“是否读过”，日期变化和新增第二条历史不会因布尔值未变而重复写入。不建立远端定时轮询或双向记录同步。

<a id="implementation"></a>

## 页面、模块与验收

资料采集页负责 API key 覆盖、配置状态、独立联网测试和网络设置；账号页负责 Desktop／OpenID 授权、邮箱及连接状态；导入页负责本人书架、已有明确目标、所选字段与可选本地手动合集；同步页负责绑定范围、字段、手动执行与默认关闭的自动执行。恢复普通默认值不清除凭据。

Node 分为 client、account、metadata 和实际采用的 import／sync 模块；Webview 使用既定 Solid 与公共组件，shared 只存私有纯合同。分页、字段映射和账号状态由 Node 拥有，IPC 薄转发完整操作。没有 ImportProvider、SyncProvider 或平台镜像库。

网络默认单次超时 20 秒、安全读取重试 2 次；限流尊重 Retry-After 和实际项目配额。写入未知结果先读回，不盲目重试；多个书架步骤不承诺远端事务。语言和资料字段选择沿本体方案，不继承旧的按首项匹配或自动拼接系列行为。

书目、授权、身份校验、成员操作与清理的来源证据见[核验报告](../../../verification/evidence/book-sources/live-api.md)。

完整页面、字段采用、身份冲突、版本范围、个人记录操作、自动触发、取消、并发与图片附件处理分别验收。固定默认预设不加入需要事先明确 Google 书目身份的来源规则；用户保存的方案不会自动重写。接入范围不包含 Google 自动新建母体和卷目录的路径，保留明确对象的资料与记录补充能力。
