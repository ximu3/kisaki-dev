# 界面、本地化与导航验收

对照真实界面和完整用户操作验证。

环境、证据与完成条件见[验收标准](../acceptance.md)，各场景引用对应设计规则。

<a id="native-interaction"></a>

## 简洁流程与平台交互

A20、A26 与 A29 按[系统能力与控件语义](../../design/ui/components.md#native-interaction)核对实际任务：常见操作没有无用途的中间步骤，同一结果不重复反馈，用户无需理解内部模块才能完成操作。文件选择、系统菜单和窗口控制使用适用的平台能力，应用内菜单不取代 macOS 系统菜单栏。

基础控件保持键盘、文本选择、复制粘贴、撤销、输入法组合和辅助技术语义。检查快捷键作用域、平台修饰键、焦点返回，以及自定义样式和复杂组件是否保留这些行为。按实际变更选择相应场景与目标平台，不能只根据控件外观或 DOM 标签认定原生体验已经通过。

<a id="work-shortcuts"></a>

## 从桌面快捷方式打开作品

A10–A12、A20、A28 和 A29 验证[作品桌面快捷方式](../../design/ui/navigation.md#work-shortcuts)。分别从四类作品详情创建，核对实际文件位置、名称与创建反馈。使用同名作品和含路径分隔符的作品名，确认文件都位于指定桌面且先前文件仍可用。桌面不可写时，操作报告失败。

从系统桌面双击已创建的文件，分别在应用已退出和正在运行时核对实际游戏、播放或阅读会话，一次激活只执行一次。关闭已有使用会话并更换首选，再次双击时核对新选择。需要选择或目标失效时核对正常打开流程的结果。W15–W17 验证各媒介，W20 在 Windows、macOS、Linux 的真实载体上验证系统交付，并核对开发与正式身份、便携载体以及桌面要求的启动许可。

## 公共组件、表单与 Toast

A18–A20、A23 和 A29 按[公共 UI 合同](../../design/ui/package.md)验证完整组件。普通控件直接挂载即可使用主题与原生行为；Field 与 Dialog 的局部上下文隔离实例，Toast 使用文档级统一队列。受控更新、默认值与 reset、fieldset 禁用、表单结果及输入法组合在真实浏览器中核对，静态声明不替代交互结果。选择器覆盖实际展开、搜索框清除后的焦点、输入法组合、键盘导航、右侧选中标记和离屏选项定位。核对搜索焦点描边跟随真正的编辑器，候选高亮保持独立。选项较多或较宽时，核对真实 listbox 紧贴面板内缘并承担纵向与横向滚动，首末项均可完整显示。关闭时确认列表立即结束交互，并在退场全程保有行内容、视口高度和滚动位置。

核对文字颜色中的有效转义、无效颜色反馈及透明宽色域拾色。Popover 打开时切换横排和竖排，验证实际物理首选侧与受控展开状态。给共享粘性表头的滚动视口设置 CSS 缩放，验证中间虚拟行仍按正文可见底边对齐。

在独立消费样板核对普通搜索、筛选和动作的外框、字号及图标。在正式任务中心核对小号搜索框与两个筛选框对齐，并核对候选行和偏好表单各自的普通尺度。核对 100% 下任务和偏好的横排页签字号，在最小窗口放大后确认查询带可以排列、页签可以滚动到末项。数字单位位于同框内，表单值仍是原生数值。多行文本超出 rows 时在框内滚动。Form 在独立消费者中验证 Enter、显式提交、原生 reset、可取消 reset 和外部关联按钮。异步提交从按钮、快捷键和关闭前保存重复进入时，只执行一次，返回同一结果。另用普通 HTML 表单消费公共控件，核对其原生能力。

在窄字段中逐项移除多选标签并滚动至两端，核对焦点、溢出按钮和提交值。起始标签与字段内缘对齐，到达端点后滚轮留在溢出区域，扩大字段至足够宽时由外层接续滚动。横排与纵排均先读字段标题和说明，再操作与其关联的控件。

对日期字段删除一个片段、粘贴完整日期，分别核对原生有效性和表单值。浏览年月保持字段值，选日立即写回，焦点返回编辑器。退场期间检查格子、列表行和菜单项沿用原选中标记，重开后显示已提交值。以默认和放大界面核对方形日期格、横纵间隙、今日圆点与键盘焦点。选择器箭头、日历和数字步进器的末端中心线对齐。拾色器打开时焦点在通道内，外框持续标识字段。Slider 的填充随实际值移动并在重置后恢复。

组合原生 Dialog、菜单、Combobox 和 Toast。菜单移动实际焦点。Combobox 展开时焦点位于触发器，Tab 进入搜索框并关联高亮，跨筛选单选或多选保留已提交的标识。Escape 先结束当前内层交互，焦点返回触发器，外层 Dialog 保持。Toast 动作位于实际模态范围内，嵌套 Dialog 的交互与焦点返回正确。监听与定位随组件结束，消息与计时随消息或显示宿主结束。

在同一个菜单内替换已挂载的按钮，分别核对替换后打开和打开中替换。测量菜单与新按钮的相对位置，核对菜单项焦点、新按钮上的 Escape 监听，以及关闭后回到新按钮的行为。源码热更新只替换触发组件时复走同一位置和焦点路径。

在系统强制配色下交叉使用应用亮暗主题，核对菜单与候选行的当前项、文字、说明、选中标记和可见焦点，不能只检查计算样式。日期、页签和分段按钮移走焦点后仍能辨认已选项；进度条保留轨道及确定／不定状态，插入指示仍可见。拾色器色域和色样保留实际颜色，图例色样与图中系列对应，坐标文字及提示使用可读的系统配色。减少动效时继续显示相应终态。

Markdown 编辑器核对标准工具栏、定制按钮及空列表。键盘一次进入工具栏，方向键移动，Tab 离开。内置及自定义编辑命令使用所属实例的选区，切换只读、配置和撤销历史时按钮随实际状态更新。

<a id="form-feedback"></a>

按[固定反馈区](../../design/ui/components.md#validation)使用多字段、字段组和跨页签表单。初次打开不标记尚未填写的必填项；提交定位第一处适用错误。切换错误字段、转向有效字段、移入反馈详情、修正当前错误及全部修正后，提示内容对应真实状态，普通输入不自动跳焦点，字段和反馈区不因错误数量或文案变化跳动。同时存在多项错误时，聚焦的错误字段只显示自身短句和可选补充说明，进入反馈区继续阅读同一项。聚焦有效字段后显示独立总数，点击可定位第一处错误。短句与数量汇总在截断时均可阅读全文。窄窗口、缩放和四语长文案均可阅读，关闭详情后仍能再次定位；辅助技术取得每个字段自身的错误原因。

从实际 Form 的提交按钮与适用的 Enter 触发同一校验。保存失败和冲突保留草稿，迟到响应保留提交之后的输入。跨组问题先展开再定位，每个字段的错误可独立读取，整次提交只在所属位置反馈。核对固定 Footer 在正文滚动和校验切换时保持可见。

按[桌面动效](../../design/ui/package.md#motion)在分数设备缩放和界面缩放下检查三档浮层。分别比较淡入中与静止后的字形位置、尺寸和清晰度，核对实际翻转落点、中途重开与减少动效。普通 Tooltip 首次悬停等待、键盘优先和同一文档的连续交接分别验证。图表提示跨数据点时即时更新数值和位置，首次出现与最后离开时淡变。

按[Toast 寿命](../../design/ui/package.md#toast)核对命令式调用、存活消息更新、主动关闭时句柄立即失效、自然到期与主动关闭的向下退场、减少动效、悬停与聚焦暂停，以及单一队列在嵌套 Dialog 中的移动。调用组件或 Dialog 结束后普通消息保持，展示宿主结束后全部清理；旧句柄不能恢复已结束消息。动作保持原目标，业务目标失效后撤下动作，显示与更新不抢焦点。

loading 提示在普通展示时长之后仍保持，更新为结果后从转换时计时；明确 persistent 的提示在转换后继续保留。用户关闭 loading 后，操作按自己的寿命执行，迟到结果不恢复提示。UI 与 SDK 采用相同状态语义，菜单回调只交付结果类型，业务取消与提示关闭分别验证。

## 三个官方译本

A23 和 A29 按第 31–33 项[完整方案](../../design/extensions/languages.md)分别验收三个官方译本。A20、A26 和 A29 同时覆盖实际使用入口与工程消费。

### 交付与语言审校

每项保留稳定身份，以当前完整英语基准提供完整译文、公开生成与校验合同、纯嵌套 ICU 目录和轻量 Node 登记，并交付独立六目标制品。

简体中文使用新模型术语；繁体中文采用台湾措辞独立审校；日文使用自然语序、标签和说明语气。三份译文分别完成术语与语气审校。

### 消息与登记语义

参数允许省略，但不能新增或收窄公共调用类型；t 保持普通文本。缺键按英语语法回退，已知坏消息拒绝整份登记。同 locale 多译本切换仍更新译文，失效回退保留选择，用户草稿及正文不重写。

### 运行与实际消费

使用真实 Node、浏览器和 Webview，覆盖所有窗口、应用内与原生菜单、无障碍文字、字体、缩放、长名称与长文案。运行验收包括零扩展英语、安装及首次安装失败与恢复、语言恢复、更新与卸载、首屏预算，以及上述消息和登记行为。仓库外 SDK／CLI 使用、构建和六目标安装分别验证。

纯消息合同复用[正式本地化包的验证](../evidence/w03/README.md)。每个译本以本次实际英语基准检查完整目录，并在已安装的扩展实例中验证登记、切换与释放。

## 既有界面对照

代表场景另覆盖长表单固定反馈区的焦点切换与错误定位、窄窗口中横向访问完整表格、双面阅读空间不足时的反馈，以及首次离线且译本未安装时的引导。检查用户能否完成当前任务，所选布局和正式设置保持原值；确有体验缺口时修订对应局部规则。

A29 核对新实现是否沿用旧 Kisaki 的 UI 设计。实施和审阅时先沿旧版页面、业务组件、公共控件与样式查清设计，再用常规 dev 窗口验证。用默认主题和 100% 应用缩放走完同一流程，对照布局、控件比例、密度、操作位置和 MDI 图标，并按当前规格核对动作结果及状态归属。再按场景验证最小窗口和缩放边界。[桌面 UI 设计基准](../../design/ui/components.md#existing-ui)

用 Playwright CLI 在旧版 Electron 窗口走完对应流程。

1. 在旧工程 `F:/project/3/kisaki` 的 PowerShell 中设置 `$env:REMOTE_DEBUGGING_PORT = '9222'`，运行 `pnpm dev`。
2. 在旧工程根目录另开终端，运行 `pnpm exec playwright-cli attach --cdp=http://127.0.0.1:9222`。从连接结果找到地址含 `/main.html` 的主窗口，按需用 `tab-select <序号>` 切换。
3. 用 `snapshot` 查看当前控件，按快照中的引用执行 `click <ref>`，核对打开的页面、对话框或焦点。用 `screenshot` 保存需要对照的页面状态，结束后用 `detach` 断开连接。这些子命令均通过 `pnpm exec playwright-cli` 运行。

对照时记录用到的旧版源码位置、从中确认的设计规则，以及核验这些规则的窗口状态、运行条件和操作步骤。截图与样本按场景留存。

各有 UI 的工作包在功能交付时完成对照。从侧栏打开任务中心，切换进行中与已结束，打开详情后回到原列表与触发点。在中断任务的详情中核对最后一次成功保存的完整结果。从左下角菜单进入偏好，在主题或字体管理中独立保存，再回到原字段和草稿。默认、最小窗口均以 100% 开始。分别核对标题栏整行下缘，尤其是窗口按钮下方的最后一段，以及实际窗口动作、同档控件外框、滚动归属、固定 Footer 和焦点。系统装饰使用窗口级取像，在 Windows 上核对最大化按钮的原生命中。75% 和 200% 复验边界，系统显示比例与应用缩放分别记录。W09 从真实资料页接续同一流程。

用跨多个读取区间的隔离任务历史核对连续滚动。表头和表体共用原生滚动视口，纵向滚动时表头保持原位，窄窗口横向滚动时列对齐。详情关闭后保留原操作焦点，滚轮仍能滚到远处，键盘可以直达末条记录。表体仅挂载视口、邻近范围及交互所需的行，搜索、类型和状态筛选应用于完整结果。单条删除后更新列表。确认「清理历史」后清除全部已结束记录，范围独立于当前搜索与筛选。[任务中心](../../design/domains/tasks.md#record)

任务详情分别验证失败及最后保存的阶段结果、没有保存结果、报告存在但没有可直接展示的字段，以及全部计数为零。仅在有对应数据时提供输入和输出，初始收起，可用键盘展开。返回历史列表后焦点仍回到发起按钮。

在隔离资料中切换主题，核对界面缩放、根字号与控件大小保持，标题栏按偏好缩放取高，分隔线与工作区沿实际原生覆盖区域布局。运行中保存新的界面缩放时，原生窗口与文档采用同一尺寸。

| 代表场景                 | 对照重点                                                                     |
| ------------------------ | ---------------------------------------------------------------------------- |
| 库的卡片／表格与分组浏览 | 导航、密度、选择、滚动、远处定位与返回；默认尺寸和现有最小支持尺寸分别记录   |
| 详情、关系与长编辑表单   | 信息层次、资料与个人记录的区分、草稿保持、保存／取消、错误定位和焦点返回     |
| 来源搜索与资料操作       | 选择、目标范围、采用方式、忙碌和部分完成反馈；新模型带来的必要差异有明确依据 |
| 游戏、播放与阅读窗口     | 主动作、内容列表、快捷键、标注、关闭与多窗口独立性；正文与外壳分别判断       |
| 引导、扩展与偏好管理     | 离线、缺少译本、资源失败、管理入口返回及已保存选择的保持                     |

新能力没有旧界面时，记录为新增场景，使用既有视觉体系和本规格的业务规则建立预期，不虚构旧版对照。图标、表格列、Toast 与预览等既定形式仍按对应合同实现；若代表场景证明用户无法完成任务或必要信息不可获得，先形成可复核的局部问题，再修订规则。验收比较用户能够看到和操作的结果，不要求新旧 DOM 或组件树相同。

## 单项保存与管理列表

A18、A20、A27 和 A29 按[编辑对象与保存边界](../../design/ui/state.md#editing-units)核对实际业务入口：

- 在展示柜、配置、关系、合集和标签管理中保存 A，再取消 B 的编辑并关闭列表；重新打开后 A 保持已保存结果，B 保持原值。列表没有第二次总保存，单项创建不留下仅存于父列表内存中的成功结果。
- 单项校验失败或基线冲突时保留该项输入；不影响其他已完成操作。独立删除、启停、成员调整与重排按各自结果更新，失败不伪装为成功。
- 确认条件或规则字段后取消所属区块、配置或合集表单，正式数据保持原状；保存所属对象后，字段与对象一起提交。字段编辑按钮与对象保存按钮表达各自实际结果。
- 从目录或偏好表单新建、修改独立方案或主题，保存后再取消原表单；独立对象保留成果，原表单的选择引用保持原值。条目标签字段中的新名称随条目取消，独立标签表单已保存的标签继续存在。
- 展示柜批量创建按输入顺序追加独立区块，允许相同配置；任一项失败时整批不创建。重排核对包含隐藏项的完整原顺序，子集重排保留其余槽位，基线冲突不改变排列。

这些断言随所属业务工作包验证真实写入、关闭重开和界面结果；公共 UI 的表单或 Dialog 试件不代替业务保存验收。

## 资源管理与草稿

打开主题编辑器 A，点击「保存并选用」。A 取得正式选择的基线后、内容保存完成前，从入口 B 选用另一主题。A 的主题内容成功保存，条件选用报告 `Conflict`，正式选择保持为 B 选用的主题。没有并发修改时，A 保存后正常选用，并结束自己仍持有的预览。其他编辑器后来取得的预览继续有效。

偏好使用顶部横排页签，可用左右键切换。在最小窗口放大界面后，页签带接收滚轮并横向滚动，键盘到达的页签完整进入视野。字段正文保有统一的纵向视口。用字段标题旁的按钮恢复一个已保存的自定义值时，核对恢复结果和焦点。

从「作品使用」依次进入四个媒介设置页，核对始终使用同一个偏好 Dialog。提交无效值时，反馈定位到实际控件。确定漫画设置后回到原按钮，小说设置分别用返回、取消和 Escape 结束，核对共用计时、已确认的漫画草稿及「作品使用」滚动位置均保留。统一保存并重开，对照漫画的修改已采用、小说保留上次正式值。按字段入口直达相应子编辑器。在默认窗口确认常规、外观、资料库、导航和媒介设置页的字段行都占满正文可用宽度，选择框、数字框与开关按各自尺寸靠行末对齐。窗口缩窄时允许字段堆叠。

在一个有多个绑定的动作上核对标签单行溢出，滚到末项后逐条移除。打开录入浮层，按住 Ctrl 和 Shift 再按数字键，检查按住时的预览、释放后的确认状态和确认前的原列表。「重置」后继续录入，分别核对确定、取消、Escape、外点与重复录入。移除最后一条并保存，重开确认未绑定，恢复默认后焦点返回录入按钮。

在手动代理设置中点击「配置」，填写凭据并确定，验证回焦及偏好统一保存。重开后字段留空，未编辑即确定、或编辑后取消均保留已保存的凭据。编辑两项后清空、使用同字段的「移除」或恢复默认后，保存并核对凭据删除。切换 SOCKS5 时核对适用性、移除入口和实际应用结果。

用键盘展开应用菜单的主题模式，确认当前单选值，切换后检查实际配色和焦点返回。切换「显示敏感内容」，重开菜单和偏好确认同一个保存值。系统集成正常状态下直接显示启动开关、链接状态和当前数据目录。在允许变更协议关联的环境中，核对关联待处理时的设置入口，以及返回后显示的实际关联状态。

在单列主题目录辨认来源和使用状态，预览亮暗色样，复制后从目录进入副本的独立编辑。字体目录打开真实文件样张，关闭后释放句柄，列表还原当前位置与预览按钮焦点。文件草稿区分保留、新增、待移除和准备失败。原偏好草稿在管理操作、焦点返回及目录刷新期间保持。更新 Dialog 使用正式偏好。

使用前景与背景无法辨认且选用缺失字体的合法主题，核对字体仅回退到对应槽的默认值，主窗口提示一次，外观页可继续看到问题。在另有未保存草稿及活动预览时，从系统菜单和托盘菜单恢复默认主题。核对选用结果持久生效、预览结束、草稿和缩放保留。[外观与字体恢复](../../design/domains/appearance.md)

## 应用搜索与导航

在已有的任务中心打开指定任务的原生入口，核对详情呈现后才唤起隐藏窗口。再定位另一条已保存任务，核对关闭详情后仍处于原任务列表范围。目标不存在时报告失败并保留已有界面。

从主窗口搜索进入已有设置字段以及菜单里的管理 Dialog，核对命中名称、实际目的地、打开前的草稿决定和返回焦点。扩展页面停用后退出可用目录，重新激活后恢复原导航位置。W18 用已交付的正式目标核对导航。W20 从菜单、搜索和已安装扩展打开更新，W22 从固定入口和已安装扩展打开引导，分别确认真实 Dialog 已就绪。

A19 和 A29 按[结果合同](../../design/domains/search.md#results)验证类别与 SearchTarget 分支关联、缺省展示值、合法 PreferenceKey 和页面归属；0、201、负数及非整数 limit 拒绝，超出 total 的 offset 返回空项与真实数量。摘要在 160 个 UTF-16 单元内保留完整字素。图标保留扩展资源归属，查询不产生无释放入口的字节占用，过期图片引用按共同缺图规则呈现。

A19、A29 和 A30 验证[应用搜索排序](../../design/domains/search.md#results)：

- 名称完整匹配、前缀匹配、包含全部词、依靠正文或上下文命中依次排列。原名、排序名和别名采用同一档次，完整外部标识归入第一档；词语分布在名称与正文中时归入第四档。
- 同一对象多处命中只计一项。同档覆盖“作品 2”与“作品 10”的自然数字顺序，以及同名结果的完整目标身份补序。
- 每组前三项与该类别结果的开头一致，远处区间沿用相同排序。隐藏内容不影响可见结果的顺序、数量或区间。
- “全部”模式保留分类分组，Explorer 输入文字后保留原有人工或字段顺序。

应用搜索与库查询还须验证[共同文字规则](../../design/domains/library/query/README.md#text-and-sort)：相同 Entry 范围和可见范围内，显示名、原名、排序名、别名和简介产生相同的普通文字命中集合。覆盖中文及日文连续文字的中间片段、英文大小写、全半角、查询首尾空白和多词跨字段命中；简繁体、假名与罗马音不自动互转。简介和笔记中的可读文字可以命中，Markdown 标记和内部附件地址不参与匹配，保存与显示的原值保持不变。外部标识仍按完整值准确比较，不套用普通文字规则。

A19 和 A29 验证标注搜索结果携带完整 AnnotationRef，经[原生导航](../../design/communication.md#capabilities)打开已保存内容；不会直接启动游戏或打开源文件，也不为此增加公开 deeplink。展示柜的最近加入区块与普通查询使用相同有效加入日期：空 added_date 回退到创建日期，部分日期保持原精度，筛选、排序和定位一致。

A19、A27 和 A30 按[资料库名称排序](../../design/domains/library/query/README.md#name-order)验证语言差异、数字排序、等价名称的 ID 补序及缺省位置。同 locale 切换界面译本保留顺序；实际 locale 改变、回退或引擎修订更新后验证索引重建、重开和原始名称保留。同一范围的 list、locate 和应用搜索使用相同的名称比较。

## 引导采用的原子范围

A18 和 A20 核对引导的待采用配置使用字段编辑与明确的“应用并继续”；局部“确定”不显示已经保存。已经创建的成果通过正常单项编辑保存，取消或退出引导不撤回这些结果。

A05、A20 和 A27 验证[有界引导采用](../../design/domains/onboarding.md#composition)：偏好、资料方案、扫描配置和展示柜的本组创建与 handled 同次提交。将失败注入业务写入之后、handled 写入之前，重开后两边均保持原状；同组后一个项目校验失败时，前项也不残留。只有提交成功才发布业务变化与引导失效，通知不承担补写。

准备期间另一个窗口处理同一 itemId 或改变同类型默认方案时，原请求按 expectedHandled 或 expected.defaultProfileId 冲突，保留草稿；无关偏好变化不影响本次提交。展示柜仅按本次选择追加新项，原区块及其相对顺序保持，不接受借引导删除或覆盖已有区块。

扩展安装完成而处理记录保存失败时，报告真实安装成果与未采用标记；再次处理核对同包版本后继续，不因缺少 handled 盲目重装。激活或扫描监听失败保留已提交配置与 applied，并显示实际运行问题。安装不能代替译本选择，跳过不能覆盖同时完成的采用，也不取消已经接纳的安装。

## 公共 UI 虚拟几何与业务身份

A18、A19 和 A29 按[虚拟化边界](../../design/ui/virtualization.md#geometry)验证实际 Solid 接入。五万项及正式预算中的更大样本保留完整 total；初始化几何不得触发逐项 IPC 或全库详情读取。记录初始索引构建、普通滚动、测量失效与动态高度的独立成本，不能用只有少量 DOM 就宣布整体性能通过。

查询代际与几何 key 不替代 EntryRef 和真实组身份。未加载行不要求预读完整 ID 表；查询、排序和成员变化后，旧几何失效，稳定业务锚点重新定位。改变网格列数、上方图片或字体导致高度变化时，同一锚点保持且不重复补偿。跨折叠组与重复显示实例的选择仍使用本体解析。

拖拽源行、焦点和必要 ARIA 目标只保留有限活动行；尚未取得真实目标不能放下。覆盖滚动中测量、隐藏／恢复、窗口缩放、退出释放和读屏。隔离 offscreen 试件的成功不代替这些正式控件、真实图片、GPU 和输入延迟验收。

## Webview 来源、联网与权限

A20、A21、A23 和 A26 按[容器合同](../../design/extensions/webview.md#isolation)验证实际发布包、SDK 与三种作者模板。并行打开同扩展的不同视图和不同扩展页面，核对各自真实来源，拒绝父页面 DOM、其他视图、原生 preload、Node 全局和伪造 MessagePort 接入。文档刷新更换端口但不重复 Node setup；视图替换后旧来源、资源与迟到消息失效。

按[发布 CSP](../../design/extensions/webview.md#csp)验证包内脚本、CSS、Worker、嵌套页面与授权图片／字体；内联、eval、远程脚本、blob Worker、远端 iframe 和 HTTP／WS 请求均拒绝。普通页面与 Worker 分别尝试读取已知的其他视图资源地址，均不得取得字节；同视图合法读取和多绑定独立释放仍成立。不能只检查 document 的 webRequest 记录后推定 Worker 已覆盖。加载失败、已撤销绑定、缓存与跨窗口重新绑定均须验证。

sandbox 的 allow-forms 使原生提交按钮与适用的 Enter 提交进入页面处理器，官方表单的 novalidate 保留有效性并采用固定反馈区。取消默认提交后，保存经实际私有 IPC 完成；未取消默认行为及直接调用 form.submit 时，form-action 'none' 仍阻止提交到 URL。该接入不改变其他 sandbox 限制、来源隔离与宿主权限，使用正式视图验证，不能只检查属性字符串。

使用真实 HTTPS／WSS 服务覆盖成功、CORS 拒绝、Cookie、重定向、流中断与应用代理变化，核对浏览器 Session 和宿主 HTTP 的各自语义。官方业务及凭据留在 Node，页面只能取得业务允许的数据。合成 HTTPS 协议响应不代替 TLS、WebSocket、代理或真实来源服务测试。

包内导航正常建立新文档；跨视图和外部导航拒绝，CSP 先行失败也能清理旧 document 并显示准确状态。明确 ui.openExternal 使用系统浏览器，拒绝非 HTTP(S) 及带用户名／密码的地址；被阻止的链接或弹窗不自动打开浏览器。真实权限检查和请求均默认拒绝，未知权限不获准；普通表单输入、用户复制与粘贴仍可用。

开发模式核对每视图独立来源、受控 loopback 映射、随机 nonce 与精确 HMR WebSocket，覆盖端口改变、构建失效、刷新、断连及会话结束。正式制品不得含开发放行。隔离试件只证明所列机制，不代替这些正式流程与完整资源寿命。
