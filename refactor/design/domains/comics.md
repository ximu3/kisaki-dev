# 漫画、卷、话与文件

ComicChapter 和 ComicVolume 分别表示漫画中的真实话与卷，卷通过收录关系组织话。ComicFile 表示实际阅读的文件或图片目录。漫画与小说共用阅读能力，实际文档决定固定页面或文本重排，漫画类别不限制版式。卷收录了哪些话、文件关联了哪些内容，以及文件读到了哪里，是三种分别维护的事实。

<a id="model"></a>

## 对象、收录与文件关联

| 表                    | 关键引用与一行含义                                                                                           |
| --------------------- | ------------------------------------------------------------------------------------------------------------ |
| comics                | entry_id 为主键，引用 entries.id；沿用七类 Entry 的具体类型约束                                              |
| comic_directories     | id；comic_id 引用 comics.entry_id；按[内容目录合同](holdings.md#directories)保存发现范围、过滤及识别方案引用 |
| comic_volumes         | id；comic_id 引用 comics.entry_id；一条真实卷记录                                                            |
| comic_chapters        | id；comic_id 引用 comics.entry_id；一条真实话记录                                                            |
| comic_files           | id；comic_id 引用 comics.entry_id；一份实际读取目标及自身位置                                                |
| comic_volume_chapters | (volume_id, chapter_id) 联合主键，分别引用卷与话；明确的收录关系及实际需要的卷内排列                         |
| comic_file_volumes    | (file_id, volume_id) 联合主键，分别引用文件与卷；明确的文件卷关联                                            |
| comic_file_chapters   | (file_id, chapter_id) 联合主键，分别引用文件与话；明确的文件话关联                                           |

卷和话分别直接属于作品，各自管理生命周期。漫画可以只有卷、只有话，也可以作为完整短篇直接拥有文件。分部依据真实内容划分，图片页、目录项和文件容器按各自用途管理。文件可以独立于卷话关联被阅读，并保存使用位置。

comic_files 保存[关联方式](holdings.md#association-mode)。自动匹配资格同时检查卷与话的全部直接关联，manual 模式下的空集合继续保留，不把卷收录投影或资料刷新当作恢复自动匹配的授权。

卷话收录、文件卷关联、文件话关联都使用组合键，没有独立 ID。完整操作在同步事务内核对两端属于同一漫画，外键只负责保证对象存在。有明确依据时，同一话可以被多卷收录，同时保留唯一的资料与当前记录。收录本身不证明完整覆盖、页码范围或不同版本之间的等价关系。

卷 V 收录话 C，文件 F 关联卷 V，并不自动产生 F 与 C 的直接关联。话的界面可以同时提供直接文件和相关卷文件入口；查询按文件 ID 去重，但不将查询结果保存成新关系。从话打开卷文件时，恢复文件自身的位置，不承诺跳到该话首页。

例如，只有第 2 卷 CBZ 时，可以只建立一卷、一文件和一条关联，不必建立话。逐话保存八个文件时，可以没有卷。后来补充第 1 卷、八条收录和整卷文件，仍保留原话与文件，不自动给整卷文件增加八条话关联。第 1–3 卷的合订文件也只有一个阅读位置。

<a id="numbering"></a>

## 三个编号与排列范围

| 所属表                | number_label                           | sort_order                       |
| --------------------- | -------------------------------------- | -------------------------------- |
| comic_volumes         | 该卷在作品中的实际卷号，可空文本       | 作品卷列表的排列，非负整数       |
| comic_chapters        | 该话在作品中采用的当前话号，可空文本   | 作品话列表的排列，非负整数       |
| comic_volume_chapters | 该话在这一卷中明确标示的编号，可空文本 | 这一卷中已登记话的排列，非负整数 |

number_label 是可空文本，可以表达 13、13.5、前篇或番外；sort_order 是非负的本地顺序。两者均可重复，身份由相应 ID 确定。作品话号与卷内话号分别保存真实来源值，缺席时保持未知，不互相补写或生成连续编号。

文件的[内置命名解释](file-recognition.md#builtin-books)对明确的“卷＋话”层次使用真实卷内话号；已识别的来源卷格式保留作品话号。裸数字和文件格式不决定卷、话粒度，缺少卷内编号不能用作品编号或排列位置代替。

同一话 c-a 可以在作品中编号为 13，在第二卷中编号为 1，在另一收录卷中编号为 3。修改其中一条收录的编号，只影响该收录，不修改话本身、其他卷、文件位置或私人记录。

作品卷序、作品话序和每卷的话序各自独立。默认按 sort_order 加稳定 ID 排序，收录关系使用 chapter_id 打破同序。首次导入可以采用明确来源顺序，普通编号或名称刷新不重排。新增项没有明确位置时追加，主动采用来源顺序时才提交重排。完整重排核对实际集合与顺序基线，不锁定整部作品的资料时间。

编号与身份分别管理，编号未知或变化时保留原对象。两卷中的“第 1 话”可以是不同对象，后来补充收录时保留原话 ID。删除卷只删除该卷范围的编号，作品中的话和记录继续存在。界面辅助显示其他范围的编号时，应注明范围，不能写回另一字段。

<a id="metadata"></a>

## 来源对应与声明数量

provider 在作品范围中分别回答作品、卷、话和收录，只提供自己知道的部分。metadata 合成来源，ingest 核对本地目标。卷和话各自有直接外部身份表，回答内的 key 只用于连接该次回答的端点。

来源对应优先使用完整身份准确匹配。其他依据按启用的作品范围、种类、编号、标题和收录规则处理；存在多个候选时保留问题，不自行决定。

按卷内编号匹配前，必须先确定卷，不能把各卷“第 1 话”合并。来源字段叫 volume 或 chapter，并不能单独证明编号属于哪个范围。不同语言发布只有在确认内容范围等价后，才能绑定同一本地话。上传时间和发布差异不覆盖原始发行事实，也不复制私人记录。来源标识变化需要明确依据，不能承诺自动恢复。

适配器按 cover_art 的来源含义采用封面，卷和话依据真实清单补齐。卷话收录默认补齐；用户明确选择替换后，只移除完整回答范围内不再保留的收录关系，卷、话、文件及个人记录保持原样。来源未回答时保留旧收录，普通更新保留人工排列。资料获取与准备在事务外完成，再经完整操作提交。

压缩包、目录和裸数字 01 都只是线索，只有明确的 holdings 规则才能将其解释为卷或话。文件可以先登记并阅读，不必补造 Part。上下两份文件不自动拆成两话，局部来源也不能冒充整话身份。

最大话号描述编号边界，返回行数描述本次响应，声明总量描述来源给出的数量，三者分别采用。编号 50 或 13.5 保留为编号；账号的累计已读量保持累计语义。逐话标记只用于已经准确对应的真实话。

<a id="records"></a>

## 记录与删除

comic_records 以 comic_id 为主键并引用 comics.entry_id，保存三种作品当前状态或 null，以及 additional_duration_ms。附加阅读时长使用非负安全整数毫秒，缺行按 0 读取，编辑、来源累计值采用和统计遵守[共同附加时长合同](records.md#duration)。comic_volume_records 和 comic_chapter_records 分别以 volume_id、chapter_id 为主键引用实际分部，只保存 is_completed 布尔标记，不保存日期、次数、附加时长或逐次历史。作品完成历史独立保存在[work_completion_records](records.md#schema)，三个范围遵守[共同完成操作](records.md#operations)。

作品完成与实际阅读遵守[共同记录模型](records.md#model)及[会话规则](sessions.md#personal-status)。卷、话只使用各自的完成标记。

明确选择卷与话 ID 时，可以在同一次批量操作中设置其完成标记。单独标记卷不传播到其收录的话，全部已登记话完成也不自动标记卷或作品。卷、话的完成数量不相加成为作品完成次数。

标注使用实际文件与发生时上下文。comic_reading_activity 保存明确的使用区间与已知上下文，手动补录不要求本地文件，见[活动编辑](library-operations.md#activities)。合订阅读区间只记一次，不能复制给所有关联卷和话。没有精确的话范围，就不生成话级历史。位置和公共标注规则见 [阅读器](reader.md) 与 [标注](annotations.md)。

删除卷时，移除卷自己的当前记录、收录和文件卷关系，保留话、话记录和文件。删除话时，处理该话自己的从属记录与关联，保留卷和文件。解除收录只删除关系，不删除两端对象。

文件失联时保留全部记录。明确删除文件记录时，解除文件引用和首选，但保留作品完成历史、分部完成标记，以及标注和活动所需的发生时上下文。完整删除按各对象实际生命周期，在同一事务内完成这些处理。

<a id="selection"></a>

## 三个范围的首选文件

| 所属表              | 字段与适用范围                   | 唯一性                          |
| ------------------- | -------------------------------- | ------------------------------- |
| comic_files         | is_preferred，所属作品的首选文件 | 每个 comic_id 至多一条为 true   |
| comic_file_volumes  | is_preferred，对应卷的首选文件   | 每个 volume_id 至多一条为 true  |
| comic_file_chapters | is_preferred，对应话的首选文件   | 每个 chapter_id 至多一条为 true |

三种 is_preferred 均默认 false，每个范围内允许零条或一条 true，切换在同一事务完成。首选保存在对应文件或文件关联上。话的选择属于话本身，因此同一话被多卷收录时仍使用同一套首选。扫描和资料刷新保留用户的首选。

可以按目录筛选文件，再按[批量默认文件规则](holdings.md#selection)设置明确卷或话的首选；目录不成为当前阅读版本。目录入口、文件选择与当前阅读各自独立，界面遵守[使用与位置操作](../ui/components.md#local-actions)。

普通打开按[共同目标选择规则](sessions.md#open)处理当前作品、卷或话范围。没有活动会话且未显式指定文件时，范围首选优先于最近实际文件；“继续”与“使用首选”入口分别传入自己已经明确的目标 ID，每份文件恢复自己的位置。目标失联时保留选择并明确提供替代；取消首选不自动选中其他文件，修改首选不切换当前内容，解除关联只移除对应范围的选择。

话首选只能来自直接文件关联，不继承作品或卷的首选。没有直接文件时，可以提供明确的“打开收录卷文件”入口；目标只有一个且明确时，无需额外选择。但打开后使用卷或文件范围的导航，不能声称已经定位到话首页。

将卷文件设为某话首选时，须显式在同一事务中建立该话与文件的直接关联。这只影响所选话，不扩散到整卷，也不产生文件内范围。继续目标失联时，不能静默改开相关卷文件。

<a id="sequence"></a>

## 作品内导航与切换

作品详情和阅读器共用[实时内容列表](reader.md#work-navigation)，资料与文件各有明确的当前范围和顺序：

| 当前查看范围   | 完整顺序                                 | 相邻项含义             |
| -------------- | ---------------------------------------- | ---------------------- |
| 作品卷列表     | 本作品全部卷的 sort_order、id            | 上一卷／下一卷         |
| 作品话列表     | 本作品全部话的 sort_order、id            | 上一话／下一话         |
| 某卷内的话列表 | 该卷真实收录的 sort_order、chapter_id    | 本卷中的上一话／下一话 |
| 文件列表       | 本作品全部文件的规范路径自然数字顺序、id | 上一文件／下一文件     |

资料视图一次查看卷、作品话或某卷收录的话，不混合卷与卷内全部话。卷内话仍按话选择文件，某话显示在卷下不授予使用卷首选的权限。卷与话的收录变化正常刷新该范围，不复制一份打开时的成员清单。

当前文件只有一个直接关联卷时，可以确定卷列表中的当前项；只有一个直接关联话时，可以确定作品话列表中的当前项。在某卷范围内导航，还须确认这条话确实被该卷收录。仅通过相关卷文件打开某话，不能声称当前位于该话；合订文件的多个关联也不按入口或排列任选一项。无法确定当前分部时仍可明确选择目标，文件视图始终按实际文件导航。

已读状态与其他筛选不改变相邻项计算，下一项缺文件、失联或加载失败时明确说明，并提供选择、重试或明确跳过。导航不制造活动归属，整卷文件不会因为从不同话入口打开而产生重叠的话级时长。末尾停留、同文件复用和切换失败处理使用共同阅读规则。

<a id="presentation"></a>

## 作品界面与阅读设置

作品详情与阅读器提供资料和文件两种视图。资料可以按卷、作品话或某卷收录的话显示，未被收录的话也必须能够访问。新阅读器有卷或话时默认显示资料，先采用卷列表，只有话时采用作品话列表；没有分部时默认文件。文件视图包含未关联、合订、不同版本和失联记录，分别展示关联、格式与可用性。只有单行本时不必补齐话，逐话追更时不需要占位卷。切换视图不会复制文件或标注，也不立即切换阅读内容。

漫画不使用互斥的 ComicFormat 或 ComicCategory。地区传统、同人和长条等描述可以并存，通过普通标签与合集整理。来源类别用于解释来源类型和匹配范围，不通过保留标签或名称驱动阅读。文件格式、实际版式、页面尺寸和页序是观察事实，阅读方式与适用呈现参数由用户设置。

完整阅读配置采用本体独立拥有的 ReadingPreferences，按 flow、pages、text 和 colors 组织。原始页编组与正文分页独立保存，支持正文双面、独立插图单面；整次主阅读仍采用同一种推进方式。下表列出阅读流与原始页面设置，正文排版及配色见[阅读配置](preferences.md#reading-values)。具体内核经阅读接入使用这些选择，同一文件的混合内容不改变作品归属或创建新会话。

| 字段含义          | 值或作用                                                            |
| ----------------- | ------------------------------------------------------------------- |
| flow              | paginated / continuous，分页推进或连续移动                          |
| pages.arrangement | single / spread，原始页的单页或左右对页编组                         |
| pages.progression | document / ltr / rtl；跟随文档或明确指定原始页推进方向              |
| pages.firstPage   | single / paired；缺少明确页位时的正文起始原始页配对策略，跳转不重设 |
| pages.fit         | page / width / height，基础适配方式                                 |
| pages.autoCrop    | 在显示时自动裁去可识别的空白边缘                                    |
| pages.brightness  | 原始页显示亮度；0–2 有限倍率，默认 1，界面显示 0–200%               |
| pages.contrast    | 原始页显示对比度；0–2 有限倍率，默认 1，界面显示 0–200%             |

rtl 改变页面推进与并排关系，不倒转源页序。连续移动与页面推进方向分别表达，对页编组不改变页身份。宽图、窗口尺寸与文档约束影响实际布局，但不能覆盖用户保存的选择。当前不适用的配置继续保留，并说明其适用条件。完整默认值与 document 缺少文档提示时的处理见[偏好](preferences.md)。

<a id="preferences"></a>

## 完整配置的选择、保存与采用

| 范围         | 存储归属                                                                | 含义                                                   |
| ------------ | ----------------------------------------------------------------------- | ------------------------------------------------------ |
| 全局阅读默认 | preferences 的固定类型配置，保存于 preferences 对应 JSON 列             | 完整默认配置，无自定义启用开关                         |
| 本作品自定义 | comic_reading_preferences，以 comic_id 为主键并直接引用 comics.entry_id | 可选的自定义配置单元，包含启用状态与完整设置           |
| 本文件自定义 | comic_files 上可空的完整配置 JSON 列                                    | 当前文件自己的启用状态与完整设置，随文件身份保存和删除 |

作品配置是可选的一对一记录，没有独立 ID，不强制创建空行，也不放入编目资料或 comic_records。自定义配置使用包含 enabled 与完整 ReadingPreferences settings 的受控 JSON，通过 customType 接入，不使用逐字段 nullable override。两种版式的设置共同属于一个配置单元。

没有自定义单元或文件列为空时使用上一级。禁用自定义时保留设置，再次启用时恢复；首次启用则复制上一级当前的完整配置。“从上一级复制”是明确替换草稿的操作。

文件自定义已启用时，使用文件整套配置；否则使用已启用的作品整套配置；再否则使用该类别的全局默认。即使某字段从未手工修改，也不会穿透到上一级继承。系统先选择完整 ReadingPreferences，再按实际内容采用各项设置，并通过阅读接入使用内核能力。复制时保留 document、theme 等跟随意图，不固化当前解析出的方向、布局或资源地址。观察结果、标签、资料和引擎都不回写偏好。

全局偏好页、作品详情或阅读器中的作品设置，以及文件列表或阅读器中的文件设置，都须明确修改目标。关闭自定义后收起字段并显示当前有效来源；“恢复继承”只关闭自定义，保留原设置。切换编辑目标不迁移配置，修改作品设置也不关闭文件自定义。

管理界面保存只影响下次打开。当前阅读器中的明确设置操作可以按所选范围应用于当前内容，其他窗口不重新配置。临时缩放不自动开启持久配置。

虽然存储保存完整配置，普通编辑仍只提交实际改动与相应基线；初始化和整体复制按完整范围核对。保存失败与引擎应用失败分别报告。改变方向、模式、裁边或显示修正前后，保留内容锚点，不重置位置和完成状态。裁边、亮度和对比度只改变呈现，不修改媒体字节或资料结构。

临时倍率、位移、视口和全屏属于运行状态，不保存为全局默认，也不用像素坐标代替定位。文件失联或重定位时保留文件自定义，另一文件不能按同名继承。删除文件时删除其配置，保留作品与全局配置；删除作品时，按完整范围删除作品配置。

验收须覆盖多种标签并存、固定页面、可重排文本和混合版式、具有特殊设置的文件、单双页切换、方向或字号变化后锚点保持、整套配置层级与下次打开的采用，以及观察结果不改写用户选择。
