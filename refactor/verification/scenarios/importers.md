# 迁移导入验收

验证十三项导入器从真实来源输入到本地资料、私人记录和实际内容的完整采用。各来源的输入家族、字段映射和支持范围见[导入目录](../../design/extensions/importers.md#catalog)，环境与制品条件见[验收标准](../acceptance.md)。

<a id="flow"></a>

## 共同采用流程

A22 和 A27 按[统一导入流程](../../design/extensions/importers.md#flow)验证以下结果。每项来源用自己的合法样本贯通实际采用，共用机制的故障与接续场景在[原批次继续](#continuation)集中验证。

| 场景                                      | 预期结果                                                                                            |
| ----------------------------------------- | --------------------------------------------------------------------------------------------------- |
| 未安装 provider、没有资料方案且网络不可用 | 最低资料完整的本地输入通过 prepared 新增，所选 initial 同次提交；缺少名称或必要归属时报告该项目失败 |
| 采用普通来源资料                          | 默认选入；新对象采用有效字段，已有对象默认保留；明确选择补空或覆盖后只修改所选字段，缺席保持缺席    |
| 采用完成总数三次，本地没有历史            | 初始化三条未知日期记录；本地已有历史时不直接再加三次                                                |
| 追加真实逐条历史或笔记                    | 新批次按明确选择新增；继续原批次跳过已完成步骤，已有正文保持原样                                    |
| 来源累计十小时，本地活动三小时            | 附加时长设为七小时；后来活动增至四小时，再明确采用同一总量时设为六小时                              |
| 来源只提供启动次数、当前页或累计量        | 按相应字段含义采用，不生成缺少依据的完成事实、活动或日期                                            |

共同流程适用于书库备份、NFO、ComicInfo 和独立 OPF 等已支持输入。联网补充另行发起，不重放私人内容。真实文件与图片准备、已有位置和首选保护、取消、缺失资源及未迁入原因，按各来源的实际能力验证。

涉及合集、游戏配置、播放、阅读、标注和任务的来源，分别接入 A08、A10、A11、A12、A14 和 A15。十三项扩展各自验证完整用户流程及独立制品；解析试件只证明其记录的输入与机制，平台运行按共同验收规则记录。

<a id="goodreads"></a>

## Goodreads

按[接入方案](../../design/extensions/importers/goodreads.md)核对作品类型、既有 Part 对应、评分空值、笔记关联和书架顺序。

- read、Read Count 和 Date Read 分别采用。Read Count 包含进行中的阅读，不成为完成次数；符合条件的完成事实只初始化空历史。
- 本地为 active、来源为 did-not-finish 时，选中状态采用也保留 active，并报告该状态未采用；既有完成历史保留。
- 合法完整日期按原值迁入，包括每月第一日；非法日期报告字段问题，不增加精度提示、确认或备注。

<a id="vnite"></a>

## Vnite

按[接入方案](../../design/extensions/importers/vnite.md)核对已有条目复用、六种状态、零分与未评分、区间与日值及累计量。已有私人值仅在明确选择后采用。

回忆图片、空回忆与缺省字段按各自含义处理，普通获胜修订保留对应来源内容。三种启动配置分别验证路径替换、参数及实际启动结果。

<a id="playnite"></a>

## Playnite

按[接入方案](../../design/extensions/importers/playnite.md)验证只读数据库、受限 BSON、Int64 精度、正常 null 省略、被动类型标记及引用字典。

- 自定义状态名为 Completed 或设置为 PlayedStatus 时，只按用户指定的当前安排与完成事实两轴采用；PlayCount、LastActivity 保留原义。
- 评分空值、累计时长、备注和分类按共同采用方式提交；未完成的启动配置可以迁入并供补全。
- 参数、变量、多 ROM 和监测方式通过实际启动核对。LiteDB 对象映射与 AOT 的环境限制沿来源证据检查其实际影响。

<a id="potatovn"></a>

## PotatoVN

按[接入方案](../../design/extensions/importers/potatovn.md)分别验证全库 JSON 与单游戏 Version 2。MyRate 为 0 时表示未评分，Rating 保持公众评分；Abandoned 保留本地安排，PlayCount 不增加完成次数。

累计分钟与日值只采用一份，同一 Uuid 的多安装共享个人事实。元数据目录、LocalConfig、实际安装根、最近安装与人工首选分别解释，来源升级标志不触发本体迁移。实际 Windows 启动验证单参数语义、管理员与转区命令、目录和存档 token；相关对象更新仍使用明确目标。

<a id="calibre"></a>

## calibre

按[接入方案](../../design/extensions/importers/calibre.md)验证 schema 28 一致只读书库及 OPF 的两种用途。资料采用核对来源身份、卷归属、明确指定的本人评分、自定义列、空值、日期时区和完成初始化。

资料笔记按所选范围创建，calres 图片和真实文件经正式资源准备后采用。多人、多设备位置与删除墓碑分别解释；阅读百分比不生成完成。真实书库覆盖 FTS／WAL，实际 EPUB 源映射和 Kana 跳转覆盖复杂内容，转换后的 CFI 只用于它实际对应的文档。

<a id="mihon"></a>

## Mihon / Tachiyomi

按[接入方案](../../design/extensions/importers/mihon.md)验证两代标准 Backup、来源系列、64 位与缺省值、库内外范围、分类顺序、作品与分部粒度，以及版本评分、状态和空历史初始化。

完整源命名与页序把零基位置对应到真实 memberPath；文件、符号链接、日期时区和 Kana 跳转用实际输入核对。整章书签和阅读概况按选定内容形成 Note，累计阅读时长按 Work 归集为附加绝对值，不在概况和活动中重复采用。

<a id="nfo-comicinfo"></a>

## NFO / ComicInfo

按[接入方案](../../design/extensions/importers/nfo-comicinfo.md)验证已声明 XML、编码、两代多集配对、路径配对、身份与母体范围，以及书目编号。个人与公众评分、已看计数和完成初始化分别处理；lastplayed 不充当完成日期，tvshow 聚合不生成作品完成。

已有文件可明确补空或覆盖所选资料。实际视频与归档核对完整页序、Image 到 memberPath、封面与正文附件、所选 Note／Annotation，并通过播放器或 Kana 重开验证采用后的内容与位置。

<a id="launchbox"></a>

## LaunchBox

按[接入方案](../../design/extensions/importers/launchbox.md)验证 Data／7z、字段大小写与关联，以及内部 ID 与公开身份。小数星级、显式 Progress、旧 Completed、主记录累计量和多版本副本分别采用；PlayCount、LastPlayedDate 不生成完成，JSONL 明细按实际支持范围处理。

手动列表、真实资源根、附件和同名图片歧义使用真实 Data 样本。多版本启动核对参数覆盖、引号、源运行时依赖、监测目标及实际执行等价性。

<a id="koodo"></a>

## Koodo Reader

按[接入方案](../../design/extensions/importers/koodo.md)验证当前 SQLite 家族、双层配置、正式 JSON／CSV 导出、全量文件去重、源键和 MD5。喜爱、Done、Work／Part 范围及空历史条件分别采用；readingTime 按作品归集为附加绝对值，日统计不重复迁入，也不另造活动或概况笔记。

实际文件、图片、书架和普通文字按所选范围采用。Note／Annotation 核对 PDF 几何与原页、CBZ 的准确成员；当前 cfi 不当作通用 EPUB CFI，未知 PDF 模式不推断页位。文字渲染地址、手绘与未知旧家族按支持范围报告，文件登记与位置恢复分别取得结果。

<a id="anx"></a>

## Anx Reader

按[接入方案](../../design/extensions/importers/anx.md)验证 schema 7 一致副本、九列 GBK CSV、独立文字导出及整数精度。五星评分和所选累计时长按对应单位采用；来源 98% 判定只为 Work 的空历史初始化一次未知日期完成，对 Part 只设置标记。重复副本和 startedAt getter 不增加完成次数或活动。

层级组与直接成员、tb_styles 标签、TXT 摘要和媒体根分别处理。真实 Flutter 导出、浏览器 Range 与 Kana 跳转核对 EPUB CFI 的范围和原文、固定 EPUB／PDF／CBZ 页序，以及 PDF 生成文本层与源地址的区别；缺少位置的文字按普通文字采用。

<a id="koreader"></a>

## KOReader

按[接入方案](../../design/extensions/importers/koreader.md)验证受限 Lua AST、current annotations、schema 20221111 和 JSON 包络。abandoned 按来源“搁置”含义采用，整数星级、favorites 与空历史 complete 分别处理；summary.modified 保持修改时间，原始页累计量进入附加时长，暂停压缩起点不生成 Activity。

合集成员与顺序、部分及全文件摘要、路径和附件使用实际导出核对。源 MuPDF 与 Kana 验证 PDF 原生坐标、跨页文字及区域；CBZ 核对完整源页序并拒绝模糊对应。旧坐标、XPointer、近似续读和无几何导出按已声明范围报告，缺少位置的文字仍可独立采用。

<a id="kotatsu"></a>

## Kotatsu

按[接入方案](../../design/extensions/importers/kotatsu.md)验证官方 ZIP、可选媒体根、应用标识和版本、准确源键及非有限浮点。四种离线追踪服务分别解释状态与评分；无日期完成只初始化空历史。Kitsu 的 manga target_id 使用 kitsu / manga/<id>，账号列表行 ID 不成为作品身份。

公众评分、发表状态和当前章节进度保留原义，分类不等于喜爱。真实阅读区间与仅累计附加时长互斥采用，来源时长单位为毫秒。索引、分章文件、零基下载页号、受限模式、缺页与重页、源比较、MIME 及非零像素偏移通过实际文件和 Kana 核对；来源私人文字与图片按所选范围采用。

<a id="yacreader"></a>

## YACReader

按[接入方案](../../design/extensions/importers/yacreader.md)区分十表书库、完整备份与两表资料导出，核对 db_info 文本版本、只读一致快照、准确整数和共享 comic_info。五星评分、未知值、正向 Favorites 及 Work／Part 最低完成分别处理；来源没有阅读活动、时长或当前安排时保留缺席，打开时间和页数不生成这些事实。

物理文件标签、两层列表及顺序、备注与评论分别采用。真实应用与 WAL 快照核对单个前导斜线的路径、部分哈希、封面归属及共享记录的文件选择；Qt／归档后端和 Kana 核对完整页集合、零基书签、一基续读、双页启发式、PDF 与固定图像 EPUB。来源资料缺席保持本地已有值。

<a id="continuation"></a>

## 离线迁入与原批次继续

A22、A15 和 A27 的共同接续机制验证以下场景。十三项来源分别用自身源键和合法样本贯通一次接续，不重复测试它们没有改变的任务或存储机制。

| 场景                                                      | 预期结果                                                             |
| --------------------------------------------------------- | -------------------------------------------------------------------- |
| 未安装资料 provider、没有默认 Profile，输入名称和类型合法 | 直接创建本地对象与所选初值，无资料请求；可以在之后另行补充           |
| NFO／OPF 已有完整普通字段，网络被禁用                     | 所选合法字段正常采用；未选远端图片不请求，缺图不阻止其余资料         |
| 第一项笔记已完成，第二项尚未写入时失败或取消              | 继续同批次跳过第一项，只处理未完成项；TaskRun 可以不同，batchId 保持 |
| 本体写入已发生，返回丢失或 completed 进度保存失败         | 步骤进入 uncertain，不自动追加；用户核对真实结果后再决定继续         |
| running 已持久保存，但进程在请求发出前中断                | 同样按 uncertain 核对，不以猜测判断请求未发出                        |
| 相同来源输入移动到另一位置                                | 摘要相同可继续；内容改变则拒绝复用原批次，保留原结果                 |
| 只修正未完成文件步骤的路径                                | 不重做已经成功的作品、笔记、活动或完成历史                           |
| 已完成的本地目标后来被删除                                | 不重建已完成对象，依赖步骤报告目标缺失                               |
| 清理 TaskRun 历史或关闭导入页面                           | 批次进度仍可读取；关闭观察不停止实际执行                             |
| 用户另建批次并明确追加相同私人内容                        | 按新选择新增，与继续旧批次的跳过行为区分                             |

接续验收通过实际本体运行取证。来源格式、字段含义和解析夹具可以复用各自已有依据。
