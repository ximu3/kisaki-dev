# MangaDex 接入设计

MangaDex 提供漫画资料、真实卷话、本人清单导入和个人记录同步。本文定义对象与字段采用、卷话及等价身份、账号连接、页面与源码组织。

不提供远端关注切换、自定义列表管理或成员增删，不下载章节图片，不建立在线阅读或文件持有记录。公开资料由匿名客户端读取；个人记录只使用明确连接的本人账号。

<a id="identities"></a>

## 对象、身份与创作者边界

正式 source 为 mangadex，sourceId 使用原生资源类别和规范小写 UUID：manga/<uuid>、chapter/<uuid>、author/<uuid>。UUID 格式由本接入验证，不把标题、卷号、话号或数组位置编码为正式身份。

| 来源资源                                  | 本体采用                                                     |
| ----------------------------------------- | ------------------------------------------------------------ |
| manga                                     | Comic；只对漫画提供独立 search、resolve                      |
| 经过下节归并的 chapter                    | ComicChapter；真实发布 UUID 保留为该话的来源身份             |
| aggregate 与封面明确给出的卷              | ComicVolume；没有原生卷 ID，不提供虚构来源身份               |
| 已明确主体类别并有真实 author UUID 的档案 | 只补充 Person 或 Organization 的普通字段，不通过姓名推断类型 |

author 同时容纳个人与创作团体，author、artist 关系只说明职责。本接入不提供人物／组织搜索与 resolve，不从作者名单创建人物、组织或 personWorks／organizationWorks。用户或其他有依据的来源已经明确主体类别且提供 author 身份时，可以直接读取其字段；provider 不查询本地库来猜测类别，也不解析传记来自动分类。

上传者、翻译组及平台用户不作为本接入的独立档案或原作参与者。原作角色资料、Anime、Game、Novel 及其他 Part 类型均不声明。

同一 manga 的彩色、黑白、正式连载和连载前记录不因名称相同而绑定为同一目标。关系只按本页的明确含义采用，关联作品不自动入库；用户已经明确对应的来源身份仍可正常读取。

<a id="parts"></a>

## 卷话分组与来源身份

卷话目录以 /manga/<id>/aggregate 的公开分组为依据，读取 includeUnavailable=1，不按资料语言或翻译组过滤成员。语言只影响可采用的标题与图像，不使同一话因切换语言变成另一条本地记录。

聚合组的 id 与 others 都是真实 chapter UUID。需要普通话字段、确认归属或同步标记时，按 UUID 批量读取 /chapter，核对 manga 关系、卷号和话号；不把不同漫画中的同号话合并。对已由公开聚合给出的 UUID，批量查询显式包含不可用、空页面、外部链接和未来 publishAt 的元数据，避免永久外链或站内延迟发布被默认筛选漏掉；这些时间不证明原作尚未发表，也不触发个人完成。读取不调用图片服务器取得正文。

话号只做来源编码范围内的解释，不截断小数、不将 15.1 归并进 15，也不按最高话号推算话数。本接入采用站点明确声明的章节划分；不声称已经逐页核对原版出版内容。跨来源存在范围冲突时不能通过编号回退掩盖。

| 来源声明                             | 分组与编号采用                                                                                                 |
| ------------------------------------ | -------------------------------------------------------------------------------------------------------------- |
| chapterNumbersResetOnNewVolume=false | 只归并来源同一个明确卷话组中的发布 UUID；话号进入 ComicChapter.numberLabel，不因其他卷组话号相同而追加等价身份 |
| chapterNumbersResetOnNewVolume=true  | 卷号与话号共同确定当前来源范围；话号只进入 volumeChapters.numberLabel，不填成作品范围话号                      |
| 未编号的 none 组                     | 不把一组未编号发布当成同一话，不据此自动生成分部                                                               |
| 每卷重置话号但卷号缺席               | 无法确定编号范围，不自动归并或生成该组分部                                                                     |

卷号缺席时不创建“默认卷”。对于不重置话号的漫画，有明确话号的无卷组可以成为作品话，但不因同号而与有卷组建立身份等价。编号作用域与身份等价是两项事实，不能用不重置编号的声明替代来源的同组依据。重置声明缺失、组内归属或编号互相矛盾时，不能交付半份成功目录，按集合读取失败处理；独立根字段可以作为 partialResult 保留。

已确认同一话的全部 UUID 随同一个对象返回：以规范 UUID 字节序最小项作为本次 identity，其余放入 externalIdentities。代表项不具有业务优先级，匹配核对全部身份。新增发布版本改变代表项时，不会因此创建新话；身份已经指向多个本地话时报告冲突，不自动合并本地记录。

卷集合来自聚合中明确的非空卷号，以及封面资料明确提供的非空卷号，不从 lastVolume 补齐中间卷。相同来源范围内的卷使用本次回答的 key 归并；key 不持久化。与已有卷的对应沿[本地分部唯一匹配](../../domains/metadata.md#local-parts)，使用本次明确启用的 Part 规则，必须唯一且没有版本或归属冲突，不把卷号升级为身份。重复获取同号卷复用原 ID；已有两个同规则目标时报告歧义，不新建第三卷。

来源返回完整的请求集合，本体继续按资料方案和本次更新范围选择卷、话与收录。收录采用只连接本次所选范围内已经明确对应的端点，卷封面字段与收录属性不能扩大卷或话清单；同一话可在多个已选卷中分别形成收录，不增加唯一卷父键。

只有卷内编号时，不拿它与本地 ComicChapter.numberLabel 做回退匹配。已有真实 UUID 的对应照常使用，其他对象只使用既有能够成立的识别规则；不添加 MangaDex 专用的隐含匹配回调。

明确 chapter refs 可以单独读取字段，不要求重读全部兄弟话；提供根 manga 身份时必须核对归属。未编号 UUID 已经明确对应某个本地话时，可以读取该发布的标题与链接，但不扩展 none 组的其他 UUID 为等价身份。无身份的卷字段必须在已确定的 manga 目录中对应，不能单靠一个卷号直接联网读取。

## 读取能力与搜索

| 上下文       | 提供的操作与关系                                                                                                                         |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------- |
| comic        | search、resolve、根字段；workRelations、entryTags、workVolumes、workChapters、volumeChapters；明确的相关漫画、创作者 refs 和卷话字段读取 |
| person       | 仅按已明确的 author 身份读取根字段，不枚举作品或其他关系                                                                                 |
| organization | 仅按已明确的 author 身份读取根字段，不枚举作品或其他关系                                                                                 |

workRelations 提供 note，volumeChapters 提供有来源依据的 numberLabel；其余上述集合没有额外普通属性。没有根 identity 时只读取明确 refs 或明确标签名，不推造根关系和身份。

漫画搜索使用 GET /manga，title 为关键词，order[relevance]=desc，保留来源顺序。名称定位返回完整的必要候选，不因只命中一项就 resolved；真实同目标身份才提供直接定位。搜索和普通集合按 limit、offset、total 续读，不能把第一页或来源上限当作完整范围。

搜索、目录与按 ID 批量读取明确请求四种内容分级，不受 API 默认过滤暗中裁剪；公开资料的可见处理交给本体敏感标记。只采用公开发表的 manga 记录，不把站点草稿状态映射为作品发行状态。搜索图片和资料读取不写入来源绑定。

已知 chapter UUID 可分批直接查询，因此读取聚合目录不依赖把整个发布 feed 当成可无限分页的清单。其他集合仍可能遇到 10,000 条查询上限；无法完整取得时报告来源限制，不使用截断数组、随机子集或循环重复首页。

<a id="fields"></a>

## 普通字段与语言

| 对象                          | 声明字段                                                                                                                     |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| Comic                         | name、originalName、aliases、description、primaryImage、externalLinks、isNsfw、releaseDate、originalLanguages、releaseStatus |
| 已明确的 Person／Organization | name、description、primaryImage、externalLinks                                                                               |
| ComicVolume                   | numberLabel、primaryImage                                                                                                    |
| ComicChapter                  | name、originalName、aliases、externalLinks、numberLabel                                                                      |
| Tag                           | name、description                                                                                                            |

来源没有同义依据的结束发行日期、声明总量、作者生卒／性别／原名、卷名、卷话原作发表日期和声明页数均不提供。上传时间、可读时间、图片页数、当前目录数量、lastVolume、lastChapter 不补成这些值。作者传记中出现姓名文字不变成结构化 originalName。

语言码按官方含义转换：zh 为 zh-Hans，zh-hk 为 zh-Hant，pt-br 为 pt-BR，es-la 为 es-419；ja-ro、ko-ro、zh-ro 分别对应 ja-Latn、ko-Latn、zh-Latn，不当作英文译名。其他普通语言码按其规范标签解释，不能靠字符外观判断语言。

漫画 name 在 title 与 altTitles 中按 preferredLanguages 选择真实名称形式。同一语言先取主 title，再按 altTitles 的来源顺序取非空项；没有匹配时采用来源主标题。originalName 只取 originalLanguage 所明确对应的原文标题，不能用罗马字转写或选中的中文译名反填。aliases 保留实际其他名称形式，沿共同名称规则去重，不从简介、标签或搜索词生成别名。

originalLanguages 使用原始创作语言，不采用 availableTranslatedLanguages。year 是原作发行年份，只形成 { year }，不补月日。发行状态 ongoing、completed、hiatus、cancelled 分别对应 ongoing、finished、paused、cancelled；不影响个人状态和完成历史。

contentRating=safe 对应 isNsfw=false，suggestive、erotica、pornographic 对应 true，表示本体的敏感内容处理，不改称统一年龄分级。未知值不默认安全，也不传播到作者或分部。

漫画介绍与作者 biography 各自按真实多语字段及 preferredLanguages 选择。没有匹配时优先来源英文正文，再取原作语言正文，最后取来源实际存在的非空正文；人物／组织没有原作语言时省略该步骤。正文保留普通 Markdown，转换为本体支持的安全结构，不执行 HTML 脚本、iframe 或站点组件。不根据未标记文字分析剧情，也不宣称所有正文都无剧透。

话标题在已经确认等价的发布记录中，按译文语言偏好选择；同一语言按真实 UUID 顺序选择非空标题，不按最近上传者偏好变化身份。originalName 只采用译文语言确实等于作品原作语言的标题；其他真实标题可进入 aliases。全部没有标题时保留空值，不把“第 N 话”写成 name。

<a id="images"></a>

## 封面与图片候选

漫画 primaryImage 使用该 manga 的唯一 cover_art 关系，即站点明确选定的主封面，不自行改取首卷、最新上传图或第一话首页。需要时扩展引用取得 fileName；cover UUID 本身不是文件名。

原图地址按官方规则由 manga UUID 与完整 fileName 构成。256、512 像素图只是同一图片的缩略版本，不成为三张候选；真实原图、缩略图与资源参数都保持来源含义，不把封面 UUID 绑定为卷身份。

卷封面从完整 /cover 列表中核对 manga 归属与明确卷号。候选按实际 locale 与 preferredLanguages 排序，无匹配时优先原作语言，再保留来源的稳定顺序；同一语言采用 createdAt 倒序、UUID 稳定补序。资源创建时间只用于候选顺序，不成为卷发行日期。未注明卷号的图不分配给任意一卷，缺少卷封面不从父作品主图复制。

独立图片浏览只为 Comic 提供 primaryImage，搜索或明确漫画身份后可浏览其全部真实封面。人物、组织的 imageUrl 只通过明确 author refs 读取；卷图随卷字段读取。没有章节封面、作品背景或标题标志依据，不声明相应候选能力，不请求章节图片或截取首页。

<a id="links-tags"></a>

## 外链与标签

普通外链保留完整 URL 及来源名称，漫画自身页面、官方原文与译文链接分别呈现。链接指向单册、章节、合集或原作小说时，不自动成为当前 Comic 的身份。未支持的站点仍可作为普通外链保存，不形成官方接入依赖。

漫画 links 中明确的同目标资源按如下语法提供其他来源身份；不能只保存链接而遗漏已明确的编号。未知形状只保留可可靠解释的普通链接，不从末尾随便截取数字。

| 来源键与值            | 正式目标身份                                                            |
| --------------------- | ----------------------------------------------------------------------- |
| al 的规范数值 ID      | anilist / media/<id>                                                    |
| mal 的规范数值 ID     | myanimelist / manga/<id>                                                |
| kt 的规范数值 ID      | kitsu / manga/<id>；slug 形态只保留官方可解释的查询链接，不冒充数值身份 |
| mu 的明确新式系列代码 | mangaupdates / series/<code>；纯数字旧编号不直接当作新式系列代码        |
| bw 的明确 series/<id> | bookwalker-jp / series/<id>；单册或无法确定作品范围的地址不绑定根作品   |

mu 的旧编号与新式代码使用各自明确的网址形态，不能猜测换算。其他 URL 只按真实目标资源范围解析；原文连载、授权译文、商店和作者网站不因同处一个对象而获得相同身份含义。作者只交付自己的官网与实际社交网站，不把其作品链接绑定到作者本身。

entryTags 采用漫画直接给出的标签，不展开父分类，不把出版受众或内容分级另造为标签。标签名称固定优先采用来源英文名；缺少英文名时取来源按语言码稳定排序的首个非空名称，不随 UI 或资料语言改名。标签 description 可以按资料语言选择。group、UUID 和 version 不存为本体标签层级、身份或隐藏属性；没有明确敏感与剧透字段，不补 isNsfw 或 isSpoiler。

独立读取标签 description 时，按明确名称与 nameKey 在 GET /manga/tag 的完整官方标签目录中对应，不按本地标签 ID 查询来源。不能因两个名称描述相似而合并标签，也不从正文关键词建立额外标签。

<a id="work-relations"></a>

## 漫画之间的关系

两端必须是明确的漫画资源，关系来自实际 related 枚举，不采用推荐接口或同名推断。来源没有本接入支持的小说、动画等根资源，不能将外链或关系文字伪装成那些类型的 SourceEntry。

| 来源 related                    | 本体关系               | 说明                                                                       |
| ------------------------------- | ---------------------- | -------------------------------------------------------------------------- |
| prequel、sequel                 | prequel、sequel        | 保留实际方向                                                               |
| main_story、side_story          | mainStory、sideStory   | 本篇与外传                                                                 |
| spin_off、adapted_from          | spinOff、spinOffOrigin | 官方说明将二者定义为衍生作品与其原作，不按 adapted_from 字面改成另一种关系 |
| doujinshi、based_on             | spinOff、spinOffOrigin | 在 note 中保留同人衍生的来源称谓                                           |
| alternate_story                 | alternativeVersion     | 来源明确为故事的另一种展开                                                 |
| same_franchise、shared_universe | related                | 保留同系列、共同世界观说明，不创建系列或世界观实体                         |
| colored、monochrome             | related                | 保留彩色／黑白版本说明，不据此自动合并身份或推导重制                       |
| preserialization、serialization | related                | 保留连载前／正式连载版本说明，不推导改编或重制                             |
| alternate_version               | related                | 来源未说明具体不同演绎，保留其版本称谓                                     |

未知枚举按无法解释处理，不降为 related。note 只在请求时交付，是否请求 note 不改变成员与方向。关系不自动建立其他漫画条目，也不将其作者、卷话或文件递归引入。

<a id="account"></a>

## 账号与三个页面

账号页使用用户自己的已获批个人客户端。client ID、连接状态和必要账号摘要是普通配置；client secret、访问令牌及刷新令牌进入 secrets。用户名和密码由用户主动提交，密码仅在当次表单请求期间存在，不持久保存、回传页面或写日志。

向官方 token 端点提交 application/x-www-form-urlencoded 的 password grant，随后以 /user/me 核验实际账号；不使用共享个人客户端，也不实现尚未开放的公共浏览器授权。该兼容模式不执行站点多因素交互，账号页如实说明。刷新、换账号、取消和断开沿[共同账号合同](../private-data.md#connection)，失败不静默降级或自动重放密码。

认证头只发送到明确的 api.mangadex.org、auth.mangadex.org 相应个人端点，不发送到 uploads、章节服务器或任意外链。公开资料客户端保持匿名。连接不触发导入、同步或自动功能。

导入页管理来源清单、对象与字段选择、资料方案、可选本地目标合集，以及独立自动导入。同步页管理已绑定漫画范围、选中个人字段、手动执行与自动同步。状态、评分与话标记接口没有可写的逐条可见性字段，不提供对应公开性控件或私密承诺，也不改写列表的 visibility。没有独立采集参数，不增加资料采集页；语言和字段仍由本体资料方案管理。

<a id="import"></a>

## 清单与个人值导入

支持本人关注漫画、本人阅读状态表中的漫画，以及用户选定的自建或关注的自定义列表。所有来源范围明确选择后按真实 manga UUID 去重；不会声称这些范围包含账号所有历史评分或全部阅读行为。评分查询只针对本次明确漫画 ID。

列表仅作为导入范围，可将结果加入用户选定的本地手动合集；不自动镜像列表结构，不按同名创建合集，也不编辑远端列表或关注关系。关注他人的列表时，成员只决定作品范围，个人状态与评分仍只读取当前本人账号。

手动导入按[共同采用规则](../synchronization.md#import)执行，已有对象的资料不因个人记录导入自动刷新。状态与评分只采用来源实际存在的记录；状态或评分记录缺席时不据此清空本地值。读取失败、未授权和分页截断不解释为无记录。

| 来源值                                         | 入站采用                                                                     |
| ---------------------------------------------- | ---------------------------------------------------------------------------- |
| plan_to_read、reading、on_hold                 | planned、active、onHold，保留完成历史                                        |
| re_reading                                     | active，不推算此前完成次数                                                   |
| completed                                      | 无本地历史时初始化一条未知日期完成记录；已有历史保留，按共同规则清除当前状态 |
| dropped                                        | 不采用当前状态，不转为 onHold 或删除条目                                     |
| 本人 rating=1–10                               | 本地 score=rating×10；平台平均分不采用为本人分数                             |
| 某一等价发布 UUID 有已读标记                   | 本地对应 ComicChapter 已读                                                   |
| 完整读取标记后，同话全部明确对应 UUID 均未标记 | 本地对应话未读；只在本次明确选择采用分话标记时写入                           |

标记导入只作用于已明确对应的话，不把卷号、最高话号、阅读历史项数或整部 completed 变成分部标记。新增所需卷话须通过本体分部与收录完整操作，保留明确来源身份；未编号、未知归属或身份冲突的标记报告未采用，不增加逐项配对向导。

自动导入默认关闭，启用、应用启动恢复配置后及运行期间默认每小时执行完整核对。只新增缺少的实际对象并采用选定初值；已有漫画、卷和话只复用，不覆盖资料或个人记录。已有漫画不代表其所有话都已经存在，缺少的话仍可按已确认范围新增。新对象初值与创建共同提交，必要收录按本体完整操作建立；源移除不删除本地对象或合集成员。

没有完成日期、逐次完成历史、评论、私人备注或时长的对应导入。评分 createdAt、发布和可读时间均不变成完成日期或活动记录。卷已读与话已读独立，不因全部话已读而标记卷或作品完成。

<a id="sync"></a>

## 本地到平台同步

只处理用户选定范围内具有真实 manga 身份的本地漫画。状态、评分、话标记分别通过各自端点修改，不构造全量收藏对象，也不额外调用关注、列表管理或章节内容接口。

自动同步默认关闭，在启用、应用启动恢复有效连接，以及范围内来源对应或所选本地个人字段变化时执行，遵守[共同触发规则](../synchronization.md#automatic)。不增加远端定时轮询，也不将自动导入的定时检查变成同步任务。远端后来出现的等价发布，在下一次实际触发的同步中核对。

| 本地目标                   | 出站行为                                                 |
| -------------------------- | -------------------------------------------------------- |
| planned                    | plan_to_read                                             |
| active                     | reading；远端已经为 re_reading 时保留该等价细分值        |
| onHold                     | on_hold                                                  |
| 当前状态为空且有完成历史   | completed                                                |
| 当前状态为空且没有完成历史 | 明确提交 status=null，撤回平台阅读状态                   |
| score=10–100               | 按 score/10 四舍五入为 1–10 整数，半值向上               |
| score=0–9                  | 低于来源有效范围，该字段报告无法同步，不钳制或改成未评分 |
| score=null                 | DELETE 本人的该漫画评分；不删除漫画、关注或列表成员      |

完成日期、完成次数、完整历史、喜爱标记、卷标记、备注与实际活动均不提供同步。没有任何个人记录变化时不通过重复 POST 制造平台编辑时间；正常验证与未知结果重读沿共同同步合同执行。

话标记同步从本地明确绑定的 chapter 身份出发，重新核对所属漫画及当前等价组。某个已绑定 UUID 当前无法读取时，可以通过同一话的其他明确身份和公开聚合核对；无法确定归属或等价范围时不提交猜测标记。

每轮重新取得当前等价 UUID 和平台标记，不因本地已读值与上次确认相同就跳过成员核对。出站同步不借此为本地登记新身份，长期绑定仍由允许采用身份的本体完整操作处理。

本地已读时，将该话已确认等价的发布 UUID 统一加入 chapterIdsRead；未读时统一加入 chapterIdsUnread。只修改这些 UUID，不以整个漫画未返回的记录推导未读。已有明确绑定的未编号发布只能按该身份操作，不扩展 none 组；身份冲突或同一组对应多个本地话时报告冲突。

不传 updateHistory 参数，标记同步不制造实际阅读历史。请求按漫画与来源 10KB 限制分批，已读、未读列表互斥，分批结果分别核对；网络结果未知时先读取标记，再决定尚需提交的差异，不盲目重放整批。只有核验过的字段更新同步确认值，不承诺状态、评分和全部话标记跨端点共同原子成功。

依据为[公开与个人合同核验](../../../verification/evidence/mangadex/public-contracts.md)及[字段与映射核验](../../../verification/evidence/mangadex/metadata-mapping.md)。真实账号申请、登录、刷新、个人读取与写后核对各自需要运行证据；OpenAPI 与匿名样本仅证明对应公开范围。

验收覆盖罗马字与译名、原作语言、年份精度、发行／个人状态分离、封面归属及缩略图、创作者类型不推断、标签名称、全部关系枚举、同源多身份和冲突、编号重置、未编号组、多卷收录、不可用发布、完整分页、无伪造卷身份；个人场景覆盖缺席不清空、重读不造历史、真实评分范围与撤回、话标记全组读写、不写阅读历史、跨批部分成功、换账号及没有关注／列表管理／正文下载路径。
