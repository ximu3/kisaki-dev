# NDL Search 接入设计

NDL Search 为已明确的漫画、小说及其单册补充出版书目资料。接入使用官方 SRU 1.2／DC-NDL v3，按真实记录与版本读取，不自动发现作品母体。

<a id="scope"></a>

## 职责与交付

| 能力             | 方案                                                                         |
| ---------------- | ---------------------------------------------------------------------------- |
| 书目读取         | 已明确整作范围的独立出版物，以及 ComicVolume／NovelVolume 的实际书目信息     |
| 精确定位         | 按完整 NDL 记录身份读取；已明确目标的 ISBN 可用于来源内部精确核对            |
| 名称搜索与根定位 | 不声明独立 Entry search／resolve，不把混合出版书目包装成作品候选             |
| 分部目录         | 不提供 workVolumes、workChapters 或 volumeChapters，不按书名搜索结果建目录   |
| 人物、组织、角色 | 不提供独立档案或作品参与；责任者文字与权威引用不能自行建立主体               |
| 图片与本人数据   | 不提供书影、账号、借阅、导入、同步或本地文件                                 |
| Webview          | 不需要独立页面；字段与来源选择沿本体资料方案，书目跳转使用普通 externalLinks |

官方 provider 通过匿名 Node 请求读取书目资料。书目引用的 Web NDL Authorities 出处保留为来源链接；人物档案、借阅、数字阅读与批量目录分别属于 NDL 的其他服务。

<a id="identity"></a>

## 身份、ISBN 与目标范围

source 使用 ndl，书目身份为 book/&lt;完整 itemno&gt;，例如 book/R100000002-I000010078222。保留原生大小写、机构前缀和编号中的前导零；只保存末尾数字会丢失记录归属。RDF 的 #material、#admin、#item 分别表示书目、管理信息和馆藏项，不另造本体对象，也不作为卷、话或文件身份。

正式读取范围限于国立国会图书馆自己的已完成藏书书目，查询限定 dpid=iss-ndl-opac；返回结果仍核对记录归属与管理信息；元数据使用条件读取 BibAdminResource 的 rights，Item 的内容／馆藏权利不能混作元数据许可。其他机构的同 ISBN 结果不自动合并进本来源，不把 NDL 的许可扩大到所有聚合机构。

根字段只为已明确作为当前 Comic／Novel 绑定的整作书目读取。分卷作品的单册通过 Entry 会话中的 Part refs 读取，可以省略 NDL 根身份，遵守[会话合同](../providers.md#session)。没有明确 refs 时不以本地卷号或模糊标题代替；不能读取一册后再宣布其父作品已经对应。明确目标可以是已有对象，也可以是本次新增流程中已由其他来源确定的对象；不要求必须先保存到本地。

ISBN 是出版物标识，不是跨版本的作品主键。以 ISBN 提供的明确目标引用使用 source=isbn、sourceId 为通过校验的规范 ISBN-13；ISBN-10 输入须先按正式规则校验并转换，不增加 ISBN 解析贡献或出版版本实体。provider 仅将这个精确引用用于查询当前书目，核对实际 ISBN 类型、单册范围和唯一记录；记录、集合 ISBN、合订、节选或版本有歧义时报告无法唯一采用，不取第一项。

NDL 与 ISBN 身份只在实际范围相同时作为同一目标的来源依据。一个书目所列的全套 ISBN、原资料 ISBN、其他版本 ISBN不能复制给当前卷。不同机构都命中同一个 ISBN，也不能直接证明它们对单册／多册范围的描述一致。

<a id="reading"></a>

## 查询与 XML 边界

采用 SRU 1.2、recordSchema=dcndl_v3、recordPacking=xml。按 itemno 精确读取，必要的 ISBN 查询同样使用 SRU。公开 OpenSearch 和旧版 RDF 仅作为核验对照，不建立运行时回退链；英文规格仍描述旧系统，不能代替当前日文合同。

按 URI 识别 XML 命名空间，不依赖前缀名称、字符串标签顺序或固定空白。禁用 DTD 和外部实体，限制响应体、节点数量与解析深度。BibAdminResource、BibResource、Item 按真实引用连接；书目字段只从对应 BibResource 读取，馆藏机构、借阅情况和来源数字文件不成为用户 holdings。

实测请求 v3 时，响应外层 recordSchema 仍可能写成通用 dc-v1.1 URI，而 recordData 内确实是 v3 RDF。因此以请求版本、实际命名空间和必要结构共同校验，不仅检查外层字符串，也不无条件接受另一种格式。

HTTP 200 仍可能包含 SRU diagnostics。优先使用结构化诊断 URI 与实际数据形状处理，缺少可读记录的诊断不作为可清空的空结果。只有完整成功的查询确实给出零条记录时才认定该次未命中；不根据异常文本猜业务分支。

分页按 numberOfRecords、nextRecordPosition 和实际记录推进。当前 SRU 最多提供前 500 条，不能通过继续增大 startRecord 获得完整大目录；这是本方案不承担按名称生成卷目录的另一项限制。完整性要求覆盖本次精确查询，截断、机构不符、重复或读取失败均不能宣布已唯一对应。

<a id="fields"></a>

## 字段采用

| 来源值                                       | 采用规则                                                                |
| -------------------------------------------- | ----------------------------------------------------------------------- |
| dcterms:title 与结构化 dc:title、volumeTitle | 对应书目范围的 name；按来源结构保留完整书名，不能删去卷次后充当整作名称 |
| 明确的 dcndl:volume                          | 相应卷的 numberLabel，保留来源实际卷次文本；书系编号和任意排列不是卷号  |
| dcterms:abstract                             | 当前书目的实际摘要／介绍；没有时保持缺项                                |
| dcterms:date、dcterms:issued                 | 按下述版本与精度规则提供适用 releaseDate                                |
| dcterms:extent                               | 只为范围一致的整作或卷提供明确 declaredPageCount                        |
| dcndl:originalLanguage                       | 仅为已经明确整作范围的根提供原文语种；不从单册反推根字段                |
| 当前 NDL 书目页、实际书目标识                | externalLinks 与经核对的外部身份                                        |

dcterms:description 主要是目录注记，例如“附年表”“插画：abec”或版次说明，不拼成剧情简介。RSS description 常将标题、责任者、出版方和分类合成 HTML，也不作为作品正文。实际摘要沿公共 Markdown 内容边界处理，不下载书内正文。

dcterms:title 可是“作品名. 卷次（卷名）”，dc:title 则可能只有共用书名；请求同一目标时使用相同的名称映射，不能让显示名与定位名各自删改。NDL 的转写、别题名和书系题名可能属于不同范围，不声明无条件 aliases 或 originalName，也不按日文字符推断原名。

dcndl:seriesTitle 中的“电击文库；1746”是出版书系信息，不等于小说母体、出版品牌组织身份或第 1746 卷。volume 字段还可能是部编名称，直接保留实际文本，不强制转为整数。空值不补成“第 1 卷”。

日期使用可验证的实际精度。样本中的结构化 issued 只有 2009，而 date 明确写 2009.4；只有两者一致且文本符合确定的年／月／日格式时，才可采用 2009-04。日期区间、约数、补记推测和互相冲突的值不取首日或任意一端。RSS pubDate、记录 created／modified 和数据全量更新时间均不是发行日期。

日期首先是该出版版本的事实，只有已经明确属于当前内容范围的原作首次发行时才提供 releaseDate；译本、修订版、重印和合订日期不覆盖原作日期。dcterms:language 表示该出版物语言，不能直接提供作品 originalLanguages；原文语言字段也不使一个译版书目自动成为已确定的整作。

“352p ; 15cm”可以给出本版本 352 页；“xii, 352p”“2 冊”或多个部分的混合容量不能自行相加。册数不是页数，电子文件实际页数也不从书目推导。合订总页数不分摊给各卷；独立完整作品只在整作范围确定时采用整作页数。

当前搜索接口可按资料类型、NDC／NDLC、作者等缩小书目范围，但没有能够稳定区分整部作品、单卷和出版版本的筛选规则。书目类型 Book、NDC 文学分类、单个 ISBN、搜索结果只有一条或缺少卷次，都不足以自行证明它是一部独立叙事作品。实测“よつばと”题名查询还返回漫画研究、名言集和育儿书，不能按关键词或共有作者归成漫画目录。

<a id="exclusions"></a>

## 不承接的来源内容

不从责任者／出版社字符串创建人物或组织，不把 foaf:Agent 一概当作 Person。权威 URI 证明存在另一个档案，但不能同时证明其类别、作品职责及整作范围；书目中的作者、编者、译者、出版者和发售者继续保持区别。

目录分类、馆藏状态、价格、尺寸、受众文字和许可说明不转成个人状态、喜爱、评分或本体专有字段。本方案不提供 entryTags 或其他资料关系，也不把书目关系 isVersionOf、hasVersion、isPartOf 当作故事前后作或本体卷话目录。

书影 API 已在 2026-03-31 结束服务，见[官方公告](https://ndlsearch.ndl.go.jp/news/20260401_thumbnail)。不使用旧 ISBN 缩略图接口，不通过网页抓取或第三方上游恢复同一已停服务。其他数字馆藏的 thumbnail、IIIF 或正文链接也不作为通用轻小说／漫画封面来源。

<a id="operation"></a>

## 运行、出处与组织

国会图书馆自有书目按当前数据提供机构清单的 CC BY 条件使用，保留 NDL Search 和实际机构出处、书目链接及许可说明。API 可匿名读取不代表所有聚合数据具有同一许可。长期接入的联系登记按官网说明处理；不把其合作请求写成用户必须注册账号的运行步骤。

固定来源地址，不允许设置任意代理或未经核对的数据机构。全扩展单队列，默认请求至少间隔 1.1 秒，单次超时 30 秒；安全读取最多重试两次，遵守 Retry-After。书目缓存一天，明确刷新绕过缓存；不下载全量目录或维护第二份本地书目库。来源未回答、失败与明确空值沿共同合同分别处理。

```text
src/
├── entry.ts
├── client/
│   ├── gateway.ts
│   ├── xml.ts
│   └── types.ts
└── metadata/
    ├── provider.ts
    ├── identity.ts
    └── fields.ts
```

entry.ts 装配并登记 provider；client 负责 SRU、节流、缓存与 XML 边界，metadata 负责身份、ISBN、书目范围及字段解释。没有账号、导入、同步、Webview、私有 IPC 或空占位目录。读取会话内复用已取得书目，关闭、取消与扩展停用沿公共生命周期执行。

<a id="verification"></a>

## 验收与预设

来源依据见[接口核验](../../../verification/evidence/reference-sources/live-api.md#ndl)。独立 Authority 的公开数据只用于确认引用性质，不计入 provider 能力。

漫画／小说预设使用 NDL 补充已明确单册的 name、externalLinks、releaseDate、declaredPageCount。验收覆盖 ISBN 校验、版本歧义、部分失败、XML 限制、引用采用与所有字段的缺席／空值；请求脚本证据与正式扩展验收分别记录。
