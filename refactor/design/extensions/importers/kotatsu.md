# Kotatsu Importer 接入方案

Kotatsu 导入器迁入漫画资料、所选追踪记录、分类、私人文字、阅读时间与实际下载内容。输入基线为已归档的 [v9.4.1 源码](https://github.com/KotatsuApp/Kotatsu/tree/06a0b5829b8d5f214d60d5011d66ec1ccbd5630e)、versionCode 1033 及固定 parsers／Coil 依赖，依据见[合成核验](../../../verification/evidence/kotatsu-importer/source-and-fixtures.md)。

<a id="scope"></a>

## 用途、入口与输入

一个本地手动迁移页面。用户选择一个官方备份 ZIP，即可迁移可识别的作品线索、分类、本人追踪记录、私人评论及阅读时间；只有文件、书签和续读需要另选已复制到持久目录的下载／本地媒体根。自动识别 ZIP 内的数据分段及所选媒体根内的已支持索引，不要求用户逐个提供内部文件。

默认处理漫画，确属小说的条目可以明确选择 Novel，范围外内容不强制归类。原项目已停止支持并归档，本项固定官方备份家族，不宣称各分支格式自动兼容。导入器不恢复 Android 应用、在线来源、下载任务、账号或云同步，不注册资料 provider；来源补充由用户在迁入后另外发起。

当前官方 ZIP 的根成员是没有扩展名的 index、history、categories、favourites、bookmarks、scrobbling、statistics，以及不采用的 settings、reader_grid、sources、saved_filters。各成员内容是 UTF-8 JSON 数组，index 也为包含一个对象的数组；没有独立全库漫画文件，书目信息嵌在收藏、历史和书签记录中。备份不包含下载漫画的图像字节和完整章节目录。

index.app_id=org.koitharu.kotatsu、app_version=1033 与必要字段结构共同识别本项基线。app_version 是应用版本号，不伪称通用备份 schema 版本；文件名、ZIP 后缀或相似应用名不足以证明兼容。未核验版本、错误应用标识及不属于该家族的输入在正式写入前拒绝。

缺少可选分段时，明确报告相应数据未知；合法的独立分段仍可采用，不能把部分副本称为完整快照。已有分段的空数组与分段缺失分别处理，不以缺席数据清除本地记录。设置、来源顺序、阅读点击规则及保存的筛选器不恢复，内容不进入日志、报告或笔记。

## 归档、JSON 与源记录

使用成熟 ZIP／JSON 库，限制压缩包条目数、单项与总解压体积、压缩比例、JSON 深度、节点数和字符串长度。仅读取已知选择投影，不把 ZIP 作为应用恢复包解压执行；拒绝越界路径、符号链接、加密成员、重复成员及按来源名称匹配规则折叠后重复的分段。

JSON 保留有符号 64 位整数，manga_id、chapter_id、page_id 可能为负数，也可能超过 JavaScript 安全整数范围；在结构校验前不能转为 number。章节索引对象中的十进制键使用同一精度规则。重复对象键拒绝，未声明的表达式、注释等不能按宽松脚本语法解析。

来源序列化器允许 NaN、Infinity 和 -Infinity 字面量，读取层须按来源语法识别，但这些值不能进入本体评分、时长、日期或位置。它们与用户字符串中的相同文字区分；非法可选数值只影响对应采用项。来源书目未知公众评分正常使用 -1，不能因此把所有评分字段都解释为私人未评分。

本次输入以准确源 ID 联接嵌套书目、分类、历史、书签、追踪与统计。外层 manga_id 必须与嵌套 id 相同；相同标题不合并不同源书目。相同源书目的重复副本只形成一个候选，bookmarks 外层 tags 属于该漫画的来源标签，不能因嵌套 manga.tags 为空而丢弃或当成私人书签标签。互相矛盾的身份副本报告冲突，不按数组顺序任取一个。

统计及追踪分段可能只有内部 manga_id，没有嵌套书目。已有明确作品对应，或本次其他书目已经提供合法身份与必要资料时才采用；孤立内部编号不创建占位作品。只有平台身份而缺少最低创建资料的项目报告待补资料，用户可先通过普通新增取得目标再继续。未采用源删除墓碑不等于执行本地删除。

## 作品、资料与原生新增

源 manga_id、source、相对 url 和本地路径是固定输入中的读取坐标，可用于本批次步骤对应，不成为 Kisaki 公开作品身份。public_url 的有效绝对网页链接可保留为外链；不从来源显示名、hash ID 或相对路径猜站点域名，也不安装来源解析器访问漫画站。

追踪记录的 target_id 表达平台目标，id 按各服务的原义处理。MyAnimeList 和 AniList 复用既有身份合同；Kitsu 的已核实 manga 数值 ID 使用 kitsu / manga/<id>，与[MangaDex 跨站映射](../sources/mangadex.md#links-tags)一致。Kitsu targetId 来自 manga 关系目标，区别于账号列表行 ID，见[固定源码](https://raw.githubusercontent.com/KotatsuApp/Kotatsu/06a0b5829b8d5f214d60d5011d66ec1ccbd5630e/app/src/main/kotlin/org/koitharu/kotatsu/scrobbling/kitsu/data/KitsuRepository.kt)。Shikimori 在本接入中只保留可验证的平台链接。各身份须与选定作品范围一致，矛盾目标分别报告。

已有准确作品正常复用，不自动刷新资料。缺少目标时，以选定 Comic／Novel 类型与可准确映射的来源资料形成 prepared 输入，经 ingest.add 新增；个人评分、当前安排、初始完成，以及“仅累计时长”的附加值随 initial 同次提交。最低资料不足的项目报告问题，不要求在线资料获取。

来源普通资料默认选中；新对象直接采用有效名称、别名、外链、标签、简介与已明确本地封面，已有对象默认保留，选择补空或覆盖后才更新。MangaBackup 本身没有简介，下载索引存在有效 description 时才提供。作者与别名按真实换行读取，索引数组保留原项；作者文字不建立主体或署名关系。

MangaBackup.rating 是公众评分，state 是来源发表状态，均不写入本人评价或完成历史。普通来源空值不清除已有资料，HTML 简介按受限正文转换。封面采用实际提供的本地图像；只有远端地址时，按共同流程由用户另选下载，不可访问与缺图分别报告。

备份没有完整分部目录。history.chapters、scrobbling.chapter、percent 和下载文件数不能生成前 N 话、卷目录或分部已读。配套索引中的 chapter_id、发布组、编号和文件关系用于准确对应内容；真实分部沿已经明确的 Work／Part 关系关联，来源上传日期不改写正式发行或完成日期。

## 本人追踪记录、评分与完成

本人状态、评分和私人评论来自 scrobbling 的离线快照。用户从本次实际出现的已支持服务中明确选择一个，再分别选择采用项；默认不采用。缺少所选服务记录时保持未知，不静默改用另一个，也不平均多个评分。此操作不连接账号，不激活平台同步，也不回写远端。

| 服务编号      | 计划中       | 进行中               | 搁置    | 最低完成事实 |
| ------------- | ------------ | -------------------- | ------- | ------------ |
| 1 Shikimori   | planned      | watching／rewatching | on_hold | completed    |
| 2 AniList     | PLANNING     | CURRENT／REPEATING   | PAUSED  | COMPLETED    |
| 3 MyAnimeList | plan_to_read | reading              | on_hold | completed    |
| 4 Kitsu       | planned      | current              | on_hold | completed    |

表内是这个应用实际保存的原始字符串，不能共用其他导入器的服务编号或状态数值。放弃与未知状态没有本体同义当前状态，报告该项未采用并保留本地。重读映射 active，不据此生成过去完成次数。null 缓存状态保持未知；明确完成状态在选中当前值采用时可清除当前安排，完成历史采用本身不清除安排。

四个服务的缓存 rating 都已由来源归一化到 0–1。有限正值乘 100 后按本体整数评分规则取整，0 为未评分；例如 AniList 三档量尺留下的 0.6666667 采用为 67，Kitsu 0.85 采用为 85，不能再次按平台原量尺缩放。越界、非有限或不符合类型的值报告未采用，不裁剪为有效分数。

completed 只提供至少一次完成事实：整作本地历史为空时初始化一条未知日期完成，已有历史保留；真实 Part 只设置完成标记。新作品通过 initial，同作多个来源副本只初始化一次；已有作品使用 expected.completionCount: 0。追踪备份没有完成日期，history 的创建／更新时刻和备份时间不补作完成日期。

阅读界面的百分比是当前分支、当前已知章节的进度；读到 100% 也可能只是追到连载最新话。来源“标为已读”同样更新这份进度，没有独立逐次完成记录。因此它、已发表完结和读过章数均不生成整作完成历史，也不推算前面各章已经完成。整作评分与状态不能从分部默认为母体事实。

favourites 表示加入来源书库分类，pinned 是来源内部字段，不提供本体“喜爱”的独立事实；本项沿用 Mihon 的范围与合集采用规则，不自动设置喜爱。现有个人值默认保留，明确采用后才修改；同目标矛盾值分别报告。

## 阅读活动与附加时长

statistics 每行按 manga_id＋started_at 标识，started_at 与 duration 均为毫秒。源码在首次状态事件记录起点，之后用 now−startedAt 更新时长，暂停时移除该次计时状态。因此有效行可解释为来源记录的一段区间：startedAt=started_at、endedAt=started_at+duration、durationMs=duration。终点是最后一次实际保存的来源事件，不补齐退出前没有落库的尾段，也不推测期间更细的行为。

用户选择采用阅读时间时，以下两种方式互斥：

| 方式       | 采用规则                                                                                 |
| ---------- | ---------------------------------------------------------------------------------------- |
| 阅读活动   | 有效且已结束的真实区间逐条调用 library.activities 完整操作；可进入原生活动列表和日期统计 |
| 仅累计时长 | 按所选记录的有效 duration 汇总，采用 Work 附加时长；不创建活动或日期统计                 |

活动不要求本地文件；统计没有记录具体章节或文件时，这些引用留空，不能拿当前 history 位置补作发生时上下文。结束必须晚于开始且不晚于提交时刻，时长非负并符合安全整数合同。零时长不生成空活动；非法起止、溢出和未来区间报告该行未迁入，不夹改。起点无效但时长有效的记录，只有明确选择“仅累计时长”时才可保留其累计量。

累计方式先确定实际源范围，按准确 Work 归集一次，再遵守[共同附加时长规则](../../domains/records.md#duration)：新作品初始化 T，已有作品明确采用后设置 T−A，其中 A 为本次已保存活动量；T<A 时不采用。固定本次绝对值和 expected 基线，不在已有附加值上加 T。同范围活动和总量不会重复计入，不另存时长概况笔记。

同一统计主键的相同副本只计一次，矛盾副本报告，不取较大时长。相同时间但不同真实记录不能仅凭时间相同去重；原生活动的重叠统计沿[统一口径](../../domains/library-queries.md#activity-statistics)。完整 statistics 中某书没有记录时累计为 0，分段缺失则未知；非法 duration 阻止对应书目的完整总量采用，不把可读部分称为完整。

history 保存每部漫画最近的阅读位置与进度，其时间、chapter 数和 pages 计数只按这一用途解释。活动从原始统计中的真实区间迁入：继续同批次时复用已完成步骤，另建批次并明确追加时才新增活动。

## 分类与私人文字

按 categories.category_id 与 favourites.category_id 联接，选中的真实分类迁为手动 Collection。隐藏于来源书库的分类仍可选入；空分类可以保留为空合集。源分类 sort_key 只排列分类，成员 sort_key／pinned 在此基线没有已生效的手动排列语义，不据此伪造顺序。

分类按用户选定的当前成员快照迁入。新合集按加入分类时间倒序排列，以准确源 ID 稳定补序；来源动态排序、更新追踪和隐藏设置留在来源端。已有合集须明确选中复用，保留原顺序并追加新成员。同名合集分别管理，同一 Work 的重复成员按普通关系规则建立一次；Part 范围保留用户选择的对象粒度。

所选追踪 comment 是私人文字，按纯文本转义为普通 Note，关联明确 Work；保留有意义换行和字面符号，不变成公开简介，不覆盖已有正文。不同服务的评论不因正文相同合并。技术创建时间为实际迁入时刻，来源记录时间只在有实际可读用途且明确选择时保留上下文。

当前书签备份没有标题、用户批注或高亮摘录正文，只有页、偏移、图像地址和时间等定位信息。不能把它解释成富文本笔记或制造空 Note；真实定位或可采用图像缺失时明确报告未迁入。来源标签来自漫画资料，只有选中时才建立普通作品标签。

## 下载文件、书签与续读

用户选择已复制到持久位置的媒体根，可以补充 Android 旧根→桌面新根映射。只在授权范围识别来源单个 CBZ 内的 index.json，或漫画目录的 index.json 及其明确引用的分章 CBZ；根据精确书目 ID、章节 ID、实际路径及来源上下文对应，不只按标题找同名文件。相同书目存在多个不明确候选时报告，不取最新或最大副本。

配套媒体索引用于核对实际文件与来源章节。具有准确索引时按它恢复内部章节对应；无索引的第三方目录或归档可以由用户明确目标后通过原生操作登记。Android content:// 与远端页面 URL 按不可用的桌面文件位置报告，本项只读取已提供的本地媒体。作品、分类、私人记录和时间可以独立于媒体迁入。

真实媒体通过 holdings 核验并登记；临时目录不成为持久文件位置，不移动、删除来源或覆盖用户文件。文件归属与 Part 范围先明确；缺少精确 Part 可以登记为 Work 文件，下载子目录和压缩包数量不产生新分部。保持已有首选，最近读到的文件不自动设为首选。

书签和 history.page 都是章节内的零基索引。单个 CBZ 的当前索引使用由分支摘要和章节序号生成的 entries 模式选择页面；分章 CBZ 则读取自身根层图片成员。适配只识别源码实际生成的有限模式，不执行任意来源正则表达式。原始下载页号也编码在页名中，从 0 开始；需交叉核对成员页序和编码，缺页、重页导致序号对应不明确时不把压缩后的下标当原页号。

来源 AlphanumComparator 按 UTF-16 字符和数字段长度比较，区分大小写及前导零，不使用区域排序、C 整数转换或其他导入器的自然比较。例如 1、2、3、01、10 是此比较下的顺序。逐章成员过滤使用固定 Coil 表与已核实规则，先保留完整来源页集合；本体不支持的图片不能先删除再重新编号。依赖未记录 Android MIME 扩展才能判断的成员导致页序不明确时，报告该位置不支持。

成功时，准确页面转换为本体 memberPath，保留实际容器和完整成员路径。file+zip URI 的实际成员与索引结果互相核对，冲突不忽略。所选真实页面图像可以通过附件准备作为书签图像保存，不抓取整部远端漫画、不把 URL 字符串当已保存图像。页号越界不夹到末页。

分页模式保存 scroll=0；长条模式保存的是依赖当时视图宽度的像素偏移，而备份没有该尺寸。当前只对明确为 0 的偏移采用页面起点 point=(0,0)，非零、负值、旧浮点残留或未知偏移不声称恢复精确页内位置。书签没有文字可降级时报告未迁入，不能用当前屏幕宽度重算。

位置采用不打开阅读器、不生成会话、活动或完成记录，不更新首选；已有位置默认保留，明确采用后才修改。初始 progress 为空，由 Kana 按本体合同计算。同一文件出现矛盾续读位置时报告，不按百分比最大值或文件修改时间挑选。

## 页面、执行与结果

一个页面提供备份 ZIP、可选媒体根、书目范围、类型、来源资料、分类、私人评论、追踪个人值、阅读时间方式、文件、书签与续读。默认范围是书库分类中的条目，库外条目可以明确选入，统计孤立编号不扩大范围。来源普通资料默认选中，追踪个人值另选，已有值默认保留；资料方案不作为迁入前提。

来源标题、类别、目标类型、Work／Part 范围、配套文件和结果各占一列，窄宽度横向滚动。必要的作品或合集对应在本次范围中完成，不增加整批差异稿、逐项文件预览或事后配对队列。

先完成结构读取与范围核对，再组织 prepared 新增／复用、所选资料更新、个人记录、时间、合集与 Note、文件及位置。ZIP 读取、图片处理和页序校验在数据库事务外完成；所选远端图片读取按独立选择处理，Webview 不直接读源数据或写本体。

完整操作分别提交，取消停止后续步骤，关闭页面不取消后台任务。结果区区分新增、更新、未变化、部分完成、跳过、失败和所选内容未迁入原因。当前可用文字或记录不因媒体缺失而全部丢失，文件登记也不掩盖位置失败。

新建与继续批次遵守[共同规则](../importers.md#repeat)。同批次复用实际目标和已完成步骤，不重复追加活动、评论或书签；未知提交保留待核对。另建批次的追加、空历史最低完成及累计时长仍按各自明确选择处理。
