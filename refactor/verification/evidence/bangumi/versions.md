# Bangumi 版本分组与参与署名

验证日期：2026-10-13。使用官方 v0 API 和官网公开资料，不连接账号、不修改远端内容。[观察数据](2026-10-13-versions.json)保留本轮两项 API 读取、前轮两项书籍读取的相关字段，以及一页 infobox 的资料投影；不保存页面评论或完整简介。

## 作品主体与版本分组

《葬送的芙莉莲》漫画 subject/305429 的[官网资料](https://bgm.tv/subject/305429)将作画、原作、出版社与连载杂志列在主体资料中，另有东立版、次元书馆版、德语版和西班牙版四个版本分组。

GET /v0/subjects/305429 的 infobox 同样保留这层区别：主体字段各自拥有 key，版本则以“版本:东立版”等 key 对应由 k、v 项组成的字段数组。版本分组不是必须从简介中猜测的内容，也不能在读取时无差别摊平为作品字段。

| 资料位置       | 本轮实际内容                           |
| -------------- | -------------------------------------- |
| 主体作画、原作 | アベツカサ、山田鐘人                   |
| 主体出版社     | 小学館                                 |
| 东立版译者     | 里歐貝萊                               |
| 次元书馆版     | 出版社、出品方、图书品牌与译者分别列出 |
| 德语版出版社   | Altraverse                             |
| 西班牙版出版社 | Norma Editorial                        |

前轮取得的 subject/10086《四叶妹妹！》同样具有多个版本分组。subject/13911《奇诺之旅》的样本没有这类分组；没有版本分组不证明作品没有其他版本。Bangumi 维基维护者整理的[编辑注意事项](https://bgm.tv/group/topic/402872)也将多版本编辑限制在书籍范围，本材料不将书籍分组视为所有媒介的共同结构。

## 参与者列表没有保留全部版本范围

GET /v0/subjects/305429/persons 的十项参与中，七项可以通过官网版本分组中的真实 person 链接和相应岗位，确定其在该分组中的署名。七项里只有两项的 eps 写有版本说明，其余五项为空。因此只排除 eps 中出现版本文字的行，会保留部分明确属于译版的参与。

官网版本分组使用 li.sub_container 的 attr-info-group = 版本 和具体 attr-info-list，字段行保留 /person/<id> 链接。静态解析原型对 #infobox 单独解析通过，四组全部取得；上述七项的身份与岗位均与 API 参与记录对应。来源页面称“德语版”，参与关系写“德国版”，也说明不能只靠两个版本名称字面完全相等来对应。

版本归属限定具体作品、岗位和署名，不表示该人物或组织的全部工作都属于某个译版。同一主体也可能在作品主体资料或其他岗位中出现。API infobox 的名称与官网提供的实体链接是不同的证据，不能把名称视为已经取得 person 身份。

反过来，主体出版社“小学館”只出现在基础资料中，本轮官网没有为它提供 person 链接，API 的十项参与里也没有该主体。因此完整的出版署名不能只靠过滤参与者列表取得，纯名称资料也不能制造来源身份。

## 验证边界

本轮证明 API 保留书籍版本分组，并验证了一页官网分组、人物链接及其与参与者列表的对应。未覆盖所有书籍、媒介、自由文本写法、版本重叠或生产解析器；没有据此宣称能够识别所有漏标版本。

已确认的[主体参与规则](../../../design/extensions/sources/bangumi.md#staff-scope)采用原作创作、制作与出版范围，排除明确的其他版本专属工作；必要资料核对后仍未注明版本的署名按作品主体资料采用。这是接入约定，不是本材料证明了所有未标版本记录均属于原版。主体出版方更替也不因本规则截断为最早一家。
