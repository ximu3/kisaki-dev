## 输入与持有关系

openReader 打开一份文档或一个图片目录，返回本次内容的 Reader。调用者提供容器、资源、完整技术设置和发行资产位置：

```ts
const reader = await openReader({
  container,
  source,
  settings,
  assetsBaseUrl,
  position,
  signal
})
```

source 接受 File／Blob 或明确的 ReadingSource。File 是带有文件元信息的 Blob，名称用于识别提示，实际格式按内容判断。宿主负责将作品和文件信息转换为这些资源输入，内核只处理相应文档。

```ts
interface ByteSource {
  readonly size: number
  read(offset: number, length: number, signal: AbortSignal): Promise<Uint8Array<ArrayBuffer>>
}

type ReadingSource =
  | { type: 'document'; data: ByteSource; name?: string }
  | { type: 'directory'; members: MemberSource }
```

size、offset、length 使用字节和非负安全整数；请求必须落在 0 到 size 之间，返回长度与请求一致。长度为 0 的合法读取返回空数组。短读、读取失败和来源变化明确失败，不用补零或另一个文件的字节凑够。数组交付后保持内容有效；库需要转交 worker 时取得独立的缓冲所有权，不擅自分离提供方仍持有的其他数据。

源内容在本次持有期间保持一致。提供方不能让旧读取无声返回后来替换的文件；失效时报告来源变化或不可用。signal 对应这次读取，提供方须实际中止或结束工作。Kana 可以合并与缓存读取，不把源接口的每次调用等同用户操作。

提供方需要保留已知的来源不可用、变化或读取失败类别时，可以抛出对应 ReadingError；其他异常由读取边界包装为 readFailed，并保留 cause。取消依据本次信号与执行状态判断，不解析任意异常消息。

| 对象                                                           | 持有与释放                                                                                   |
| -------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| 调用方传入的根 ByteSource、目录 MemberSource、自定义字体字节源 | 借给本次 Reader；提供方拥有授权范围，在 Reader 收尾后关闭它                                  |
| File／Blob                                                     | 输入内容由浏览器对象持有；Kana 释放自己建立的适配、缓存与临时 URL                            |
| MemberSource.open 返回的 OpenedMember                          | 是 Kana 本次打开取得的占用，含 data 和 dispose；不再使用时由 Kana 释放，不能全部留到文档关闭 |
| openUrlSource 返回的 UrlSource                                 | 创建者拥有，向 Reader 借出 source；在 Reader.close 后调用 dispose                            |
| TemporaryStorage.create 返回的 TemporaryFile                   | Kana 拥有本次创建的临时对象，使用完或关闭时 dispose；只删除自己创建的内容                    |

MemberSource.list 异步列出已授权成员的规范相对路径，open 按路径返回 OpenedMember 或 null。路径保留大小写和 Unicode，使用 / 分隔；绝对路径、越界和有歧义的同名成员不得偷偷选择另一项。目录成员集合的身份与排序由此次打开确定，图片识别、页序和格式内部访问由 Kana 处理。

ZIP 内部成员由 Kana 自己解包，不要求宿主先解析归档再传成员列表。书内关联引用只在本次授权内容范围内解释，不授予任意路径或网络访问。

TemporaryStorage 提供创建、范围读写与释放，写入完成表示本段内容已经可读，逐段等待形成背压。createBrowserTemporaryStorage 提供浏览器私有存储适配，创建适配对象本身不打开文档或建立文件。未提供临时存储时采用有界缓存和允许的重读；资源不足如实失败，不自动改为整包常驻内存。当前可见内容、正在形成的目标和完整原文读取优先，搜索和预取使用余量；取消只释放本次使用占用，不撤销其他操作还在使用的共享资源。缓存、解码器和页面资源的容量策略仍须随实际后端验证固定，不在此承诺整个浏览器进程的精确内存上限。

## 设置与运行时字体

ReadingSettings 由 Kana 独立定义，包含 flow、pages、text 和配色技术输入 colors。flow 决定主阅读推进，pages.arrangement 控制原始页编组，text.pagesPerView 控制正文分页面数；完整字段、库默认值、单位与适用条件见[呈现设置](settings.md)。FontRef、主题身份、附件 id 和宿主配置层级不进入技术合同。

主应用的偏好类型、默认值、读取校验和保存形状由本体独立拥有，不引用或派生 ReadingSettings。只有[阅读接入](../../domains/reader.md#settings-boundary)核对两边需要对齐的含义并准备本次输入；当前部分字段相近不表示两份合同必须同步变化。

颜色使用 document／custom 技术分支：document 保留原书配色并接收区域外 background，custom 接收已解析的 foreground／background。两者均不接收应用主题身份，适用范围见[读者样式](styles.md#colors)。字体使用三种技术选择：文档字体、系统 family、或本次提供的字体资源 id。字体资源另外传入 FontResource，包括具体字节源、字重或字重范围、normal／italic／oblique 样式；同一个资源可以包含多个字重。技术 id 只用于把本次设置与资源对应，不成为 Kisaki 的字体持久身份。

openReader 接收初始 fonts；setSettings 的 options 可以同时提供完整的新 fonts 集合，未提供则沿用现有集合。引用 id 必须存在、资源 id 唯一、faces 非空。库在同一次采用中固定设置及资源输入，不让后来修改调用方对象改变排队中的请求。

提供的字体资源实际读取或加载失败时，可以回到文档字体，并在状态中保留 fontUnavailable；宿主保留原选择。非法配置或根本未提供所引用的 id 属于输入错误，不伪装成正常字体回退。书内字体继续经过文档授权范围，不混入应用字体库。

getDefaultSettings 返回由库维护的独立纯设置值，默认值及其用途见[设置合同](settings.md#values)。宿主将自己的偏好转换为完整输入；库只采用传入值，不读取浏览器存储、操作系统主题或应用配置。

setSettings 完整校验后采用配置，保留当前源落点及仍有效的文字范围。只有实际改变的配置触发相应更新。普通字体或配色调整不重置手动缩放和旋转；pages.fit 改变时采用新的适配方式。缺少可读布局时不能提前报告采用成功。

## 状态、按需内容与交互

Reader 成功建立后，getState 和 observe 交付同一种只读快照：

| 字段                     | 含义                                                                                              |
| ------------------------ | ------------------------------------------------------------------------------------------------- |
| phase                    | ready、closing、closed，描述本次句柄寿命                                                          |
| activity                 | idle、navigating、layingOut，描述当前影响可见位置的执行；搜索不占用此字段                         |
| location                 | 最后已经确认的实际源位置，不能先填入仍在执行的目标                                                |
| view                     | 当前固定或重排视图；两者均含实际前进方向和每组面数，另按类型交付缩放／旋转或书写模式              |
| progress                 | 正文路径中的 fraction 与 estimated，未知或明确进入独立辅助内容时为 null；不用于恢复位置或声明已读 |
| canGoPrevious／canGoNext | 当前正文或独立阅读路径是否还有对应方向的结构目标；不保证目标资源一定可读                          |
| canGoBack／canGoForward  | 本次 Reader 的有界跳转历史是否存在对应条目                                                        |
| referenceView            | null 或已显示临时内容的 { target }；target 是已解释的真实源位置                                   |
| selection                | none、text、region 的当前交互种类；完整文字和几何按需取得                                         |
| interactionMode          | read、region、pan 的当前工具模式                                                                  |
| capabilities             | 当前可用的文字选择、页面区域，以及文档文字搜索能力                                                |
| notices                  | 当前需要说明的字体回退或资源省略，按原因合并，包含首次打开时已经发生的情况                        |
| failure                  | 导致本句柄结束的失败分类；普通单次操作失败不在这里积累历史                                        |

主阅读、临时查看和活动选区各有所指，字段与操作的作用对象见[临时查看](#temporary-view)。快照不暴露私有 DOM 或第二个 Reader。

progress 的具体口径见[格式进度](formats.md#progress)：原始页和 TXT 源偏移使用对应结构计数；重排或混合内容采用带 estimated 的结构估算。它不估计阅读耗时，不触发完成，也不为了先取得全书分母而阻塞首个可读目标。

ReadingView 的两种分支都交付 forwardDirection，取 left、right 或 down，供宿主解释当前主阅读的物理前进方向；它不是底层 scrollLeft／scrollTop 属性。pageSlots 表示当前显示组预留的阅读面数：固定页始终为 1 或 2，重排分页为 1 或 2，连续重排为 null。连续固定页面可以同时看见多个组，pageSlots 不统计视口内全部源页；空槽位也不增加源身份。这些反馈对应已经采用的布局，不提前反映尚未完成的目标，也不反写主应用偏好。

openReader 在成功返回前没有可供调用的 Reader，打开中的 UI 由宿主持有对应 Promise 和取消信号。关闭后的 getState 仍可读取最后可信位置及结束原因，不把卸载后的空 DOM 当作新位置。旧快照不会随之后的调用原地改变。

observe 先同步交付当前快照，再接续变化；返回可重复调用的停止函数，停止订阅不关闭文档。Reader 同步调用回调并忽略返回值，不把回调返回的 Promise 追加到操作或关闭等待。调用方管理自己启动的异步工作及其失败；最终记录保存由 Kisaki 自己等待，不能以“通知已经调用”代替保存完成。

回调中再次调用 Reader 的操作进入后续执行，不打断正在交付的同一快照。某个回调抛错时终止该订阅，并交给宿主未捕获错误机制报告；其他订阅和 Reader 自身继续按其真实状态工作。普通快照可以合并，确认的操作结果和最终关闭状态不能被合并丢失。

需要主动反馈的交互使用 on：selectionChange 通知选区变化；externalLink 交付用户发起的外部 URL；markActivate 只回传不透明标记 id；error 报告没有外部调用 Promise 可承接的交互／后台失败。已经通过调用 Promise 交付的失败不再重复广播成同一错误。状态中的 notices 让首次订阅也能取得仍适用的说明，不另靠打开期间的一次性事件。

[同步按键入口](interaction.md#host-keyboard)通过可选的 OpenReaderOptions.handleKeyDown 交付内容未处理的普通键值。ReadingKeyInput 归纯值合同；宿主同步返回 true 时，由库取消原按键默认动作，false 或缺省时保持。局部编辑、控件和阅读操作优先；异步宿主动作须同步确认接手并自行处理完成。这是打开输入中的处理回调，不加入通知事件表，也不交付私有 DOM。

资源省略通知只适用于仍可有效阅读的辅助资源。当前图片页或其他关键内容不可读时，打开或导航按实际失败结束，不能用 notice 把空白页面交付成阅读成功。

read 是正常阅读模式，按当前内容支持文字选择与通常的阅读移动；pan 明确使用拖动平移；region 在原始固定页面上框选。区域模式不适用于重排内容，显式请求时报告不支持；导航进入重排内容时回到 read，并在状态中交付实际模式。切换工具本身不保存或删除 Annotation。

getSelection 异步取得本次调用时固定的逻辑选择及匹配原文；没有选择则为 null。异步提取过程中用户改变选择，不把新范围和旧原文拼在一起。明确的导航完成后清除旧交互选择，选择动作自身引发的自动翻页或滚动继续同一逻辑范围。setSettings、缩放和旋转保留源选区并重算显示几何；clearSelection 显式清除当前交互选择。

## 导航、搜索、标记与完成

| 操作                    | 公开结果与结束条件                                                                                        |
| ----------------------- | --------------------------------------------------------------------------------------------------------- |
| seek(position 或 start) | Promise<ReadingLocation>；等待目标实际可读、可见，再返回当前真实位置                                      |
| next／previous          | 同样返回实际位置；沿当前正文或独立阅读路径移动，在边缘保留当前位置，不打开其他文件                        |
| back／forward           | Promise<ReadingLocation>；沿本次跳转历史定位，成功后移动游标；没有目标时保留并返回当前位置                |
| closeReference          | Promise<void>；关闭调用时的临时查看及其待完成加载，无取消选项；不改变主阅读位置                           |
| getNavigation           | 按需取得目录标签与结构；没有目标的分组 getLocation 为 null，有目标的条目按需解析为 ReadingLocation        |
| setSettings             | Promise<void>；本次必要的字体、布局与位置恢复完成后成功                                                   |
| setZoom／setRotation    | 固定页面的临时显示操作；倍率必须为正有限数，旋转使用 0／90／180／270；重排视图不接受这些操作              |
| search                  | AsyncIterableIterator<SearchHit>，按源顺序逐步取得 range 和有界 excerpt；支持取消，退出迭代会收尾本次搜索 |
| getTextContext          | Promise<string \| null>；读取指定位置的有界邻近原文，不改变视图或选区                                     |
| setMarks                | Promise<MarkOrder>；采用完整只读投影，返回源顺序的并列分组，以及无法恢复项的 id 和原因                    |
| close                   | Promise<void>；幂等关闭，不接受取消选项，调用持续到关闭完成                                               |

目录条目随本 Reader 存活，在实际使用时通过 getLocation 解析稳定源位置。显示目录只取得所需目录信息，目标章节按定位需要读取。Reader 关闭后条目失效；内部链接也由内核解释并转换为对应源位置。

正文路径由格式明确语义形成，正常翻页和连续浏览沿该路径移动；独立辅助内容仍可通过目录、链接、搜索和标记定位。start 指向正文路径的起始位置。明确进入独立内容后，在其自身路径内阅读，边界处停住，back 可回到此前位置。正文范围、辅助范围、源顺序和进度的共同规则见[阅读路径](positions.md#order)，不增加另一种持久路径标识。

打开、导航和设置采用的共同就绪条件见[完成条件](#completion)。

### 有界跳转历史

Reader 的 navigation 拥有本次文档的历史。首次打开以实际初始位置建立首项，不为恢复位置额外插入首页。seek、目录、搜索结果、标记及普通内链的正式跳转在成功提交后形成历史；普通滚动和 next／previous 更新当前项的停留位置，设置与重排不增加条目。临时查看的打开、替换和关闭不进入历史。

back／forward 接受 CallOptions，沿用真实定位、取消及替代规则。失败或取消不移动历史游标；返回后发起新的正式跳转，仅在成功时截去旧的前进分支。同一实际源位置的重复定位不增加条目，由格式按源语义判断，不按估计进度合并。连续 back／forward 按动作顺序接续，新的显式 seek 可以按既有规则替代尚未完成的导航。

历史保存有界的源位置，不持有正文、DOM 或解码资源，不调用宿主 window.history，也不跨文件或会话持久化。达到内部容量时淘汰较早的条目，保持当前位置有效；不因此删除书签或其他正式记录。关闭 Reader 时清理历史。

<a id="temporary-view"></a>

### 临时查看与活动选区

临时查看用于在正文旁查阅注释。同一 Reader 同时最多显示一处，复用格式文档、源映射和资源管理。新查看替换旧查看；需要连续深入查阅时，可以明确进入原文，临时查看内部不设多级返回。

注释引用由格式语义识别，例如 EPUB 的 noteref／doc-noteref 或 FB2 的引用关系。缺少依据时按普通内链定位；用户从目录、搜索或标记进入注释时，也按正式定位处理。

| 字段或动作                                          | 作用对象与结果                                                            |
| --------------------------------------------------- | ------------------------------------------------------------------------- |
| location、view、progress、翻页能力、interactionMode | 描述主阅读；临时查看的开关保持这些值及续读位置                            |
| capabilities                                        | search 描述文档搜索；textSelection、pageRegion 描述主阅读面的起始交互能力 |
| referenceView                                       | 当前已显示临时内容的真实源目标，没有独立进度                              |
| selection、getSelection、摘录与文字标注             | 唯一的活动选区，可属于主阅读或临时内容                                    |
| 当前阅读位置的点位书签、readView 的 viewport        | 使用主位置与主画面；明确指定源位置的记录操作按该输入执行                  |
| seek、next／previous、back／forward、进入原文       | 正式导航成功后关闭临时查看；失败保留可用内容                              |
| 工具切换、缩放和旋转                                | 作用于主阅读                                                              |
| setSettings                                         | 更新本 Reader 的适用呈现，保留仍有效的源选区和临时查看，等待必要重排      |
| 临时内容的键盘、滚动和焦点                          | 由该内容先处理；宿主快捷键只接手内容未处理的输入                          |

查看支持键盘进入、明确关闭和焦点返回，呈现位置由整体布局决定。关闭只结束查看，不执行反向定位；“进入原文”则使用格式提供的真实目标。

打开或替换查看时结束旧活动选区，关闭时清除其中的选区。主阅读与临时内容分别在自己的路径内选择；已保存标注继续使用源地址恢复。选择过程遵守[统一选择行为](interaction.md#interaction)，getSelection 按调用时固定的范围完成。

closeReference 幂等结束调用时捕获的查看及其加载，释放相应占用；稍后新打开的内容不受旧操作影响，旧加载结果也不能重新打开已关闭的查看。根文档与借入资源继续由 Reader 和实际拥有者管理。

临时内容保留必要的语义、样式上下文和源映射，不因复制片段丢失呈现条件，见[章节上下文依据](../../../verification/evidence/kana-layout-boundaries/boundaries.md)。临时显示调整保持文字资格及已固定选区。

### 搜索、标记与位置转换

getStartLocation 是纯值函数，把标记位置、文字范围或页面区域转换为跳转起点。文字锚点取 start；页面范围取首个实际片段内的中心点，区域取矩形中心，以进入对应源区域，不宣称这是文字光标的真实起始点。它不读取文件，也不能证明目标存在；实际存在性仍由 seek 核对。宿主无需复制这部分确定性几何换算。

search 默认大小写不敏感、wholeWord 为 false，范围包括可呈现的正文与独立辅助内容。匹配转换保持到源字符的对应，结果范围用于定位和标记，不保存搜索用字符串偏移。消费者暂停取用时减少后续读取和解码，不积累整本文档的未消费命中。能力缺失返回 unsupportedFeature；确实执行了文字搜索而没有命中才是空结果。读取途中失败则结束迭代，之前交付的命中仍有效，但不能表示完整搜索已经成功。PDF 有文字提取能力不等于每一页都有文字，图片本身不产生 OCR 承诺。大小写／分词与摘录规则见[内容与视图合同](content.md)，完整格式样本的符合性仍须验证。

setMarks 接收 marks、selectedId 和统一样式。重复 id、非法纯值及 selectedId 不在投影中属于输入错误；当前文档无法恢复某个合法位置则列入 unresolved，不抹去其他标记。同起点标记形成并列组，Kisaki 再用正式记录的稳定顺序补齐。显示重排不会改变这些源顺序或历史 quote。

<a id="operation-lifetime"></a>

### 操作次序与关闭

导航与排版共用执行次序。新的 seek 可以替代尚未完成的导航，被替代调用以 superseded 结束；连续 next／previous 保留每次动作的顺序。setSettings 与导航按调用顺序协作，新的源位置不会被旧设置请求恢复回去。搜索和原文读取不抢占当前可见位置，标记更新只采用本次最新的完整投影。

取消发生在操作提交前时，结束其未完成工作，并以 cancelled 返回；操作已经完成提交时不逆转结果。关闭导致的未完成操作以 closed 结束。返回位置或完成 Promise 前，先采用对应的实际状态；后来的请求不能拿自己的结果冒充前一次成功。信号只控制所属调用，openReader 的信号在成功交付后不变成永久关闭开关。

close 先拒绝新操作，停止并收尾读取、搜索、导航和渲染，交付最后可信状态，再释放视图、格式、实例拥有的专用 worker、临时资源和订阅。静态内容转发登记遵守[部署寿命](distribution.md#assets)，不由单个 Reader 注销。重复调用复用同一次关闭结果。某一步释放失败时继续尝试其余释放，最终如实失败；closed 表示句柄已不可使用，不把关闭失败包装成资源全部成功回收。宿主在自己的 finally 中继续释放所拥有的授权范围。

<a id="reading-operations"></a>

## 资源预算与接入核验

操作返回值、执行次序与关闭规则见[状态和操作](#state)，每次成功所需的可见事实见[完成条件](#completion)。调用方通过这些合同等待实际结果，正式记录保存仍由宿主另外等待。

读取、解包、源树、文字索引、页面 canvas、字体及临时 URL 各有实际拥有者和有界缓存。只在所需内容附近保留昂贵显示资源，搜索不顺带渲染整本书。根源句柄由宿主持有，库释放自己取得的资源占用；关闭后的迟到回调不能重新挂载视图、建立 URL 或访问下一份文档。

声明与独立消费的依据见[公开接口校核](../../../verification/evidence/kana-api/public-contracts.md)。实际接入、完整错误映射与发行资产按[阅读验收](../../../verification/scenarios/reading.md)分别验证。

<a id="completion"></a>

## 内容、字体与布局的就绪条件

打开、定位和设置采用只等待当前目标所需的内容与资源，不等待全书分页，也不以整个网络暂时安静代替完成。需要确认的是目标可读、当前必要依赖已有明确结果、布局已形成，以及源目标已经映射到实际可见位置。

document.fonts.load 可以拒绝，而 fonts.ready 正常完成；后续加载也不改变旧 ready Promise 的完成状态。两者分别表达加载结果与就绪，见 [CSS Font Loading](https://drafts.csswg.org/css-font-loading/#font-face-set-ready)。因此分别跟踪字体成功／既定回退、当次必要布局和待确认的导航目标。fontUnavailable 沿用既有合同；不能仅凭 ready 完成就把回退字体报告成用户所选字体。

可见目标准备期间，保留上一个已确认位置与可用视图；目标及必要布局成立后，才一起采用新位置、视图和选区变化。失败或取消结束本次尝试，不能先把目标写入 location，再由稍后的错误解释空白页面。所需资源的短期重叠也必须计入预算。

具体完成条件如下：

| 操作                                | 成功之前应成立的事实                                                                                 |
| ----------------------------------- | ---------------------------------------------------------------------------------------------------- |
| openReader                          | 首个请求目标已解释，可读内容已出现，必要资源与字体成功或允许的回退已有结果，当前布局和真实位置已确认 |
| seek／next／previous／back／forward | 新目标已经实际可见，再共同采用位置、视图及相应选择／历史变化；只取得目录项或 DOM 不算完成            |
| setSettings                         | 本次适用设置及其必要资源已经完成当前可见布局，原源位置已重新找到；字体回退如实保留 notice            |
| readView                            | 在同一执行次序中固定本次实际布局，按既有合同等待采集与收尾，不消费尚在形成的新几何                   |

完成不要求等待全书图片、全书分页或网络暂时安静。与当前目标无关的预取仍可继续；若后续真实变化影响当前几何，再按新的必要布局处理。资源失败是否允许回退按它在当前内容中的作用判断，不把一个完成 Promise 当作全部依赖成功的凭据。

操作复用只读解析事实，仅为必要的新呈现保留准备空间。宿主尺寸变化使旧几何失效时，保留最后可信的源位置，并重新完成当前区域布局。readView 按同一导航与布局次序取得稳定画面。

<a id="errors"></a>

## 错误与纯值验证

失败通过 ReadingError 携带 ReadingFailure 分类，message 为安全英文诊断，cause 留给拥有失败的边界。分类包括非法输入、不支持的格式／能力、来源不可用或变化、读取失败、损坏文档、无法定位、布局不可用、密码、缺失资源、资源上限、资产加载，以及取消、替代和关闭。无法定位另给缺失目标、越界、歧义、不可呈现或编码冲突原因，不要求调用方解析消息文本。

sourceChanged、局部操作失败及可省略资源失败的影响范围见[失败处理](#failures)。

layoutUnavailable 携带 insufficientSpace 原因，表示当前视口与明确设置无法形成可读区域。打开、定位或设置采用以该原因失败，保留最后可信源位置，不自动减少面数或缩小字号。它属于单次操作失败，不写入 ReadingState.failure，也不因此结束已建立的 Reader。单纯隐藏或零尺寸期间暂停自动布局，重新可见时恢复源落点；readView 继续按其不可见规则处理。

纯入口提供 parseReadingLocation、parseTextRange、parsePageRegion、parseReadingSettings；不可信值无法满足该合同则返回 null，不修补成邻近坐标或另一种编码。写入或执行入口严格拒绝非法值。纯校验不打开文件、不检查当前节点存在性，也不使用 DOM、worker 或浏览器全局。

文本范围在类型上关联相同的地址分支，页面和四边形集合非空；数值范围、代理对边界、TXT 两端编码一致、几何凸性、当前源内容顺序以及是否属于同一可读路径仍需要对应层的运行校验。文字锚点属于不同阅读路径时报告 locationUnavailable／notRenderable，不能把独立辅助内容与正文拼成一个连续范围。TypeScript 检查不被当作完整格式验证。

<a id="failures"></a>

### 按影响范围处理

既有错误分类按失败影响范围处理：

| 情况                         | 已确认行为                                                      |
| ---------------------------- | --------------------------------------------------------------- |
| 自定义字体不可用             | 按已确认规则回退并报告 notice，保留宿主选择                     |
| 可省略的辅助资源失败         | 保留可读内容，明确呈现缺失并报告 notice                         |
| 当前目标页面或必要正文不可读 | 本次打开／导航失败；已有可用位置不被目标或空白覆盖              |
| 单个合法标记无法恢复         | 进入 unresolved，其他标记继续按各自结果交付                     |
| 搜索途中读取失败             | 迭代以错误结束；此前命中有效，但不能表示整份文档已完整搜完      |
| 同一根输入已确认发生变化     | 停止本实例继续读取及提交新结果，保留最后可信状态并结束该 Reader |
| 被取消或替代的局部操作       | 沿现有 cancelled／superseded 规则收尾，不终止仍可信的文档       |

根输入变化影响后续源解释，但保留已有持久地址和标注。发现 sourceChanged 后立即停止接纳新业务，拒绝尚未提交的结果，并沿既有 closing → closed 完成资源收尾。触发调用以 sourceChanged 失败，其余未完成工作沿既有关停规则结束。failure 保留 sourceChanged，最后可信源位置继续可读；关闭不把卸载后的 DOM 或迟到布局写成新位置。宿主需要重新读取时建立新的 Reader，借入的根输入仍由原拥有者释放。此处指已确认的来源变化，普通缺图、单次读取失败或某个标记无法恢复不触发整实例结束。

资源是否必要，应由格式结构和当前操作判断，不能按扩展名简单认定“所有图片都能省略”。当前漫画页丢失与正文中一张可省略配图丢失，影响范围不同。XML 实体被静默省略造成的正文不完整，也不能降为普通辅助资源 notice。
