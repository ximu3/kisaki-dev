# YMGal 公开接口与官方资料集核验

验证日期：2026-10-15。核对官方文档、公开应用访问、游戏搜索及四类档案读取，并检查官方资料集。没有连接用户账号或执行个人记录写入。[结构化记录](2026-10-15-public-contracts.json)只保留必要结果，不包含应用凭据、访问令牌或请求认证头。

## 依据与环境

- [开放 API](https://www.ymgal.games/developer)，文档源码固定于 [1284ac90454b1e68c15a0fc3e94f6003a927f49b](https://github.com/ymgal/docs/tree/1284ac90454b1e68c15a0fc3e94f6003a927f49b/developers)。
- [官方资料集说明](https://github.com/ymgal/data-export/blob/5f7408852fad840ea3d3399bc62146bb64ff34f6/README.md)及 [release-2026-10-09](https://github.com/ymgal/data-export/releases/tag/release-2026-10-09)。
- 普通 Node 24.11.1 发起 HTTPS 请求；资料集通过 ZIP 读取器检查，未执行来源代码。

## 实际结果

| 核对项         | 结果与可支持的结论                                                                                                       |
| -------------- | ------------------------------------------------------------------------------------------------------------------------ |
| 公开应用访问   | 官方公开 client_credentials 配置取得访问令牌，HTTP 200；这属于应用访问，不构成用户登录                                   |
| 游戏列表搜索   | mode=list、每页 2 项时，查询“近月少女的礼仪”得到 total=4、hasNext=true，首项身份为 31147；本次首段不能作为完整候选集合   |
| 游戏详情       | gid=31147 返回 game、cidMapping、pidMapping；实际资料包含 12 条角色关系、22 条职员记录和 15 条发行记录                   |
| 角色详情       | cid=19365 返回生日 3000-01-06，证明样本确实使用占位年份；不能作为真实公元 3000 年生日采用                                |
| 人物与组织详情 | pid=11333 与 orgId=10041 正常读取；独立档案字段不能由游戏响应中的名称和图片摘要替代                                      |
| 真实字段名     | 在线响应使用 moreEntry、jobName、empName、empDesc、releaseName、releaseLanguage 等名称；文档中的部分旧示例与实际编码不同 |

官方的 accurate 游戏搜索按相似度挑选最高项，文档并不保证唯一精确身份。因此，该端点的单个结果本身不能证明来源内定位成功。公开文档只列出游戏名称搜索；人物、角色和组织的独立详情通过明确身份读取。

## 官方资料集

已下载的 ZIP 大小为 32,617,686 字节，SHA-256 为 `4aa2285a5d7fc9c63f7388a330504032a7a0f8daae71f5c7878793f2e5d35613`。其中有 game、person、organization、character、game_releases、game_character_relation 和 game_staff 七份 JSONL。

资料集的游戏基础行不内嵌角色、职员和发行集合，相关记录通过 gid 等字段连接。它使用 chinese_name、org_id、developer_id、cv_id 等编码，不能把在线响应解析器原样用于资料集。本次读取各文件首条记录并核对结构，没有构建完整索引、遍历全部关联或验证全部字段。

官方说明规定每周导出，数据不是实时接口的等价快照；同一来源身份应保持一致，当前字段值则可能因版本不同而变化。API 与资料集的说明均限制非商业使用并要求署名；资料集另明确限制未经许可的打包再分发，不能随扩展安装包镜像分发源库。

## 结论边界

本次证据支持应用访问、公开档案读取、搜索分页和资料集格式的设计判断，不证明来源支持个人账号、清单或同步，也不表示完整实现已通过验收。[产品范围](../../../design/extensions/sources/ymgal.md#ymgal-scope)已选择仅在线 API，不提供资料集下载、更新、索引或读取；资料集核验保留为候选通道的研究依据，不构成支持承诺。采用范围、字段、关系与内部组织已由[专门设计](../../../design/extensions/sources/ymgal.md)明确，设计讨论完成与本次验证范围分别成立。
