# KOReader Importer 接入方案

KOReader 导入器迁入书籍资料、阅读记录、合集、私人文字、文件及可转换标注。输入基线为 [v2026.07.1](https://github.com/koreader/koreader/releases/tag/v2026.07.1)、提交 9192014d8bd82a91dc1012473be0f238dedfdb54 和该版本绑定的 koreader-base／MuPDF，依据见[源码及合成核验](../../../verification/evidence/koreader-importer/source-and-fixtures.md)。

<a id="scope"></a>

## 用途与输入

一个本地手动迁移页面，处理用户选中的漫画、小说、阅读记录与文字。Comic／Novel 和整作／分部范围按实际内容选择，不由扩展名、来源文件夹或一本电子书的外观推断。源库其他类别的书籍不自动归入 ACGN。导入器不注册资料 provider，不登录 KOReader 同步服务或外部笔记平台，也不恢复源应用及其设置。

| 输入方式      | 支持范围                                                                                                                               |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| 随书数据      | 当前 metadata.<扩展名>.lua、同目录的 custom_metadata.lua 与真实封面；可从用户选定的 .sdr／集中存储根读取，媒体根和旧新路径映射另行选择 |
| 阅读统计      | 一致的 statistics.sqlite3，user_version=20221111；可以单独选择，也可与上述书目明确合并，按真实必要表和列识别                           |
| 收藏与合集    | 本次明确提供的 settings/collection.lua；以保存的实际成员为快照，不执行文件夹扫描、过滤或其他自动规则                                   |
| JSON 笔记导出 | 官方 json/1.0.0 的单书或 documents 多书结构；迁移所选摘录、私人批注和上下文                                                            |
| Markdown／TXT | 官方 UTF-8 文字导出，整份保存为一篇普通 Note；不反向拆成猜测的原始记录                                                                 |

当前随书数据与同批 JSON 采用不同输入模式，不把同一批批注的两种表示自动叠加。统计、合集是随书模式的可选补充，统计也可独立提供书目线索。纯文字模式可以明确关联已有作品或保留独立 Note，不因标题、文件名或一段文字而创建占位作品。

版本字符串、文件名及 .sdr 后缀均不足以单独证明兼容。只解释本项声明的结构；不自动读取 .old、历史目录、metadata_arc 归档、旧 highlight／bookmarks 布局，或把 annotations_paging／annotations_rolling 备用内容与当前 annotations 合并。旧格式可由来源应用另行整理后重新提供；当前书目资料可独立采用，未支持的旧批注明确报告。HTML、远端笔记服务、云端同步及任意 Lua 设置文件不在本项输入范围。

源程序关闭后取得完整一致的数据库副本。不把带未合并 WAL 的任意主文件当作快照；输入只读，不执行源库迁移、触发器、来源自定义 SQL 或插件。统计只查询已知真实表，来源 page_stat 视图与缓存仅用于说明差异，不作为本体写入入口。

## Lua、文件与来源对应

Lua 文件按字节解析为 AST，只允许单个 return table、普通键、列表字段、有限数字、字符串、布尔值、nil 和数字负号。拒绝函数、调用、变量求值、算术、赋值、循环、计算键、重复键及多返回值；即使代码位于未选择字段也拒绝。绝不调用 dofile、load、require 或 Lua 虚拟机执行输入。

采用成熟解析库，并在解析及遍历中限制文件字节、节点数量、嵌套深度和字符串长度。Lua 字符串先保留原始字节，所采用文字再按严格 UTF-8 解码；十进制转义不能被当成 Unicode 码点，非法可选文字单独报告。字符串键、数字键保持区别，不能通过普通对象原型属性读取数据。选入的位置、页号、顺序等再执行各自有限值及安全整数校验。

当前支持旁置 .sdr，以及用户指定的集中／摘要存储根中的已选随书数据。doc_path 和明确的旧根→新根映射用于对应；旁置路径也只在所选范围内核验。两者矛盾时报告，不按同名、最近修改时间或最长路径猜测。不跟随数据中的任意绝对路径读取磁盘，不自动枚举其他设置目录、归档或用户文件。

KOReader 的 partial_md5_checksum 及统计 book.md5 是分段抽样摘要，官方 JSON 的 md5sum 则是可选的整文件 MD5。二者不能互换，也不是公开作品身份。抽样摘要可能在未采样字节变化时保持不变，写入 PDF 批注也可能改变它；它只辅助本次来源对应，不能独自证明文件完全相同。统计书目的来源身份由 title、authors、md5 共同约束；与随书数据合并时使用原始属性和实际摘要，唯一命中或本次明确绑定才合并，不能仅按标题或摘要关联。

## 作品、资料与新增

源书目 ID、路径、摘要和数组下标只在这份固定输入与批次内解释；批次保存步骤所需的本地引用，不写入公共 externalIds，也不建立来源资料镜像。每本源书先明确对应整部 Work 或真实 Part：合集、合订本、单卷和同作不同文件都不能仅凭数量或标题转成新作品、卷目录或作品关系。

已有作品按实际文件归属、明确选择或完整公开身份复用。新作品以实际书名、用户选定类型及可准确映射的来源资料形成 prepared 输入，经 ingest.add 新增；评分、当前安排、初始完成与附加时长随 initial 同次提交。最低资料不足时报告具体项目，不依赖联网资料方案补齐后才能迁入。

来源普通资料默认选中，新对象直接采用有效名称、简介、关键词及已明确的本地封面；已有对象按明确补空或覆盖范围更新。custom_props 按来源语义覆盖 doc_props，空字符串同样是源覆盖；本体采用仍保留缺席与空值区别，不用无效空资料清除本地值。

作者和关键词只按真实换行拆分，不按逗号猜人名。关键词可作为所选普通作品标签；作者文字不创建人物、组织或署名关系。文件中的语言、出版者、系列和日期可能属于版本，不直接改写 Work 原文语种、首次发行或系列关系。缺少公开身份时仍可用合法本地资料创建，来源补充另行选择。

封面只采用明确匹配且字节可解码的实际文件，同一范围存在多个不明确的 cover 候选时报告。附件正式接收后不依赖来源目录。缺少媒体文件不阻止书目线索、个人值、书评和其他文字迁移，但不能生成有效文件登记。

## 状态、评分、收藏与完成

| 来源事实                          | 本体采用                                                                     |
| --------------------------------- | ---------------------------------------------------------------------------- |
| summary.status=reading            | 当前安排 active                                                              |
| summary.status=abandoned          | 当前安排 onHold；该值在当前来源界面表示“搁置”                                |
| summary.status=complete           | 当前安排可明确采用为空；完成事实按下述独立规则处理                           |
| 状态缺失或未知                    | 没有可采用的当前安排，不由书库存在、最近打开或百分比补造                     |
| summary.rating 的整数 1–5         | 分别映射 20、40、60、80、100；不接受半星、越界或非法值                       |
| 已知 summary 中的 nil／0 评分     | 未评分；summary 本身缺失或无法解释时区分未知                                 |
| 明确提供的有效 favorites 成员快照 | 对本次准确对应的书目表达收藏 true／false；缺少该保留名称的集合时不推断未收藏 |

收藏只识别来源保留的 favorites 集合，不把 default 标记、名称含“喜欢”的普通合集或任意成员关系解释为收藏。采用完整的该集合快照时，所选且准确对应的非成员才可表达 false。现有当前安排、评分和收藏默认保留，明确选择采用来源个人值后才修改。

complete 只证明至少完成过一次。整作对应且本地历史为空时初始化一条未知日期完成；已有历史时保留，不追加一条快照。为已有作品初始化时携带 expected.completionCount: 0，新作品通过 initial 提交。同作多个完整源书不重复生成最低完成记录。源书对应真实 Part 时只采用该 Part 的完成标记。

summary.modified 既会因状态变化更新，也会因修改评分或书评更新，因此不能作为完成日期。文件修改时间、JSON 导出时间、最后打开时间和笔记时间也不补作完成日期；百分比 98%／100%、末页和读过页数均不代替明确 complete。完成历史采用本身不修改现有当前安排，只有另行选中的当前值采用才会修改它。

分部的评分、收藏和当前安排不能默认为整作事实；只有其范围明确为 Work 或用户在本次明确采用到 Work 时才设置。多个来源对应同一目标却给出矛盾个人值时报告对应值，不取最新、最大或任意一项。summary.note 是私人书评，所选内容另建 Work Note，不成为公开简介。

## 阅读时长

采用口径明确命名为“原始页记录累计时长”：按 book.id 汇总 page_stat_data.duration 的有效整数秒，再换算为毫秒。原始表、page_stat 展示视图、book.total_read_time 缓存和随书旧统计不能相加，也不相互回退。

来源 page_stat 会按当前页数重新展开旧记录，并以整数除法分配时长。例如原始 5 秒拆到两页后，视图合计可能只有 4 秒；缓存还可能未更新。选用原始记录保存已实际落库的时长，不承诺与来源所有展示统计完全一致，也不能恢复来源已忽略或封顶的时间。该完整快照内没有页记录的书目，按此口径明确为 0；缺表、未知 schema 或有非法时长时不采用该书总量，不将可读部分冒充完整总量。

页记录用于累计阅读时间。来源会在暂停恢复后调整 start_time，并忽略或封顶过短、过长的停页时长，因此这些值仅按原有汇总语义采用。它们不能准确恢复连续活动区间，日历活动、热力图和最后使用时间不由这些页记录生成。

互不重复且明确属于同一 Work 的源书总量先汇总一次，再按[附加时长](../../domains/records.md#duration)采用。新作品以选定总量 T 初始化；已有作品默认保留，选择采用时按本次已保存活动量 A 设置 additionalDurationMs=T−A，保留 expected 基线。T<A 时不采用该总量。重试沿用同次固定绝对值，不在已有附加值上加 T，不把时长另存为概况笔记。

不同副本、书名变更、多个统计库或同一文件的重复书目不能在未明确覆盖范围时相加。没有 Part 对应不妨碍明确属于 Work 的时间采用，也不因此增加 Part 时长。仅随书数据或 JSON 中没有当前统计库时，不从旧 statistics 字段、页数、百分比或打开时间补出总时长。

## 合集与文字

collection.lua 中每个已选普通集合迁为平面手动 Collection，保存的 file 成员通过本次书目对应转换为 Work，目标重复成员按普通关系规则只保留一次。来源有明确手动 order 时保留该顺序；设置 collate 而未保存成员 order 时只保留成员集合，新成员按稳定来源路径排列，不声称恢复了手动顺序。已有合集只能明确选择复用，不因同名自动合并；保留已有顺序，新增成员追加。

带文件夹扫描或过滤设置的集合可以迁入已保存成员快照；不重新运行扫描，不恢复未来自动维护规则。源路径暂时不存在时，仍可通过已明确的来源书目采用其 Work 关系。favorites 可以单独选择为收藏值，也可以按所选整理范围保存为普通合集，两者不隐含联动。

当前 annotations 中 text 是来源保存的摘录，note 是私人批注；不重新生成、额外裁短或把缺失 quote 猜为当前文件文字。能够准确转换位置时保存为原生 Annotation；不能转换时，已选的实际文字可保存为普通 Work Note，并报告定位未迁入，不同时复制成一份 Annotation 和一份相同 Note。纯定位失败且没有可保存内容时只报告未迁入。

官方 JSON 当前导出丢失了 pos0、pos1、pboxes 和跨页 ext，还可能遗漏纯页书签。page 可能是显示标签，pn_xp 只有单个起始页或 XPointer；这些字段不能恢复完整高亮，本项 JSON 统一按实际文字迁为 Note。导出器在产生文件前已因同名书覆盖的内容无法恢复，导入端也不再按标题合并记录。旧图像载荷、其他入口产生的未知 entry 类型不冒充当前文本标注；可用文字与未迁入图像分别报告。

Lua 和 TXT 中的用户文字按纯文本保存；转为 Markdown Note 时转义字面语法并保留换行。Markdown 导出整份按受限正文保存，不执行内嵌内容或自动下载外链资源。原始批注日期可选保留为可读上下文；无时区的日期不伪称 UTC。本体 Note／Annotation 的 createdAt 是实际迁入时刻，created_on 是导出时间，均不互相替代。

## 文件、书签、高亮与续读

媒体按所选持久根和路径映射核验、登记，不移动源文件、不覆盖用户文件。作品／分部归属与实际文件明确后才转换位置；不能仅凭同名或抽样摘要把旧坐标挂到另一份文件。

| 来源位置                         | 本项能力                                                                                                        |
| -------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| PDF 当前纯页书签                 | page 是从 1 开始的真实物理页，核对实际 PDF 后转为 pageIndex=page−1，页内点为起点；不采用 pageno／pageref 显示值 |
| PDF 当前文字高亮                 | 使用真实原生页面 pboxes，保留每条矩形及跨页 ext，转换为 ReadingTextSelection 的逐页 quads                       |
| PDF 当前区域选择                 | 同页、有限同义端点和相同正 zoom 可确定源区域时，按源公式去除 zoom 并规范化为 ReadingPageRegion；不补造截图附件  |
| CBZ 当前纯页书签                 | 重建来源真实成员集合与页序，将 1 起始页号转为完整 memberPath                                                    |
| 固定页面续读                     | 仅来源只记录物理页或明确记录页内起点时采用页起点；非零 page_positions 是近似排版进度，不能伪装为精确坐标        |
| EPUB／TXT／FB2／MOBI 的 XPointer | 本项不转换；文件可按本体支持能力登记，摘录和批注仍可迁为 Note                                                   |

PDF pboxes 来自 MuPDF 原生页面坐标，即使阅读画面使用重排，当前保存的 pboxes 也经过映回原生页处理。它们不是截图像素，也不是未经变换的 PDF 底部原点坐标。按实际文件 CropBox／MediaBox、UserUnit 和页面 Rotate 确定可见原生页宽高，再将四个端点规范化；不能重复应用用户视图缩放或旋转。

来源写入 PDF 批注时使用 x+w−1、y+h−1 作为 pbox 的右下端点；本体按该约定保存从左上开始的顺时针四边形，不简单使用 x+w，也不把多行合成一个大矩形。跨页高亮保留从 pos0.page 到 pos1.page 的全部 ext 几何。缺任一页、越界、非有限或退化几何时整条位置不采用，文字保留路径独立处理，不裁剪后宣称完整恢复。未核实的旧坐标家族、屏幕框和 CBZ 区域高亮不进入此适配。

CBZ 按此版本 MuPDF 的图片后缀集合与 ASCII 不分大小写的自然数字比较重建页序，包含 KOReader 补丁支持的 WebP。大写 PNG 仍属于来源页；先列出完整来源页集合，再检查本体能否读取所指成员，不能删除不支持的图片后重新编号。本项可验证范围为无比较歧义的 ASCII 成员名；大小写／前导零比较相等、数字段超出源 C int 范围、非 ASCII 比较或重复成员时，不猜测平台排序。子目录保留为 memberPath，不由目录或源 TOC 生成 Part。

XPointer 依赖来源生成的 DOM、DOM 版本和重排选项。不能把 DocFragment 编号当 EPUB spine 下标，剥掉路径前缀后当 CFI，或以第一处同文搜索、当前页数和百分比替代原端点。JSON 的单个 pn_xp 同样没有补齐另一端的依据。

已有文件位置默认保留；明确采用的同文件位置彼此矛盾时报告，不选最大进度或最新文件。采用位置不打开文件、不生成会话与时长、不修改首选、不产生完成记录；progress 保持本体未知值，由实际阅读内核按原生合同计算。

## 页面与执行

页面按迁移目的组织入口。“迁移书库与阅读记录”选择书籍目录，自动识别其中受支持的 .sdr；需要时再选择 KOReader 数据目录，自动识别当前统计库、合集文件及所支持的集中随书数据。“只迁移摘录与批注”选择官方导出文件。通常选择一到两个目录，不要求逐个挑出内部文件；识别只在本次授权范围内进行。页面显示实际找到的资料种类供用户选择，缺少可选统计或合集不阻止其余迁移。

一个页面选择输入方式、数据文件／根、来源书目范围、Comic／Novel 类型、Work／Part 对应及本次采用。来源普通资料默认选中；当前安排、评分、收藏、完成、时长、合集、标签、私人文字、文件和续读分别选择，已有值默认保留。需要时才显示媒体根、路径映射、日期时区或已有目标选择，资料方案不作为导入输入。

来源标题、输入类型、目标类型、Work／Part 范围、文件状态与结果各占一列，窄宽度横向滚动。对应和冲突在本次选择范围处理，不增加整批差异稿、逐项文件预览或事后配对队列。

先检查必要格式和来源关联，归并同目标的明确范围，再调用原生新增／复用、所选资料更新、个人值和空历史初始化、附加时长、整理、文件、标注及 Note 的完整操作。字节读取、网络资料准备和位置转换不放在本体数据库事务中；Webview 不直接读来源数据库或写本体库。

每个完整操作独立提交，取消停止后续步骤，关闭页面不取消后台任务。结果区区分新增、更新、未变化、部分完成、跳过、失败和所选内容未迁入原因；文件已登记不掩盖位置转换失败，未选内容不报告为迁移问题。

新建与继续批次遵守[共同规则](../importers.md#repeat)。同批次保存源键和步骤结果，继续时跳过已完成文字与标注，未知提交先核对；另建批次可以明确追加。最低完成仍受空历史条件约束，时长仍按绝对值采用。
