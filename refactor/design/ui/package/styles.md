# 组件样式与定制

desktop-ui 提供完整的桌面控件外观。组件从 desktop-appearance 的 CSS 呈现值取得颜色、阴影、字体和尺寸。应用与扩展使用同一套[主题值](../../domains/appearance.md#tokens)，文档的明暗模式、缩放、字体取得和全应用预览归[外观接入](../../domains/appearance.md#view)。

## 公开定制面

| 作者要改变的内容               | 接口与作用范围                                                                                               |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------ |
| 整个桌面的配色、字体与尺寸     | 主题作者通过 SDK 提供完整的亮暗定义，桌面采用后向各文档投影当前分支。                                        |
| 一个控件的用途与密度           | 用组件声明的变体和尺寸，例如次要按钮和紧凑图标按钮。                                                         |
| 当前页面中一个实例的布局或样式 | 传入 `class`，由宿主样式表定义。组件保留自身类名，并把调用方类名附加到该接口说明的元素上。                   |
| 部件的实际内容、动作或原生属性 | 组合该家族公开的部件，例如菜单项、对话框内容与动作。已有按钮与 Popover 通过[原生触发关系](overlays.md)组合。 |

Button 的类名落在实际 button 上，Input 的类名落在编辑元素上，Popover 的类名落在浮层表面上。负责状态的组合根通过其可见部件提供定制。作者可让一个按钮在工具栏中靠右，主题作者则可统一改变次要操作及辅助标记的配色。两种设置分别由页面 CSS 与主题登记管理。

长期接口涵盖文档列出的视觉 token、Props、组合部件与类名落点。颜色变量按声明位置和 CSS 继承规则生效。主题节点负责计算派生值，局部覆盖可针对该部件实际消费的属性或呈现变量。[CSS 自定义属性](https://www.w3.org/TR/css-variables-1/)

## 家族内的样式

TSX 表达语义结构、属性与交互。尺寸、颜色、变体、伪元素和动效在家族的普通 CSS 中维护。规则通过带 `ks-` 前缀的类名命中所属元素，例如 `.ks-segmented-item[aria-pressed="true"]`。优先按 `:disabled`、`:focus-visible` 和 `aria-expanded` 等实际状态绘制。额外的视觉用途可由根上的变体属性表达。

包内规则进入 `kisaki-ui` 层。默认选择器保持较低优先级，宿主按 CSS 层叠规则定制自己的元素。通用焦点环、仅供读屏的文字等规则由需要的部件显式采用。浮层、菜单项及第三方生成的内容在实际挂载区域取得各自的样式，嵌套部件仍由各自家族绘制。

普通控件使用对应前景和填色，普通及图标尺寸沿现有桌面密度校准。键盘焦点、选中、按下、禁用与字段错误应能分辨，聚焦的无效字段可同时呈现焦点环与错误边框。动效跟随减少动态效果的系统偏好。[共同界面](../components.md#accessibility)

## 组件与窗口底色

内容和窗口框架的基础区域按[底板规则](../../domains/appearance.md#tokens)呈现。标题栏、侧栏和结构性页头属于窗口框架。徽标、页签选中项、提示内容等已经位于某一层上，使用本组件的填色。Popover、菜单及 Dialog 采用各自的浮层色和阴影。

## 普通 CSS 制品

`src/styles.css` 从公开入口接入 desktop-appearance 的基础样式，并聚合 `base.css` 和各家族的样式表。W01 负责主题节点的变量与约定的文档根字体、字号、前景和底色，W05 的选择器只作用于显式采用其样式的元素。宿主负责自己的页面布局、工具类和文档重置。

构建将相对导入与公开的外观 CSS 展开为 `dist/styles.css`。包通过 `/styles.css` 交付这份普通样式及对应声明，用 CSS 副作用配置保留显式导入。Solid 工程只需在文档入口加载一次。使用 Tailwind 的应用可以从 W01 的独立映射编译自己的工具类。[工作区视觉交付](../../engineering/workspace.md#visual-packages) · [样式聚合依据](../../../verification/evidence/native-ui/README.md#styles)
